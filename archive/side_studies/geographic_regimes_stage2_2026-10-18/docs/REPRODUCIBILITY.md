# Воспроизведение этапа II

## Вход и среда

Checkout исследовательской ветки, с исходным stage71 в publication/stage71. Нужен gzip 142570×135 с SHA256 d40273e13a8ecf8f31bf367ddc414e21bd026eea325192629fb2f81f6dfa374c и accepted_common_federal_territory_axis.csv. Никаких Excel малых городов вместо панели. Выход направляется в новый каталог; вход, main и этапI не переписываются.

Python3.12; точные версии зависимостей в protocols/requirements-research.txt. Seed20261018 там, где используется выборка. Геометрические процедуры детерминированы; UID разрешает равенства. Среда и SHA скриптов/выходов сохранены в receipts. Ссылки и уровни чтения литературы/первичных свидетельств не заменяются библиотечными версиями.

## Полный расчёт

Из корня checkout, где REPO - абсолютный путь этого checkout:

```bash
python research/geographic_regimes_stage2/scripts/reproduce.py \
  --repo-root "$REPO" --workdir /tmp/stage2-replay
```

Entry point запускает географию, чувствительности C2, аудит, весь matching и C1. Он не загружает заново внешние источники и не повторяет первичное чтение шести локальных XLS: их байты могут отсутствовать в другом checkout. Старые скрипты конкретного облачного запуска сохранены неизменными; geography wrapper материализует подстановки путей в новом каталоге, хешируется исполняемая версия. Отдельные независимые скрипты в validation/independent содержат пути исходного исполнения: для их переноса нужно явно подставить вход, сравниваемые результаты и выход. Это ограничение записано, не скрыто.

Память: основной baseline matching хранит439786пар с диагностикой и использует около3-4ГБ RAM; широкая CSV gzip около100МБ. Артефакт GitHub хранит полный состав графа в компактных ключах. Значения каждой пары восстанавливаются из обоих паспортов и scaling contract; полный широкий CSV можно пересоздать compare.py.

## Как читать компактный полный реестр

outputs/comparison_registry.csv.gz содержит439786строк: a_unit_id,b_unit_id. Оба ключа соединяются с outputs/registry_units.csv, где есть kind,unit; затем со своим паспортом в outputs/territory_metrics.csv.gz. Так сохраняется весь допустимый граф, а не только выбранные пары. Участники одной пары имеют одинаковыйkind. Ничего не пересопоставляется после просмотра исходов. Перекрывающиеся пары зависимы.

Основные таблицы: outputs/comparison/pair_distributions.csv; selected_illustrations.csv; outputs/geography/sensitivity_table.csv; outputs/c1/c1_sensitivity_summary.csv. Large derivative manifest хранит SHA пропущенных тяжёлых промежуточных файлов. Неопределённость источников, границ и панели не устраняется точной арифметикой.

# Ошибки и ограничения независимой проверки

- Первая попытка compare_matching.py прочла comparison_registry.csv.gz, пока основной процесс ещё записывал его; возник EOFError до gzip end marker. Полученное исключение не интерпретируется как повреждение завершённого файла. После завершения основного процесса сравнение повторяется.
- Полные142570 строк проверены на UID и hash; региональные суммы/доли пересчитаны полностью. Геодезический полный перебор применяется к60 детерминированно выбранным origins,120 minima; это выборочная проверка алгоритма, не исчерпывающая проверка каждой точки.
- Matching baseline NN и центров использует опубликованную таблицу метрик, не независимо пересчитанные национальные NN для всех origins. Поэтому matching репликация проверяет стандартизацию, eligibility,caliper и membership, не полноту национальной геометрии центров.60 point-NN проверяются отдельно.
- Случаи tie соседей сравниваются по минимальному distance; возможное различие UID при почти равных distance не объявляется геометрической ошибкой. Top population ties проверены deterministic UID lexicographic.
- Никакие первичные данные, main, этапI и Git не изменялись.

Завершение: после закрытия primary gzip повторное compare_matching.py прошло;439786 pairs membership совпали,353 numeric pairs прошли. Первое EOF полностью объяснено ранним чтением незавершённой записи.

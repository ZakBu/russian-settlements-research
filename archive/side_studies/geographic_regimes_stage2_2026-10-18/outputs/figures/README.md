Шесть научных статических рисунков. Карты показывают точную геометрию квадратных аналитических ячеек EPSG6933, без выдуманных границ регионов. Малые ячейки серые; полный состав и исходные CSV сохранены. Основная карта x>=0, отдельная врезка для x<0. Москва/СПб — контекстные якоря, федеральная территориальная масса не размещена в точках. Подписи прочих ориентиров из строк исходной панели. Расстояния WGS84. Медиана парных изменений NN равна0 в1356/1359 supportedcells; показанныйp90 предусмотрен исходным протоколом, не выбран по значимости. Цветовые шкалы ограничены для читабельности, концы со стрелками; исходные значения не обрезаны. Никакой статистической значимости не заявляется.

# Независимая калибровка и исторические услуги

`build_services_2021.py` извлекает магазины, рынки, банки, банкоматы, почту и административные учреждения из российского OSM-снимка **2021-01-01T21:42:03Z**. Полный PBF уже загружен общим медицинским/дорожным конвейером; повторная загрузка не нужна. Сначала создаётся малый reference-complete PBF, затем извлекаются узлы и геометрии ways. Relation-геометрии не извлекаются. Среднее вершин way — представитель геометрии, не проверенная точка внутри здания.

В `services_2021_objects.parquet` сохранены объекты, исходные теги и доказательства связей. Явный адрес населённого пункта в радиусе5км и отделённый ближайший географический кандидат до2,5км имеют разные поля. Возможные node/way-дубли одинаковой функции и имени до50м сохраняются, а счётчики считают каноническую запись. Эти правила не доказывают полный перечень физических учреждений. Ноль принятых картографических записей означает неизвестную обеспеченность. Число записей не равно мощности.

`extract_admin_centers.py` использует **явные** роли `admin_centre` в административных OSM-relations. Код в данном Geofabrik-срезе чаще хранится в `oktmo:user`; это название атрибута, а не юридическое подтверждение. `link_admin_centers.py` связывает буквальное имя центра и координаты с уникальным принятым НП до5км, сохраняя неразрешённые и неоднозначные случаи. Для самостоятельного административного эксперимента оставлены районные отношения уровня6 с точным восьмизначным кодом, присутствующим в справочнике оси2021:127единиц/28регионов до отбора полной выборки.

`source_admin_crosswalk_exploratory.parquet` независим от рассчитанных гравитационных районов. Это допускает **нециркулярную** калибровку на административном прокси. Однако современная картографическая связь и равенство кода не доказывают историческую эквивалентность границ или фактическую ориентацию населения. Статус `source_confirmed_administrative_center` означает прямое утверждение источниковой OSM-relation; ограничения источника и времени записаны в отдельных колонках. Основная гравитационная масса автоматически этим экспериментом не заменяется.

Исходники: [исторический OSM2021](https://download.geofabrik.de/russia-210101.osm.pbf), [зафиксированный OSM2026](https://download.geofabrik.de/russia-261019.osm.pbf). Атрибуция: © OpenStreetMap contributors, ODbL-1.0; Geofabrik. Хеши полных PBF и результаты извлечения сохранены в receipts.

Запуск из корня репозитория:

```bash
python research/sgrt_word_completion_20261021/calibration/build_services_2021.py
python research/sgrt_word_completion_20261021/calibration/extract_admin_centers.py
python research/sgrt_word_completion_20261021/calibration/link_admin_centers.py
```

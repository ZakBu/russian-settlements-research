# Точный численный вход основного расчёта

Архив сохраняет точные байты четырёх файлов принятого кэша: разреженную матрицу полного времени поездки, порядок исходных пунктов, порядок потенциальных центров и квитанцию построения. Манифест указывает SHA256 каждого файла и каждой части. Время включает дорожный путь и принятые соединения точки с дорогой; это модельная доступность, а не наблюдённое время поездки.

Из корня репозитория:

```bash
python research/sgrt_word_completion_20261021/model/cycle07_scale_hierarchy/source477_numeric_cache_archive_v1/restore.py --verify-only
python research/sgrt_word_completion_20261021/model/cycle07_scale_hierarchy/source477_numeric_cache_archive_v1/restore.py --output /tmp/sgrt_restored_source477_cache
```

Первая команда проверяет все байты, ничего не создавая. Вторая создаёт точные файлы в отдельном каталоге; иной существующий файл не перезаписывается. Для восстановления требуется около321МБ свободного места. При частичном клонировании Git должен сначала получить файлы частей и указанные манифестом таблицы.

Матрица содержит77479271значение для155606исходных пунктов и26680маршрутизируемых потенциальных центров. Исходный полный реестр потенциальных центров шире: отсутствие маршрута не заменяется нулём. Все использованные элементы независимо побитово сопоставлены с расширенной исходной матрицей180838778пар: `reviews/cycle07_source_cache_numeric_independent/audit.json`.

Кэш переносим как набор точных байтов. Старые абсолютные пути внутри исторической квитанции описывают происхождение; они сами по себе не являются командами запуска на новой машине. Для нового полного запуска необходимо явно задать существующие входы и новый каталог вывода с сохранением проверок источников и конфигурации. Подробные команды и ограничения переноса перечисляются отдельно в `coordination/cycle07_reproduction/REPRODUCE_RU.md`.

# Аграрная структура документированного функционального фрагмента

Получен конкретный результат для Малоказаккулова и Уральска. Основа выделения — школьный акт2025 и официальная медицинская страница, а не районные административные границы. Ни одно муниципальное сельскохозяйственное число не распределено искусственно по СГРТ.

## Содержательный результат

1. В исходных официальных аграрных данных обнаружен **уровень сельсовета**, пропущенный прежним районным анализом. Амангильдинский сельсовет имеет16 строк, Уральский15 строк за2007–2009: посевы и скот в **хозяйствах населения**. Это не все категории хозяйств и не современная структура.
2. Малоказаккулово — центр **Амангильдинского** сельсовета. «Малоказаккуловский сельсовет» в этой связке было бы ошибочным названием. По перечню закона РБ№126-з сельсовет включает6 деревень, а школьный нижний фрагмент —3 из них: Малоказаккулово, Калуево, Амангильдино. Общий школьно-медицинский фрагмент подтверждён лишь для2: Малоказаккулово и Калуево. Это разные множества, они сохранены отдельно.
3. Старший школьный фрагмент включает названные3 деревни и Уральск. Он пересекает **два сельсовета**:3 из6 деревень Амангильдинского и1 из5 Уральского. Тем самым реальный документированный школьный контур уже не совпадает с единицей аграрной статистики.
4. На неподвижном наборе этих4 населённых пунктов RFSD даёт6 аграрных юридических лиц в2016 и4 в2021; все находятся в Уральске и имеют основной код группы01. В нижних3 деревнях точных свидетельств юрлиц по выбранным аграрным группам не обнаружено. **Это не отсутствие сельского хозяйства**: хозяйства населения и многие ИП в этой отчётности не представлены, филиалы не образуют полной отдельной сети. Как раз официальная сельсоветская статистика подтверждает значительный масштаб хозяйств населения.
5. При фильтре геокодирования `house` и расстояния≤5км число юридических свидетельств Уральска равно **2→2**, тогда как широкая кодовая версия **6→4**. Все4 сохранившихся ИНН наблюдаются в обоих годах. Два выпавших сигнала не дают доказательства закрытия хозяйств, утраты рабочих мест или перехвата функций большим центром. Таблица целевой проверки ищет их ИНН по всему исходнику2021, а не только внутри пилота.

## Crosswalk и полнота

`municipal_legal_membership.csv` содержит полный опубликованный перечень11 деревень двух сельсоветов.10 точно найдены в замороженной оси, **Кучуково-Маяк не найден** и не заменён похожим пунктом. Отсюда доля нижнего школьного фрагмента —3/6 мест сельсовета; её доля в **наблюдаемом** населении пяти найденных деревень равна559/893≈62,6%. Это не доля полного официального населения сельсовета. Для старшего школьного фрагмента распределение его2225 жителей2021 по двум сельсоветам равно559/2225≈25,1% и1666/2225≈74,9%. Это веса описания состава фрагмента, **не веса распределения аграрного производства**.

Перечень источника: закон Республики Башкортостан17.12.2004№126-з,ст2,ч1,п48б и48ц. Прочитан полный первичный нормативный текст, воспроизведённый на неофициальном правовом хосте: https://bash-pravo.ru/zakon/2004/12/17/n-126-z/ . Оригинальные полученные байты и SHA256 сохранены в `law126z.html` и `source_crosswalk.json`. Дата редакции страницы не установлена. Нынешний перечень и кодовые префиксы2021 не доказывают неизменность состава сельсоветов в2007–2009. Поэтому аграрные наблюдения остаются датированными муниципальными значениями. Нет ретроспективной подмены границ.

В raw есть8559473 строк верхнего муниципального уровня,272648 нижнего,629 субъекта РФ. Для обоих целевых сельсоветов доступна только ранняя группа2007–2009, для Учалинского района —3667 строк2006–2024. Покрытие показателей, категорий и лет опубликовано отдельно. Отсутствие более поздних сельсоветских значений **в этой выгрузке** не объявляется доказательством отсутствия иных первичных данных.

## Экономический слой

RFSD прочитан колоночными батчами после проверки схемы:2016 —5047775 строк;2021 —3412469. Отбор по точному11-значному ОКТМО населённого пункта, без ближайшего центра. Группы01,01.6,10,46.2,46.3,75 проверяются с согласованностью раздела ОКВЭД. Авторы RFSD сообщают гармонизацию ОКВЭД2011–2023: DOI https://doi.org/10.1038/s41597-025-05150-1 ; локальная первичная проверка `../literature_review/RFSD_OKVED_PRIMARY_CHECK.md`. Неоднозначные межклассификационные соответствия и основной код ограничивают детальное толкование.2016 сопоставлен с фиксированной кодовой осью2021: историческая идентичность кода и физического адреса каждой строки отдельно не доказана.

Числа — **зарегистрированные юридические свидетельства**, не фактические рабочие места, площади полей, выпуск продукции или внешние услуги. Отчётность организации не требуется быть ненулевой для фиксации её юридического свидетельства. Обнаруженные0 по переработке, оптовой торговле и ветеринарии означают0 точных свидетельств в данном слое, а не отсутствие соответствующих услуг. Подгруппа01.6 входит в01; эти столбцы нельзя суммировать. Нижний и верхний контуры вложены: их показатели также нельзя складывать как независимые территории.

## Воспроизведение

Из корня рабочей среды:

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python functional_dynamics_20261019/agriculture/build_functional_agriculture.py
python functional_dynamics_20261019/agriculture/summarize_crop_change.py
python functional_dynamics_20261019/agriculture/verify_outputs.py
```

Требуются Python, pandas,numpy,pyarrow и замороженные файлы по путям `AUDIT.json`. Первичные данные не изменяются. `--base` меняет корень входов, `--out` позволяет отдельный повторный каталог. Код пересчитывает полный batch-скан, а не использует ручные числа этого текста.

Основные результаты: `functional_municipal_crosswalk.csv`; `documented_scope_members.csv/.parquet`; `official_lower_municipal_context_2007_2009.csv`; `official_municipal_series.parquet`; `lower_municipal_profiles.csv`; `functional_agro_legal_aggregates.csv/.parquet`; `point_agro_counts_2016_2021.csv`; `agro_legal_witnesses_2016_2021.csv/.parquet`; `agro_identity_transition_2016_2021.csv`; `missing2016_2021_targeted_followup.csv`; `AUDIT.json`, `CHECKS.json`.

Таким образом, аграрный слой действительно присоединён к документированным контурам по точечным организациям и к их **проверенным отдельным муниципальным окружениям** по официальной статистике. Достоверное распределение хозяйств населения между выбранными деревнями и сравнение их сельхозпродукции как СГРТ не идентифицировано: данных о подеревенских хозяйствах/полях нет. Эта граница данных не восполняется произвольным коэффициентом.

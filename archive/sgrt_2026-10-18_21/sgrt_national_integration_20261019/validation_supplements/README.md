# Отдельная независимая проверка дополнений

Фактический запуск:

```bash
python national_integration_20261019/validation_supplements/audit_supplements.py
```

Результат — **PASS, 940 выполненных проверок**. Закрытый основной пакет `validation/` не изменён. В каждом чтении Parquet запрашивалось не более трёх колонок; основной 914-польный master целиком не читался.

Все 3005 исходных записей PickPoint сохранены, включая исходные поля и ID. Независимое соединение по нормализованному полному имени, региону и явному типу воспроизвело все решения: 2282 записи присоединены к 480 обычным UID, 505 отнесены к федеральным городским территориям, 121 неоднозначна, 97 не разрешены. Проверены все показатели слоя 142570×9 и отдельные федеральные счётчики. Геометрический ближайший пункт не использовался.

У всех 505 федеральных записей проверен сам адрес: в первых трёх сегментах явно присутствует соответствующий город. Москва — 356, Санкт-Петербург — 149. Исходные групповые заголовки «Московская обл.» и «Ленинградская обл.» сохранены; они согласованы с макроконтекстом, но сами по себе не использованы как доказательство принадлежности федеральному городу. Полная таблица — `pickpoint_all505_federal_address_audit.csv`. Проверка строки адреса не восстанавливает юридический полигон города или координаты пункта.

В расширенном файле проверены число строк 142572 и обе федеральные строки: значения переписей из шести исходных записей, отдельный территориальный статус, все native-поля как неизвестные NA, унаследованные федеральные RFSD-значения и все явные федеральные Places-счётчики категорий, статусов и сигналов имени. Places explicit: 124772 записи Москвы и 60449 Санкт-Петербурга. Результат — `independent_federal_places_explicit_counts.csv`. Значения всех обычных строк расширения заново не сверялись: это не полный повтор основной приёмки.

`AUDIT.json` содержит каждый результат, SHA входов и кода. Все записанные входы оставались неизменными за запуск. Проверка не превращает выбранное расписание одной партнёрской сети в полный рынок ПВЗ, разницу с WB2026 — в сопоставимую динамику, а совпадение адреса — во внешнее обслуживание или поток.

# Национальная мастер-таблица признаков

`feature_master.parquet` — по одной строке для каждого из 142 570 UID неизменной общей поселенческой оси. Это общая референтная когорта, а не перепись всех поселений каждого года. Все 64 исходных поля, исходные пропуски и нулевые значения населения сохранены без изменения. `feature_master.csv.gz` — текстовая копия для обмена; типизированный основной формат — Parquet.

Слои присоединяются слева по уникальному `id`: 15 лет зарегистрированных организационных свидетельств RFSD 2011–2025, их траектории, 21 секция экономики 2021/2025, отдельные условные кодовые соответствия/строгие режимы/финансовые показатели, опубликованные места доставки WB по каждому исходному типу, муниципальная аграрная статистика; при готовности — физические Places. Повторные общие столбцы экономики проверяются на точное равенство и не размножаются. Фактический размер последней сборки, SHA каждого входа, состав модулей и число присоединений — в `MASTER_AUDIT.json`; точная выполненная команда и время — в `ACTUAL_COMMAND_RECEIPT.json`.

Baseline, условные связи и ближайшие координатные кандидаты остаются разными столбцами. Технические/почтовые/нерасшифрованные WB-подтипы не превращаются автоматически в общедоступный ПВЗ. Внеосевые территории и федеральные города не приписываются соседним деревням. Значения аграрного района повторяются у его НП как контекст: складывать такие столбцы по поселениям нельзя. Число зарегистрированных организаций, выручка и расположение объекта не являются измерением рабочих мест, внешних посетителей или доказанным СГРТ. Ноль регистрационного/объектного свидетельства не означает отсутствия функции; при отсутствии пригодных финансовых отчётов сумма сохраняется NULL.

`feature_dictionary.csv` содержит по одной записи на поле с источником, исходной переменной/годом, уровнем свидетельства и единицами. `join_audit.csv` проверяет ключи, число строк, порядок и общие столбцы каждого присоединения. `coverage_audit.csv` разделяет годовое наличие свидетельств и полноту референтной оси.

`feature_master_extended142572.parquet` добавляет два ряда федеральных городских территорий с отдельным `axis_kind`, сохраняя обычные строки. Это иной территориальный носитель, а не ещё два сопоставимых сельских/городских НП. В федеральных рядах отсутствующие нативные RFSD-признаки остаются NULL; доступные исторические территориальные агрегаты 2016/2021 имеют собственные `econ_legacy_federal_*` поля. Их происхождение и единицы сохранены в `EXTENDED_MASTER_AUDIT.json` и `external_federal_features.csv`. Население разных территориальных носителей не объявлено строго сопоставимой национальной динамикой.

Запуск из корня рабочего пространства:

```bash
python national_integration_20261019/core/build_feature_master.py
python national_integration_20261019/core/build_extended_master.py
python national_integration_20261019/core/check_master_invariants.py
python national_integration_20261019/core/verify_master_reproduction.py
python national_integration_20261019/core/make_manifest.py
```

Первый скрипт использует готовые слои соседних каталогов. При отсутствии расширенной экономики, агро- или Places-модуля он выполняет доступную сборку и фиксирует состав в аудите; отсутствие root WB-пакета включает отдельно обозначенный исходный fallback. Новые исходные входы не перезаписываются. После изменения пакетов выполняется новая сборка и проверки, а не сохранение прежних чисел покрытия.

Каталог `results/` содержит только первый промежуточный прогон. Итоговые данные и актуальные аудиты расположены непосредственно в `core/`.

Федеральное расширение отдельно содержит опубликованные Places с явно указанным адресом Москвы/Санкт-Петербурга (`places_federal_explicit_*`) и геометрическую окрестность городского якоря (`places_federal_coordinate_core_*`). Эти маски не объединяются: координатная близость не является юридической территориальной принадлежностью. Современный объектный слой не восстанавливает функции в прошлые переписные годы.

Историческая массовая сеть PickPoint февраля 2021 года сохранена отдельным приложением `../services_pickpoint/`; она не изменяет замороженный основной master и не образует сопоставимого временного ряда с WB 2026.

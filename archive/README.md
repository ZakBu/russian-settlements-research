# Архив

Здесь лежат материалы прошлых проходов исследования. Они нужны, чтобы понимать, что уже пробовали, какие источники искали и почему от чего-то отказались. **Это не текущее состояние.** Многие выводы отсюда отменены или пересмотрены; числа из архива перед использованием перепроверяй. Текущее состояние описано в [README.md](../README.md), [POPULATION_BASE.md](../POPULATION_BASE.md) и [sgrt/README.md](../sgrt/README.md).

Тексты перенесены без правки, со своими датами и формулировками. Многие из них написаны тяжёлым внутренним языком агентов.

## Что здесь лежит

### `census_base_2026-10/` — история сборки базы населения (3–14 октября 2026 года)

Отчёты о том, как связывались переписи 2002, 2010 и 2021 годов. Отдельно — попытки добавить 1979 и 1989 годы: они не завершены, цель 100 тысяч НП для каждого года не достигнута. Сама база готова и описана в [POPULATION_BASE.md](../POPULATION_BASE.md). Методика и источники — в [docs/census_base/](../docs/census_base/). Здесь — только хронология работы.

- [reports/](census_base_2026-10/reports/) — отчёты отдельных этапов.
- [publication/](census_base_2026-10/publication/) — описания промежуточных выпусков базы (октябрь 2026). Данные этих выпусков — в соответствующих релизах GitHub.
- [STATUS.md](census_base_2026-10/STATUS.md) — хронологический журнал статуса.

### `sgrt_2026-10-18_21/` — прежние попытки выделить районы тяготения (18–21 октября 2026 года)

Несколько последовательных проходов, каждый в своей папке. **Их итог отвергнут**: 4 069 «районов» при едином часовом ограничении не являются реальными районами тяготения (почему — в [sgrt/README.md](../sgrt/README.md)). Полезное отсюда:

- **Поиск функциональных данных** — что искали, что нашли, что оказалось недоступным:
  - медицина: [functional_dynamics/medical](sgrt_2026-10-18_21/sgrt_functional_dynamics_20261019/medical/README.md), [word_completion/medical](sgrt_2026-10-18_21/sgrt_word_completion_20261021/medical/README.md);
  - образование: [word_completion/education](sgrt_2026-10-18_21/sgrt_word_completion_20261021/education/README.md), [word_replication/education](sgrt_2026-10-18_21/sgrt_word_replication_20261021/education/README.md);
  - торговля: [word_replication/commerce](sgrt_2026-10-18_21/sgrt_word_replication_20261021/commerce/README.md);
  - сельское хозяйство: [national_integration/agriculture](sgrt_2026-10-18_21/sgrt_national_integration_20261019/agriculture/README.md);
  - официальные реестры: [opornost/services](sgrt_2026-10-18_21/sgrt_opornost_20261019/services/SERVICE_EVIDENCE_REPORT.md).
- **Дорожная сеть и время в пути** — [transport](sgrt_2026-10-18_21/sgrt_word_completion_20261021/transport/README.md). Код построения дорожного графа 2021 года пригодится и новой модели.
- **Опубликованная маятниковая миграция** по Московскому региону — [typology_commuting_cases](sgrt_2026-10-18_21/sgrt_word_completion_20261021/typology_commuting_cases/README.md). Это кандидат для проверки функций затухания.
- **Итоговый отчёт прошлого расчёта** и записка для научного руководителя — [report_v2](sgrt_2026-10-18_21/sgrt_word_completion_20261021/delivery/cycle07_current_primary_v1/report_v2/SGRT_RESEARCH_REPORT.md). Читать как описание отвергнутого подхода.
- **Восстановление численности 2010 года** — [demography2010_recovery](sgrt_2026-10-18_21/sgrt_word_completion_20261021/demography2010_recovery/README.md).

### `side_studies/` — побочные исследования из незакрытых PR

Три работы, которые лежали в отдельных ветках в виде черновых PR и не были влиты. Их тексты и код перенесены сюда, а PR закрыты. PDF, DOCX, рисунки и таблицы — в архивном релизе (см. ниже).

- [settlement_context_2026-10-18](side_studies/settlement_context_2026-10-18/) — помогает ли контекст поселения (соседи, география) предсказывать его динамику. Итог: выигрыш маленький и неустойчивый (бывший PR #2).
- [geographic_regimes_stage2_2026-10-18](side_studies/geographic_regimes_stage2_2026-10-18/) — атлас изменений сети расселения 2002–2021 годов по регионам: концентрация, разрежение, ближайшее соседство (бывший PR #3).
- [settlement_progress_report_2026-10-21](side_studies/settlement_progress_report_2026-10-21/) — иллюстрированный отчёт «Трансформация территориальной структуры расселения России в 2002–2021 гг.» на 15 страниц (бывший PR #5).

## Удалённые материалы

При разборе 22 октября 2026 года из рабочего дерева убраны около 6 100 файлов. Из них примерно 5 750 — машинные выгрузки (JSON и CSV): промежуточные таблицы, расписки проверок, манифесты. Ещё около 340 — служебные тексты и скрипты агентов: протоколы приёмки, журналы прогонов, устаревшие копии отчётов, скрипты упаковки и самопроверки. Научных текстов среди удалённого нет. Полный список — в [removed_files.txt](removed_files.txt).

Ничего не потеряно. Вернуть удалённое можно так:

1. Скачать архив `removed-from-main-20261022.zip` из релиза [repository-archive-20261022](https://github.com/ZakBu/russian-settlements-research/releases/tag/repository-archive-20261022). Там все удалённые файлы с исходными путями, а также полные папки побочных исследований с PDF и рисунками.
2. Взять файл из Git по метке, поставленной на последнее состояние до разбора. Так можно вернуть только файлы до 1 МБ: крупные файлы данных убраны из истории Git (см. ниже), их берите из ZIP или из полной копии истории.

```bash
git fetch origin tag repository-archive-20261022
git checkout repository-archive-20261022 -- путь/к/файлу
```

## История Git

22 октября 2026 года история Git очищена от файлов больше 1 МБ, которых нет в текущем дереве: старых версий таблиц, архивов и карт. Объём истории уменьшился с 9,9 ГБ до 0,4 ГБ. Все коммиты, их сообщения, код и тексты сохранились, но хеши коммитов изменились. Соответствие старых и новых хешей — в файле `commit-map.txt` релиза [git-history-backup-20261022](https://github.com/ZakBu/russian-settlements-research/releases/tag/git-history-backup-20261022). Например, срез базы населения от 13 октября, который указан в каталогах данных как `source_commit` 85aebaff, теперь — коммит c2a1e28c.

Полная копия прежней истории со всеми ветками и данными лежит в том же релизе: шесть частей общим объёмом около 10 ГБ, инструкция по сборке — в описании релиза.

Рабочая ветка связывания переписей (`research/mass-linkage-2026-10-02`, 145 коммитов за 2–13 октября) сохранена меткой `census-linkage-work-2026-10-13`. Остальные ветки удалены. Их содержимое либо вошло в `main`, либо перенесено в этот архив, либо было промежуточной попыткой переупаковать репозиторий; все они есть в полной копии истории.

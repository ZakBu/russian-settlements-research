# Саратовская область: исходные данные первого прохода

Для областного пилота доступны **1 814 переписных точек 2021 года с принятыми координатами и дорожной привязкой**. Среди них 502 ранее опубликованных модельных центра с внешними участниками хотя бы по одной базовой функции. Это не число полных СГРТ: функции известны неполно, а фактические поездки не установлены.

## Состав основы

| Набор | Записей | Смысл |
|---|---:|---|
| Все межпереписные цепочки Саратовской области | 1 998 | Включают цепочки без записи 2021 года |
| Есть запись 2021 года | 1 821 | Население сохранено в исходном виде |
| Есть принятая пространственная точка | 1 814 | Основная точечная основа пилота |
| Есть запись 2021 года, но нет принятой геометрии | 7 | Отдельная таблица; исходная сумма населения —106 человек |
| Только историческая цепочка без записи 2021 года | 177 | Не выдаётся за современную точку |

Все 1 814 пространственных записей имеют допущенный дорожный конец в существующем графе. У 155 из них опубликован ноль населения; эти точки сохранены. У 111 опубликована численность, но не принят её аддитивный зачёт. Это не пропуски и не автоматически доказанные дубли.

В пространственном наборе опубликовано 2 442 469 человек; принятый аддитивный бюджет составляет 2 436 311 человек. Разница относится к учёту исходных записей и не заменяется нулями. Семь записей без принятой геометрии сохраняют ещё 106 опубликованных человек, которые не распределены по соседним точкам.

Пространственная основа включает 947 сёл, 399 посёлков, 215 деревень, 156 хуторов, 35 железнодорожных объектов, 25 пгт, 18 станций, 18 городов и одну запись типа «населённый пункт». Типы сохранены из принятого источника; не назначаются по численности.

Эти шесть якорей —начальная транспортная иллюстрация. Размер города не объявляется порядком системы; наличие якоря не доказывает тяготения окружающих НП. Пути считаются по полной сети, без обрезания административной границей области.

## Известные местные функции

В 1 814 пространственных НП собственная школа установлена у 169, базовая медицинская функция —у 926, продуктовый магазин —у 127. Это количество **населённых пунктов с установленной функцией**, не количество учреждений и не полный реестр области. У 269 из 926 медицинских свидетельств источник только исторический 2021 года; их нельзя автоматически объявлять действующими в 2026 году.

У 869 НП не установлена ни одна из трёх собственных функций; у 733 известна одна, у 147 —две, у 65 —три. Ноль в этом счётчике означает отсутствие установленных свидетельств собственного предложения в данном наборе, а не отсутствие услуг.

Из 502 опубликованных внешнеобслуживающих модельных центров 315 имеют одну известную собственную базовую функцию, 124 —две, 63 —три. Ещё два НП со всеми тремя функциями не входят в 502: наличие собственного обслуживания не доказывает внешней зоны.

Функциональные изохроны в дальнейшем нужно считать по подходящим физическим площадкам. Школа с координатами, но неразрешённой точной принадлежностью переписному НП, не должна пропадать из доступности только потому, что счётчик собственных функций удержан неизвестным.

## Источники и география

Код `scripts/sgrt_saratov/source_inventory.py` проверяет размер и SHA-256 каждого из 31 файла: принятую ссылочную таблицу переписей, текущие дорожные привязки, опубликованные центры и направления услуг, три части дорожного графа и 24 части координат его узлов. Файлы читаются из прежних неизменных публичных выпусков; полный список URL и имён внутри архивов находится в `references/provenance/saratov_isochrones_inputs_20261028.json`.

Для карт выделен один контур Саратовской области `r72193 / RU-SAR` из проверенного полного `RUS-adm1.geojson` выпуска `atlas-boundaries-20261026-v1`. Источник —Terrae/OpenStreetMap 2026.10, срез 28 сентября 2026 года, уровень medium с ориентировочной точностью около 150 м. Это контекст другой даты, не доказательство границы переписной совокупности и не маска воды.

Отдельной закреплённой гидрографической маски в локальных исходниках не найдено. Административный полигон нельзя подменять маской Волги. При первом отображении сетевой доступности дорожными коридорами мосты сохраняются, а связность определяется дорожным графом. Сглаженная оболочка точек не используется как доказательство достижимости всей заключённой территории.

## Выходные таблицы и повторение

`source_inventory.py` создаёт `region_reference.parquet`, `all_current_settlements.parquet`, `settlements.parquet`, `current_without_geometry.parquet`, `historical_only_chains.parquet`, `regional_function_evidence.parquet`, `centres.csv`, `saratov_boundary.geojson` и `summary.json`. `all_current_settlements.parquet` содержит все 1 821 текущую запись для знаменателя дорожных таблиц; у семи строк без принятой геометрии координаты и дорожные поля остаются неизвестными, время не заменяется нулём. Функциональные поля у этих семи строк также неизвестны, а не равны нулю. Число 1 814 не скрывает остальные записи: обе исключённые группы сохраняются отдельно с исходными ID.

Аргументы CLI —`--input-root` для логических путей каталогов, `--road-nodes` для 24 исходных частей координат, `--output` для отдельной папки результатов. Без `--boundary-source` полный проверяемый контур регионов считывается по закреплённому HTTPS; с этим аргументом допускается только тот же полный исходник с тем же SHA. База населения и прежние научные выпуски не изменяются.

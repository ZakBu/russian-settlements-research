# Российские пути: что удалось проверить

Исключение 23 исходных дорожных отрезков, не целиком лежащих в принятом контуре России, не изменило время ни для одной из 29 803 точно проверенных пар «НП — НП». В них участвуют 570 исходных переписных пунктов, включая 536 с положительным населением 2021 года. Для 180 из 511 кандидатов проверен хотя бы один путь; это не означает полной проверки их окружений или признания 180 установленных центров.

Проверены исходные дороги 2021 года, а не только обрезка рисунка. Из 242 296 направленных дуг осталось 242 250. Минимальные стоимости параллельных дорог определены заново после фильтрации; направления движения сохранены. Прямые соединения точки НП с дорожной вершиной также не должны пересекать исключённую территорию.

## Почему частичной сети достаточно для части выводов

Сначала по исходным геометриям воспроизведены все 158 140 сохранённых оценок времени до шести опорных пунктов. Они совпали точно. Внутри обоснованных временных окон дополнительно совпали 4 547 ячеек исходной полной матрицы; максимальная разность — 1,1×10⁻¹³ минуты.

Для нового российского пути используется простое неравенство: **L ≤ t ≤ U**. Здесь L — прежний минимум по полной сети без ограничения страной, t — искомый минимум внутри контура, U — время найденного допустимого российского пути. Если L и U совпали с точностью 10⁻⁷ минуты, минимум установлен даже при отсутствии полной сети в памяти. Неизвестные обходы не могут сделать российский минимум меньше прежнего неограниченного минимума.

Второе обоснование даёт полное временное окно. Для вершины назначения c и одного из шести опорных пунктов a известна прежняя стоимость A(c,a), включая соединение опорного пункта с дорогой. Любой путь к c с дорожной стоимостью не более 60−A(c,a) остаётся в сохранённом 60-минутном окне a. Для общей стоимости НП—НП добавляется соединение назначения с дорогой. Это достаточное условие полноты вычисления, а не радиус обслуживания. У всех 29 803 опубликованных точных результатов сработало также независимое от этого условия совпадение нижней и верхней оценок.

Из 103 740 рассмотренных пар для 73 521 доступной сети не хватило; ещё для 416 найден только допустимый путь с верхней оценкой времени. Они не названы недоступными или изолированными. В исходных дорожных окнах Питерки и Новоузенска исключены соответственно 11 и четыре вершины вне контура. Все 158 125 оценок времени для вершин внутри контура сохранились. Это оценки по шести направлениям, а не 158 125 различных вершин.

## Три школьных расхождения

Проверены оба направления для Доронкина, Первопитерского и Шлягина — к закреплённому месту и к месту выбранного моделью поставщика. Все шесть российских путей совпали с прежними минимумами между точками НП. Для каждого сохранена исходная геометрия дороги и проверена сумма её времён. Это пути до точки населённого пункта, а не обязательно до школьного здания.

| Откуда | Закреплённая местность, мин | Выбранная моделью местность, мин | Разница, мин |
|---|---|---|---:|
| Доронкин | Питерка — 52,8 | Агафоновка — 50,9 | 1,9 |
| Первопитерский | Агафоновка — 17,3 | Запрудное — 16,7 | 0,6 |
| Шлягин | Нива — 29,8 | Агафоновка — 25,6 | 4,2 |

Зарубежный транзит на уровне этих местностей расхождения не объясняет. Необходимо проверять ступени обучения, фактические площадки, правила приёма и подвоз. Прежние стоимости до физических поставщиков сохранены отдельной колонкой и не заменены стоимостью НП—НП.

## Насколько устойчив выбор ближайшей услуги

Отдельно разобраны прежние стоимости до физических поставщиков из выпуска v2. Взяты жилые НП без известной собственной функции и с конечной первой стоимостью: 1 477 школьных, 733 медицинских и 1 525 торговых направлений. Разница до следующего известного места имеет медиану соответственно 7,9, 5,4 и 9,7 минуты. Нижние децили — 1,1, 0,9 и 1,3 минуты. Это описывает точечную модель выбора, не поездки жителей и не доказанное отсутствие местных услуг.

Половина разницы Δt/2 — лишь граница, при которой разнонаправленные ошибки двух оценок могут поменять их порядок. Это не измеренная ошибка и не доверительный интервал. Общая ошибка одного и того же начального соединения дороги может сокращаться при вычитании. Новых порогов отбора центров или коэффициентов затухания по этим числам не назначено. Часть физических поставщиков не имеет принятой связи с НП; они не приписаны ближайшему селу.

## Состав и повторение

Основной файл — `np_route_comparison.parquet`: известные нижние оценки, найденные верхние оценки, точные значения и причины неполноты хранятся раздельно. `school_case_domestic_paths.geojson` содержит шесть дорожных путей; `school_locality_route_checks.csv` — все внешние школьные проверки. `service_choice_margins.parquet` и сводный CSV описывают прежний выбор поставщиков. Мелкие таблицы и JSON читаются без повторного моделирования; крупный CSV не дублирует Parquet в выпуске.

Код: `scripts/sgrt_saratov/domestic_routes.py`. Публикационный исполнитель `cloud_domestic_routes.py` получает только нужные файлы по неизменным каталогам v2 и изохрон. Все входы сверяются по SHA; исходная переписная основа и прежние выпуски не меняются. Команда пересчёта при наличии входов:

```bash
python -m scripts.sgrt_saratov.domestic_routes --source INPUT --boundary RUS-adm1.geojson --output OUTPUT
```

Граница — закреплённый картографический контур, не точное юридическое описание. Общероссийская сеть и все направления к физическим учреждениям ещё не пересчитаны. Ближайший приоритет — проверка подходящего предложения и альтернатив, а не подгонка числа центров.

# Фактические медицинские адреса по всей стране

**Получен официальный федеральный справочник адресов оказания медицинской помощи с положительными адресными привязками во всех 85 регионах исследовательской основы.** Это адреса мест оказания помощи, а не юридические адреса головных организаций. Они позволяют существенно расширить прежние региональные сведения. Клинический вид помощи устанавливается отдельным соединением со справочниками подразделений и профилей; один адрес сам по себе не объявляется ни ФАПом, ни больницей.

**Итог строгого сопоставления:** 130 244 из 152 294 действующих адресных строк связаны с 37 128 различными НП/городскими контекстами. Адресные свидетельства получены во всех 85 регионах. Остальные строки сохранены с причинами неопределённости; это не отсутствие медицинской помощи.

## Источники и независимая проверка

Основной источник — опубликованный [ТФОМС Ставропольского края пакет НСИ](http://www.xn--j1adfnaco.xn--p1ai/informatizatsiya-v-sfere-oms/nsi/), архив `http://www.xn--j1adfnaco.xn--p1ai/files/nsi/SpravNSI.zip`, дата справочников 23.10.2026. Код подготовки и контрольные суммы полного архива ведёт `scripts/sgrt_zero/medical_regional_sources.py` и сопроводительная документация этого набора. Из справочника F038 используются `IDADDRESS`, `UIDMO`, `UIDSPMO`, `ADDR`, `ADDR_GAR` и интервалы действия записей. На 23.10.2026 выделены **152 294 действующие пары «подразделение — адрес», 86 430 идентификаторов адресов**. Количество пар не равно количеству учреждений: подразделения могут находиться по одному адресу.

Независимый источник — [официальная страница классификаторов ТФОМС Ростовской области](https://rostov-tfoms.ru/dokumenty/klassifikatory), файл [F038_XML.zip](https://rostov-tfoms.ru/documents/nsi/klassifikatory/F038_XML.zip). Получен HTTP 200; 5 482 347 байт, SHA-256 `1e8ae114f34f3982df72896611411c4eae367fbad9f26bc9155b0a2f3fed66ba`. Внутри F038.xml: 60 774 417 байт, версия 4.498, дата 23.10.2026. Сообщение страницы об ошибке формирования не означало отсутствия фактически доступного файла.

Ростовский файл содержит **146 729 действующих пар**. Все они есть в ставропольском наборе; у последнего дополнительно 5 565 пар. Для общих пар `ADDR_GAR` совпадает полностью, буквальные адреса различаются в девяти случаях. Поэтому зеркало независимо подтверждает основную часть адресного массива, но одинаковая дата на страницах не делает выгрузки идентичными. Наборы не объединяются автоматически. При разборе расхождений восемь различий относятся к кодировке элементов внутри помещений; девятое — к адресу вне принятого территориального состава исследования.

## Как привязывается населённый пункт

`scripts/sgrt_zero/federal_medical_addresses.py` сопоставляет только буквальный фактический адрес F038. Нужны явный регион и компонент населённого пункта с совместимым типом. При одноимённых НП учитывается явно названный район; неразрешённые совпадения остаются неизвестными. Привязка не использует размер населения, число профилей помощи или ближайшую точку. Юридический адрес организации не подставляется вместо фактического.

Три особенности проверены отдельно: «Ямало-Ненецкий» не создаёт второго региона «Ненецкий»; название улицы не становится названием НП; конкретный локальный НП в адресе внутри федерального города имеет приоритет перед общим городским контекстом.

Идентификаторы сохраняются строками с ведущими нулями. `IDADDRESS`, `UIDSPMO` и `source_record_row` обозначают исходные адресные записи; `source_record_id`, `census_source_record_id_2021` и `provider_settlement_id` — один и тот же идентификатор НП переписи 2021 года.

Для 35 непустых идентификаторов `ADDR_GAR` разные буквальные адреса привели к разным строго установленным НП; затронуты 104 адресные строки. Противоречие помечено `gar_multiple_literal_np_conflict`, буквальная принадлежность сохранена. Такой GAR нельзя автоматически использовать для геокодирования или перепривязки всех соответствующих подразделений.

 Координаты учреждения из адреса не выводятся. Выход имеет `physical_coordinates_observed=False` и `default_external_seed_eligible=False`: известное наличие учреждения внутри НП допустимо учитывать как местное предложение, но фиктивная точка в центре НП не должна незаметно удешевлять дорогу соседним деревням. Использование представительной точки НП для внешней доступности потребует отдельного явно названного приближения.

Это реестр участвующих в ОМС мест оказания помощи, а не доказательство полноты всей медицинской инфраструктуры. Запись в реестре не подтверждает фактическую работу каждого специалиста, вместимость или наблюдённые поездки пациентов.

## Повторение

Сначала воспроизводится датированная выборка действующих F038 из замороженного официального архива. Затем:

```bash
python scripts/sgrt_zero/federal_medical_addresses.py \
  --source INPUTS/F038_current.parquet \
  --reference INPUTS/analysis_reference.parquet \
  --output OUTPUTS/medical_addresses

python scripts/sgrt_zero/federal_medical_addresses.py \
  --source INPUTS/stav_F038_current.parquet \
  --compare-source INPUTS/rostov_F038_current.parquet \
  --output OUTPUTS/mirror_comparison

python -m unittest discover -s tests -p test_sgrt_zero_federal_addresses.py
```

Выходы: `F038_current_np_identity.parquet`, `F038_np_coverage.csv`, `address_identity_summary.json`. Сверка зеркал отдельно сохраняет полный перечень пар и расхождений. Все неустановленные адресные соответствия остаются в таблице с объяснением причины. Пройдены 16 адресных тестов, включая противоречивый GAR, ведущие нули, одноимённые НП и запрет подстановки юридического адреса.

# Нулевой уровень обслуживания и переход к более крупным системам

В этом проходе населённые пункты объединяются по общему набору ближайших повседневных услуг. Размер города не даёт ему преимущества: Саратов, Новоузенск и Питерка начинают с одного порядка. Расчёт и независимые проверки продолжаются; окончательный комплект этого прохода ещё не опубликован.

Включены медицина из официальных реестров и OSM, школы и другие образовательные объекты, продуктовые магазины, пункты выдачи разных операторов. У источников разные даты: магазины OSM относятся к2021, большая часть медицинских и образовательных точек — к2026; свежие открытые ответы карт выдачи сохраняются отдельными файлами. Сведения о наличии услуги и её отсутствии в нашей базе различаются.

Основные населённые пункты прежней базы сохранены:153 800 точек. Москва, Петербург и Севастополь включены отдельными городскими ориентирами с внешними координатами. Их население не прибавляется повторно к переписному итогу. Все85 субъектов принятого справочника участвуют в обследовании; это не утверждение о полной сети учреждений в каждом из них.

Небольшие группы сохраняются при проверке более редких услуг. Дальние обращения остаются в исходных направлениях. Отсутствие автомобильной дороги означает ограничение сведений о поездке, а не независимость поселения. Высшие объединения проверяются по доступности и отдельному внешнему модельному слою городских агломераций2015 года. Он не выдаётся за наблюдённые поездки россиян.

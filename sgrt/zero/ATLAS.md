# Атлас нижних систем обслуживания

Атлас показывает фактически рассчитанные группы НП и направления к поставщикам услуг. **Одиночный НП, недостаточно известная связь и группа из нескольких населённых пунктов считаются раздельно.** Цвет на главной карте обозначает состояние каждого НП; центры отмечаются дополнительными звёздами. Обслуживаемые деревни больше не оставляются серыми лишь потому, что сами не являются центрами.

Код: `scripts/sgrt_zero/atlas.py`. Результат — 12-страничный `zero_level_atlas.pdf`, отдельные PNG и `atlas_manifest.json` с SHA входов, параметром выбранного источникового варианта, точными числами страниц и проверкой неизменности таблиц во время отрисовки. До получения законченных таблиц национального расчёта окончательный атлас не выпускается.

## Страницы

1. Нулевой уровень по стране: многопоселенческие группы, собственные услуги, близкий вариант без общей группы, только дальний вариант, невосстановленный автопуть и нехватка сведений. Звёзды центров накладываются отдельно: поставщик одной услуги может сам обращаться в другой НП.
2. Все 85 субъектов: доля расчётных НП с адресно известными медицинскими, образовательными и торгово-сервисными сведениями. Это представленность данных, не доля реально обслуженных жителей. Физические объекты с неизвестным НП не выдают за адресно установленные.
3. Сколько НП относится к каждому состоянию; дальняя найденная связь сохраняется отдельно от отсутствия данных.
4. Размеры групп с отдельными колонками одиночных и недостаточно известных записей; географический размер между точками НП.
5. Описательные типы и динамика 2002–2021 для групп с сопоставимыми данными у всех участников. Причинные типы Word не выводятся автоматически.
6. Саратов и Энгельс, Новоузенск, Питерка на одном нижнем уровне. Население не усиливает притяжение города. Увеличения карты не задают радиус расчёта и не обрезают состав групп.
7. Четыре повседневные функции в одном окне Саратова и Энгельса. Пунктир — направление к поставщику, не трасса дороги. Неразрешённая принадлежность объекта к НП сохраняется.
8. Реально выполненные попытки укрупнения по дополнительным функциям. Считаются новые объединения, а не новые номера для прежних групп.
9. Саратов и Энгельс выше повседневного обслуживания; другие местные группы не исчезают из данных.
10. Москва и Петербург рядом с внешней оценкой eFUA GHSL/JRC за 2015 год. Эта граница относится к другой модели и другому времени, не является наблюдением российских трудовых поездок и не выдаётся за самостоятельно найденную нами границу.
11. Распределения стоимости автомобильного пути по функциям. Отсутствующие маршруты учитываются отдельно; дальний хвост не превращается в радиус местной системы.
12. Районный профиль посевов и география известной части работников организаций. Районные площади не распределяются по деревням; частичная численность работников не называется полными рабочими местами.

## Что означает цвет

Классы главной карты взаимоисключающие только для удобства отображения. Приоритет: участник многопоселенческой группы; наличие собственной близкой услуги; иной принятый близкий вариант; только дальний найденный вариант; невосстановленный автомобильный путь; недостаточно сведений. Полные состояния всех функций сохраняются в исходных таблицах.

Серые точки означают недостаточность сведений для показанной близкой связи. В дополнительных картах, где выбран отдельный город или услуга, серый фон обозначает остальные НП — это поясняется отдельно. Цветные точки и прямые пунктирные отрезки не являются сплошными границами районов.

Объект OSM без установленной принадлежности к НП остаётся физическим объектом. Если известны координаты школы, маршрут идёт к школе; соседняя деревня не получает учреждение в собственность автоматически. Известная собственная функция НП может сохраняться и без подходящего автомобильного пути наружу.

## Повторение

```bash
python scripts/sgrt_zero/atlas.py \
  --root ZERO_OUTPUT \
  --hierarchy ZERO_OUTPUT/hierarchy/daily_20_school30_wb \
  --scenario daily_20_school30_wb \
  --output ZERO_OUTPUT/figures
```

Нужны `context/analysis_reference.parquet`, выбранные таблицы `level0_units`, `level0_memberships`, `daily_edge_evidence`, поселенческие предложения трёх сфер и фактически полученные таблицы более высоких шагов. Если в папке есть несколько источниковых вариантов, параметр `--scenario` обязателен. Код не выдаёт региональную подвыборку за неизвестность по всей стране.

Медицинское покрытие читается из `health/public_scope_corrected/np_supply.parquet`, если исправленный перечень имеется. Исходный замороженный медицинский набор не изменяется. Два хозяйственных Parquet скопированы из прежнего опубликованного комплекта без изменений; их исходный релиз, логический путь, размеры и SHA записаны в `context/context_sources.json`. Границы внешней оценки 2015 года и их роль также записаны в метаданные атласа.

Функции кода классификации карты проверяются отдельно: обслуживаемая деревня не становится неизвестной точкой; известная собственная услуга не стирается при отсутствии автопривязки; дальний вариант не смешивается с неизвестностью; близкий объект с неподтверждённой пригодностью не называется дальним.

# Ближайшая подходящая услуга: исправленный исходный расчёт

**Сельское учреждение больше не конкурирует с суммой однотипных городских объектов.** В `scripts/sgrt_local/assignment.py` каждый населённый пункт рассматривается отдельно по каждой конкретной услуге. Выбирается ближайшее известное место её предоставления. Это исходный сценарий потенциальной доступности, а не доказанные поездки, распределение учеников или готовая иерархия СГРТ.

Школа, предоставляющая начальное образование, не становится поставщиком старших классов по одному слову «школа». ФАП не становится поставщиком специализированного лечения. Более редкая услуга создаёт отдельную связь и не удаляет местную связь по базовой услуге. Состав подходящих поставщиков и их даты определяются по источникам до расчёта; программа не выводит порядок услуги из населения центра.

## Что делает программа

- Принимает исходные НП (`source_record_id`), места деятельности (`provider_id`, их `source_record_id`), точные коды услуг (`service_code`) и затраты пути к этим местам (`origin_id`, `provider_id`, `cost_minutes`). Названия и размеры центров не участвуют в выборе.
- По умолчанию допускает только наличие услуги со статусом `observed`. Косвенный признак `proxy` включается только отдельным параметром чувствительности. Неизвестность (`unknown`) и подтверждённое отсутствие (`confirmed_absent`) сохраняются раздельно.
- Сохраняет все известные допустимые альтернативы. При равных временах не выбирает центр по имени или численности: сохраняет несколько равноправных кандидатов и отсутствие единственного выбора.
- Для известной услуги внутри того же НП, если маршрут вообще не представлен, допускает отдельное нулевое время на уровне НП (`same_settlement_zero_assumption`). Это предположение о совместном расположении, не измерение поездки внутри города или села. Явно записанное неизвестное время не заменяется нулём. Для анализа крупного города нужен уровень зданий и внутригородские маршруты.
- Не устанавливает российского радиуса обслуживания. Ограничение времени можно передать только как явно названный сценарий. Отсутствующая запись маршрута остаётся отсутствием сведений, а не доказанной недоступностью.
- Сохраняет опубликованную общую мощность учреждения (`capacity_total`) и её неизвестность. **Мощности не распределяются**, наличие свободных мест не рассчитывается. Числовая общая мощность не равна свободной мощности; неизвестная не считается ни нулевой, ни бесконечной. Любой выбранный поставщик остаётся кандидатом с неоценённой возможностью принять конкретный спрос.

Таблица нормативных прикреплений не подаётся в этот расчёт как истинный выбор. Она хранится отдельно с собственным видом доказательства и используется для содержательного сопоставления. Все модельные строки имеют `evidence_kind=modeled_nearest_known_eligible`, `established_flow=False`. Даже точное совпадение с нормативной связью не превращает её в наблюдённый поток.

Ближайшая известная услуга может оказаться далёкой из-за неполного списка. Поэтому сохраняются признаки неизвестного местного предложения и неполного множества поставщиков. Они не устраняются одним выбором ближайшего. Если в источнике нет подходящей услуги или допустимого времени, результат остаётся неопределённым.

## Запуск и выходы

```bash
python scripts/sgrt_local/assignment.py \
  --origins origins.parquet --supply supply.parquet --costs costs.parquet \
  --services school_primary,school_upper,medical_primary,medical_specialist \
  --output RESULTS
```

Коды услуг в примере — имена для интерфейса, не универсальный справочник медицинских компетенций. Даты входных таблиц и допустимость сопоставления разных дат задаются и описываются исследователем. Скрипт не переносит современные учреждения назад во времени.

`assignments.csv/.parquet` содержит одну строку на сочетание НП и услуги. `candidates.csv/.parquet` сохраняет альтернативы, источник предложения при наличии этих полей во входе, время и основание его получения. CSV и Parquet содержат одинаковые логические результаты. Нужны pandas, numpy и pyarrow из `requirements-sgrt-pilot.txt`.

## Проверка механизма и предел метода

16 регрессионных тестов воспроизводят существенные ошибки прежней постановки: сто городских школ не вытесняют местную; неподходящая специальность не закрывает потребность; неизвестная функция не объявляется отсутствующей; дополнительная специализированная связь не стирает базовую; равные времена не маскируются единственным выбором; неизвестный маршрут не становится измеренным нулём.

```bash
python -m unittest discover -s tests -p test_sgrt_local_assignment.py -v
```

Тесты проверяют устройство алгоритма, не достоверность реальной сети учреждений. Для внешней проверки нужны первичные списки услуг и мест деятельности, прикрепления, маршруты подвоза или обследования. Ограниченное время поездки, нормировка по центрам и красивые границы сами по себе такой проверкой не являются.

Методическое основание — различение конкретных услуг, вложенности и ограничений мощностей в TAO2020_H2SFCA; переменных сельских и городских ареалов в MCGRAIL2012. Их методы потенциальной доступности не объявляются источником готового российского правила выбора. Сам nearest eligible baseline и правила обработки неопределённости — наше исследовательское решение, изложенное также в [предыдущем разборе](../pilot/LOCAL_SERVICES_AND_ECONOMY.md).

## Что добавило повторное чтение литературы

Вновь получены полные HTML статей Tao et al. (2020) и McGrail (2012); прочитаны выбранные разделы, не вся библиография. Tao et al., раздел о hierarchical location-allocation models, объясняют: ближайшее учреждение — упрощённая постановка, которая сама не учитывает конкуренцию потребителей за ограниченные возможности. Раздел о пространственной доступности описывает два шага отношения предложения к потенциальному спросу. Это отношение нельзя читать как свободную мощность или поток посещений. В классификации иерархических систем отдельно различаются вложенность услуг и обязательность единого старшего центра: это два разных свойства.

McGrail, раздел о переменных ареалах, описывает три контекста: городские услуги главным образом обслуживают местное окружение; пригородные и более крупные сельские узлы могут обслуживать более широкую территорию; малые сельские услуги обычно не притягивают жителей соседнего крупного центра, если у тех достаточно местного обслуживания. Это содержательное основание отказаться от одинаковой конкуренции всех учреждений. Оно не задаёт для России готового радиуса или запрета связи по размеру НП. В статье также разбирается расширение поиска при низкой местной обеспеченности; без наблюдённой обеспеченности такой переход остаётся гипотезой.

Для будущей модели распределения потребностей требуются совместимые единицы: учащиеся определённой ступени и места обучения; обращения за период и время медицинского персонала; потребность в стационарном лечении и койко-дни. Нельзя вычесть всех жителей города из числа школьных мест либо считать десять стационарных коек мощностью первичного приёма. Если известны спрос D и мощность C, распределение f по допустимым связям должно удовлетворять ограничениям Σᵢ fᵢⱼₖ ≤ Cⱼₖ и Σⱼ fᵢⱼₖ ≤ Dᵢₖ для каждой услуги k. Остаток спроса сохраняется отдельно. Эти ограничения — предлагаемое развитие модели; в настоящем baseline объёмы f и остатки спроса не оцениваются. Они требуют независимого определения допустимых связей: разрешение всем ехать три часа вновь создаст искусственно огромные зоны.

# Как проверять многомасштабное поле расселения

Литература поддерживает сравнение пространственных концентраций на разных масштабах, но **не даёт основания заранее строить дерево, в котором малые центры только исчезают и объединяются**. Даже математическая диффузия на графе может увеличить число локальных максимумов. Поэтому пилот должен наблюдать изменения поля, а не производить заданную иерархию. Поле населения и поле доступности услуг отвечают на разные вопросы; ни одно само по себе не доказывает поездок жителей.

Записка подготовлена 28 октября 2026 года для проверки принятой пользователем концепции. Она не объявляет новые эмпирические уровни России. Объём прочтения и точные версии источников указаны в [реестре этого прохода](../../references/provenance/field_literature_20261028.json). Полные тексты чужих работ в Git не добавлены.

## Что именно подтверждает литература

### Дорожное поле нельзя заменять интерполяцией между городами

Кузьмин и соавторы, 2023, DOI [10.5194/isprs-archives-XLVIII-1-W2-2023-347-2023](https://doi.org/10.5194/isprs-archives-XLVIII-1-W2-2023-347-2023), показывают на российско-казахстанском приграничье различие между вычислением потенциала на регулярной сетке и интерполяцией значений, рассчитанных только в поселениях. Во втором случае возникают ложные местные минимумы. Проверены полный шестистраничный текст, формулы 1–4, описание данных и рисунки 2–4; источник уже зарегистрирован как `KUZMIN2023_FIELD_GRID`.

У авторов 422 наиболее населённых поселения с людностью 2017 года. Дорожная величина — геометрическая длина кратчайшего маршрута, а 50/300 км в формуле 4 — предположения, не оценённые по поездкам. Полная статья не выделяет функциональные уровни центров по устойчивости максимумов.

Для нас это основание **вычислять поле непосредственно в выбранных точках**, а не рисовать непрерывную поверхность произвольной интерполяцией. Пилот только в точках НП допустим как дискретный пилот; его нельзя называть исследованием всех максимумов непрерывной территории. Если сетка присоединяется к дороге, необходим учёт соединительного участка и непроходимых барьеров.

### Увеличение масштаба не гарантирует уменьшения числа пиков

Линдеберг, 1990, DOI [10.1109/34.49051](https://doi.org/10.1109/34.49051), различает свойства одномерного и двумерного пространства масштабов. В авторской версии прочитаны постановка, определения дискретного сглаживания и разделы 8–9; это не заявление о проверке всех доказательств статьи.

В разделе 8, с. 17–18 авторской версии, приведён механизм появления нового максимума при двумерной диффузии: узкий гребень между двумя широкими возвышенностями размывается раньше самих возвышенностей. Число пиков может увеличиться. В разделе 9 используется более слабое условие: значение уже существующего локального максимума при диффузии не возрастает, а локального минимума — не уменьшается. Это **не** утверждение о монотонном числе максимумов.

Наш вывод: исчезновение, возникновение и смещение пиков следует сохранять в результатах. Нельзя искусственно прикреплять каждый новый пик к одному прежнему центру ради дерева. Свойства регулярной решётки также не переносятся без доказательства на дорожный граф.

### Сетевая экспонента и диффузия — разные модели

Shuman et al., 2013, DOI [10.1109/MSP.2012.2235192](https://doi.org/10.1109/MSP.2012.2235192), рассматривают обработку сигналов на взвешенных графах. Прочитаны разделы II–III, пример 3 и обсуждение ограничений в разделе V открытой авторской версии arXiv:1211.0053; остальные приложения не заявлены прочитанными целиком.

Для неориентированного графа с симметричными весами `W` ненормированный лапласиан имеет вид `L = D − W`. В примере 3 распространение сигнала задаётся матричной экспонентой `u(τ) = exp(−τL) P`. Она учитывает структуру графа через оператор, а не только кратчайшие пути. Величина `τ` — параметр диффузии; это не дорожные минуты. Выбор нормированного или ненормированного оператора меняет интерпретацию.

Следовательно, наша запись `V_h(i) = Σ_j P_j K_h(c_ij)` с `K_h(c)=2^(−c/h)` — **не эта диффузия**. У неё нельзя заимствовать свойства сохранения массы или пространственного сглаживания без отдельной проверки. Для первого пилота достаточно прямо назвать её суммарным сетевым потенциалом.

### Выраженность пика и устойчивость по масштабу различаются

Edelsbrunner, Letscher, Zomorodian, 2002, DOI [10.1007/s00454-002-2885-2](https://doi.org/10.1007/s00454-002-2885-2), определяют устойчивость топологических признаков через их появление и исчезновение во вложенной последовательности комплексов. Прочитаны разделы 1–3 и начало раздела 4 журнальной версии, с. 511–521; экспериментальные приложения полностью не разбирались.

Для нашего пилота возможна отдельная адаптация: **при фиксированном `h`** понижать порог значения поля и отслеживать слияния связных компонент надпорогового графа. Разность высоты пика и уровня его соединения с более высоким пиком характеризует его выраженность. Такая адаптация к нашему графу — наше решение, не готовая модель расселения авторов.

Эта последовательность по **порогу поля** не тождественна последовательности по **ширине затухания `h`**. Большая выраженность пика не является доказанным рангом города; результаты зависят от графа соседств и обработки плато. Если этот расчёт не выполнен в текущем коде, его нельзя указывать среди реализованных методов.

### Сетевая плотность — ещё один, отдельный объект

Okabe, Satoh, Sugihara, 2009, DOI [10.1080/13658810802475491](https://doi.org/10.1080/13658810802475491), показывают, что наивные переносы ядерной оценки плотности на сеть могут завышать оценки около узлов. Проверены издательская аннотация и библиография. Полный текст получить не удалось; индексируемая университетская ссылка на препринт возвращала 404. Формулы исправленных ядер не объявляются прочитанными или реализованными.

Для нас это предупреждение о необходимости определить оцениваемую величину. **Потенциал доступности населения не является оценкой плотности событий на единицу длины дороги**. Поэтому результат о смещённой сетевой плотности нельзя автоматически объявлять доказательством ошибки нашего потенциала. Но нельзя и называть простой потенциал несмещённой сетевой плотностью.

## Сопоставимые варианты потенциала для пилота

Ниже — наши проверяемые проектные решения, а не коэффициенты, оценённые перечисленными авторами для России.

Пусть `P_j` — исходная людность НП, `c_ij` — известная дорожная стоимость в минутах, `h` — сценарное время уменьшения веса вдвое. Для сравнения формы при одинаковом полувесовом времени пригодны:

```text
K_exp(c;h)   = 2^(−c/h)
K_gauss(c;h) = 2^(−(c/h)^2)
K_power(c;h) = [1 + (sqrt(2)−1)c/h]^(−2)
```

Во всех трёх случаях `K(0)=1`, `K(h)=1/2`, значения конечны и неотрицательны. Равенство при `h` не делает одинаковыми суммарные дальние вклады. Набор `h` описывается до просмотра желательной карты и не объявляется порядками городов.

Для каждой комбинации сохранять:

```text
V_h(i)          = Σ_j P_j K_h(c_ij)
V_h_external(i) = V_h(i) − P_i K_h(0)
self_share(i,h) = P_i K_h(0) / V_h(i), если V_h(i)>0
```

Второе поле — диагностическое исключение собственного вклада, **не обязательная замена** полного потенциала. Оно отвечает на вопрос о внешнем окружении; полное поле описывает собственную и окружающую концентрацию. Для функционального поля вместо `P_j` нужна измеренная характеристика предложения конкретной услуги, а спрос и контингент пользователей учитываются отдельно.

Потенциал с безразмерным ядром измеряется в условно взвешенных людях. Сумма его значений по точкам расчёта не равна населению территории: один исходный НП влияет на много точек. Нормировка вкладов каждого источника до единицы создаёт другую модель и не должна вводиться скрытно.

## Что считать максимумом и что проверять

В дискретном пилоте понятие максимума требует явного графа соседств. Нельзя называть каждый НП, превосходящий сам себя, отдельным пиком. Сохраняются выбранное правило соседства, число соседей и наличие изолированных точек. Для плато нужны связанные компоненты равных в пределах заранее заданной численной погрешности значений; произвольный ID не должен создавать несколько фиктивных центров. Проверка на нескольких заранее выбранных соседствах показывает, насколько ответ определяется именно этим выбором.

Краевой тест сравнивает **те же внутренние точки** при расширении набора источников. Он не должен смешивать эффект добавления населения с эффектом удаления дорожных путей: маршруты, проходящие за границей окна, по возможности остаются доступными. Если известны исключённая масса `M_out` и доказанная нижняя граница стоимости `T`, то для положительного убывающего ядра пропущенный вклад ограничен сверху `M_out K_h(T)`. Без этих условий такой границы нет. Пропущенная строка кэша не доказывает отсутствие дороги.

Минимальная сравнительная таблица должна разделять: число точек, известную и неизвестную массу, долю недостающих маршрутов, число пиков, их собственный вклад, изменение при другом ядре/соседстве/окне и совпадение с известными местными функциями. Динамику 2002–2021 сначала сопоставляют на фиксированной географии; сегодняшние дороги и учреждения не превращают результат в восстановленную историю поездок.

## Контрпример на пяти вершинах: диффузия создаёт дополнительный максимум

Это наша синтетическая проверка, **не наблюдение российских поселений и не доказательство поведения каждого варианта сетевого потенциала**. Граф — звезда: вершина 0 соединена с вершинами 1, 2, 3, 4, веса рёбер равны 1. Исходный сигнал `P=[10,9,8,0,0]`, `L=D−W`. Строгий максимум сравнивается с непосредственными соседями.

| Параметр диффузии `τ` | Значения в вершинах 0–4 | Максимумы |
|---|---|---|
| 0 | 10; 9; 8; 0; 0 | 0 |
| 0,2 | 7,09224543; 8,86590972; 8,04717897; 1,49733294; 1,49733294 | 1 и 2 |

Сумма сигнала остаётся 27 с погрешностью вычисления порядка `10^−14`, но число максимумов возрастает с одного до двух. Параметр `τ` здесь не имеет единицы дорожного времени. Воспроизведение:

```python
import numpy as np
from scipy.linalg import expm
W = np.zeros((5, 5))
W[0, 1:] = 1
W[1:, 0] = 1
L = np.diag(W.sum(axis=1)) - W
P = np.array([10., 9., 8., 0., 0.])
for tau in (0., 0.2):
    values = expm(-tau * L) @ P
    peaks = [i for i in range(5)
             if np.all(values[i] > values[W[i] > 0] + 1e-12)]
    print(tau, values, peaks, values.sum())
```

Этот пример исключает методическое правило «при увеличении масштаба число максимумов обязано уменьшаться». Он не отменяет содержательное исследование устойчивых центров; он требует проверять устойчивость непосредственно.

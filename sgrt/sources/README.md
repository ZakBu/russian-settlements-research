# Собранные источники

Таблицы по населённым пунктам России за 2025 год собираются из публичного архива Росстата `stat.info_NP_2025.rar` скриптом `scripts/sgrt_sources/build_russia_settlement_tables.py`. Каждый регион — отдельный файл меньше 1 МБ.

- `russia/headcount/` — среднесписочная численность работников организаций без малого бизнеса и без внешних совместителей. Это не рабочие места села.
- `russia/preschool/` — места и ставки дошкольных организаций.
- `russia/preschool_children/` — число воспитанников.

Значение `suppressed` — в книге стоит «...». Это не ноль. Часть книг архив не отдаёт: они в `russia/extract_failures.csv`.

Списки школ и опись реестров медицины лежат рядом, в `schools/` и `medicine/`. Исходные книги Excel в Git не кладутся: репозиторий их не принимает.

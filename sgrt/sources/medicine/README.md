# Источники по функциям поселений

Опись реестров медицинских организаций лежит в трёх файлах `inventory_part_01.csv`, `inventory_part_02.csv` и `inventory_part_03.csv`. В каждой строке регион, адрес, код ответа и примечание. Пустая ячейка значит, что файла нет, а не что объектов ноль.

Сборка скачивает файлы по этим адресам и кладёт текст таблиц в `tables/`. Книги Excel в репозиторий не входят. Чужой регион вместо пропущенного не подставляется.

Поселенческие таблицы Росстата собираются на ветке `cursor/sgrt-russia-sources-252c`.

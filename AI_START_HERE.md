# Вход для ИИ-ассистента

**Расчёт опубликован и повторён из скачанных данных.** Получены нижние группы обслуживания и вложенные модельные объединения. Реальные поездки и особый высший ранг Москвы пока не установлены; прежние варианты сохранены в исследовательской истории.

Правила работы, порядок чтения и стандарт текстов — в [AGENTS.md](AGENTS.md). Здесь — как получить данные и какой результат считать текущим.

## На каком этапе исследование

**База переписей готова и остаётся главным набором для скачивания. Текущая работа СГРТ — [нижние территории общего обслуживания и вложенные объединения](sgrt/zero/README.md).** Начните с [текущего состояния](research_context/current_state.json), [последних уточнений пользователя](research_context/conversation_context_20261025.md) и [дневника 25 октября](research_context/diary/2026-10-25.md). Старый [национальный однофункциональный проход](sgrt/mass/README.md) остаётся опубликованным контролем.

Расчёт начинается с ближайших известных повседневных услуг. Население не увеличивает притяжение школы или ФАПа. Нижняя группа — совпадающий набор поставщиков нескольких услуг; она может иметь несколько центров или неполные сведения. Одиночные записи и отсутствие поддержанной ближней связи показываются отдельно. Выше проверяются новые функции, целостность нижних групп и прямые дорожные связи всех участников. Внешние модельные границы агломераций 2015 года — отдельное условие сценария, а не обнаруженные нами современные границы.

Новый медицинский источник — федеральные адресные справочники на 23.10.2026. Профили соединены с конкретными адресами подразделений; общей лицензии больницы недостаточно, чтобы объявить её школьный кабинет обычным врачебным центром. Добавлены координатные образовательные объекты 2026, датированные официальные сведения, магазины OSM 2021 и свежие положительные свидетельства продуктовой торговли, отдельные операторские варианты ПВЗ. История и исходные строки сохраняются. Наличие записи не устанавливает посещение или мощность.

Москва, Петербург и Севастополь — отдельные городские ориентиры внутри 153 803 точек анализа; население этих агрегатов не прибавляется к бюджету 153 800 обычных пространственныхНП. Каждый город представлен одной точкой спроса; внутригородские территории здесь не выделяются. **Глубина слияний не является рангом города; единственный высший порядок Москвы заранее не назначается.**

Полный и компактный повтор — [sgrt/zero/REPRODUCE.md](sgrt/zero/REPRODUCE.md). Итоговый комплект содержит своё описание завершённого расчёта `RESULT_README.md`; копия контекста внутри него фиксирует состояние на момент исходного коммита. Все предыдущие выпуски остаются доступны и не подменяются. Базу населения не надо брать из отвергнутых расчётов районов.

## Клонирование

Полный клон весит около 400 МБ; для работы достаточно последней версии:

```bash
git clone --depth 1 https://github.com/ZakBu/russian-settlements-research.git
cd russian-settlements-research
```

## Данные

Данные лежат в релизах GitHub этого репозитория. Каталог [data/catalog.json](data/catalog.json) связывает каждый файл с архивом, размером, SHA-256 и схемой таблицы. Загрузчик использует только стандартную библиотеку Python; для чтения Parquet нужен PyArrow (`python -m pip install -r requirements-handoff.txt`).

```bash
python scripts/research_data.py list                 # что входит в профиль и сколько весит
python scripts/research_data.py fetch                # скачать
python scripts/research_data.py verify               # сверить контрольные суммы
python scripts/verify_population_base.py             # проверить контрольные числа базы
```

| Профиль | Что скачивается |
|---|---|
| `core` (по умолчанию), `population`, `current` | База населения 2002/2010/2021, около 56 МБ. Описание полей — [POPULATION_BASE.md](POPULATION_BASE.md) |
| `legacy_model` | Таблицы предыдущего расчёта районов (отвергнут, см. [sgrt/README.md](sgrt/README.md)) |
| `legacy_model_full` | Полный пакет предыдущего расчёта |
| `all` | Все сохранённые данные, около 15 ГБ |

Можно скачать только нужное:

```bash
python scripts/research_data.py list --profile all --match '*medical*' --show-files --show-schema
python scripts/research_data.py fetch --profile all --match '*medical*'
```

`--match` сравнивается с путём файла; несколько `--match` объединяются по «или». Архивы обрабатываются по одному и удаляются после распаковки (`--keep-archives` их сохраняет). Скачанные данные и `.research-cache/` не коммить.

### Особые файлы в профиле `all`

В `data/source_special_files.json` описаны четыре символические ссылки и один служебный файл macOS. Две ссылки указывают на существующие таблицы, и загрузчик создаёт их копии. Две другие указывали на отсутствующую папку ещё в исходном снимке. Их цели восстановить нельзя, похожими таблицами их не подменяй. Если `fetch` останавливается с `Existing file differs` на одном из этих путей, сверь SHA-256 файла с `original_sha256` в этом JSON, убери совпавший файл и повтори загрузку.

## Текущий комплект нижних групп и верхних сценариев

Для текущего результата используется **отдельный** [каталог](data/zero_catalog_20261025.json). Профиль `all` основного каталога сохраняет прежнюю историю и не заменяет этот комплект. Связанная база населения по-прежнему скачивается по умолчанию.

```bash
python scripts/research_data.py list --catalog data/zero_catalog_20261025.json
python scripts/research_data.py fetch --catalog data/zero_catalog_20261025.json \
  --dest ../sgrt-zero-data --cache ../sgrt-zero-cache
python scripts/research_data.py verify --catalog data/zero_catalog_20261025.json \
  --dest ../sgrt-zero-data
```

Восстановленный корень — `../sgrt-zero-data/sgrt/zero20261025`. Сначала прочитайте его `RESULT_README.md`: это описание завершённого расчёта. Главные таблицы:

| Путь от корня комплекта | Смысл |
|---|---|
| `context/analysis_reference.parquet` | Принятая переписная ось и три отдельных городских ориентира |
| `health/public_scope_corrected/np_supply.parquet` | Окончательное медицинское предложение по НП; сырые источники рядом не подменяют эту таблицу |
| `screens_final/daily_edges.parquet` | Прямые повседневные направления всех пяти вариантов с причинами допуска |
| `hierarchy/daily_20_school30_wb/level0_units.parquet` | Сочетания поставщиков основного нижнего варианта, их типы и полнота |
| `hierarchy/daily_20_school30_wb/level0_memberships.parquet` | К какой нижней группе относится каждая исходная точка |
| `hierarchy/daily_20_school30_wb/level0_provider_anchors.parquet` | Поставщики каждой группы, отдельно от входящих в неё точек |
| `upward/daily_20_school30_wb/` | Основные строгие верхние шаги; составы, дети и исходные связи |
| `upward_extended/daily_20_school30_wb/` | Сравнение полного расширения и диагностика двух согласованных сфер |
| `hierarchy_readout/` | Сводка всех 15 разделений, геометрия и причины неполного ближнего набора |
| `population_context_readout/` | Население обычных членов и неаддитивные городские агрегаты отдельно |
| `functional_complexity/` | Известные функции и ограничения сравнимости источников; не ранги городов |
| `checks/`, `reproduction/` | Фактические проверки, закреплённый код, литература, Word и контекст |

Общий каталог хранит логические пути, размеры, хеши и схемы. Файлы исходного происхождения, в том числе прежние таблицы неизменённых дорожных классов, сохраняются ради проверки. Для текущего расчёта берите канонические роли выше. Вариант двух сфер — диагностика; астраханский пример 119,69 км от города не принимается за доказанную агломерацию. Уникальный верхний функциональный ранг Москвы пока не установлен.

## Предыдущие проверяемые этапы СГРТ

Результаты от 24.10.2026: [sgrt/pilot/README.md](sgrt/pilot/README.md). Это рассчитанные сценарии образования и медицины с типами кандидатных единиц и картами, не принятая общероссийская делимитация. Данные доступны через отдельный `data/pilot_catalog_20261024.json`; главный каталог и профили core/population/current по-прежнему загружают принятую базу населения. Исходные данные и результаты не надо брать из отвергнутой модели районов.

[Документированные локальные системы Учалинского района](sgrt/local_systems/README.md) — содержательная проверка исправленной постановки на конкретных школьных и медицинских связях. Их источники и опубликованный компактный комплект сохранены. Национальный проход выше развивает эту постановку; региональные сценарные массы первого пилота не принимаются за локальные СГРТ.

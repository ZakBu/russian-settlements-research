# Вход для нового ИИ-ассистента

Это продолжающееся исследование сельско-городских районов тяготения России. Пользователь хочет передавать репозиторий между ассистентами без потери контекста, данных и истории решений.

## Прочитай перед действиями

1. [AGENTS.md](AGENTS.md) — правила ведения исследования и подробного дневника.
2. [README.md](README.md) — действующая постановка, отличие прежнего расчёта от новой модели и ссылки на полные материалы.
3. [Текущее состояние](research_context/current_state.json) и [дневник22октября2026](research_context/diary/2026-10-22.md).
4. [Исходный Word](research_context/primary/word_concept.docx), [полный извлечённый текст](research_context/primary/word_concept_extracted.txt), [приложенный контекст](research_context/primary/pasted_context.txt), [уточнения переписки](research_context/conversation_context_20261022.md).
5. Для затухания, иерархии и полицентричности — полный каталог литературы и карта использования в references/, а также подробные восстановленные записки по ссылкам README.

Важное различие: предыдущий cycle07 — вычислительный срез потенциальных районов. Новая постановка с отдельными функциональными массами и эмпирической проверкой связей не реализована автоматически старым кодом.

## Получи данные

Данные находятся в GitHub Releases **этого же репозитория**, без внешнего аккаунта или отдельного облака. Parquet сохранены побайтно; одинаковое содержимое лежит в ZIP один раз, а каталог восстанавливает исходные пути. Все пути и версии доступны через [data/catalog.json](data/catalog.json).

Из корня клона:

```bash
python scripts/research_data.py list --profile core
python scripts/research_data.py fetch --profile core
python scripts/research_data.py verify --profile core
```

Профиль core нужен для входа в данные; current — для структурированных таблиц последнего вычислительного пакета; all — для всех каталогизированных исторических данных. Сначала посмотри объём командой list. Для чтения Parquet установи pyarrow или другой совместимый инструмент. Схемы и количество строк также записаны в каталоге.

Скачанные данные и .research-cache не коммить заново. Если файла нет в каталоге, сначала проверь подробные манифесты и историю; не придумывай значения и не объявляй набор полным. Непопавшие в Git локальные файлы, исчезнувшие при сбое прежней среды, не восстановлены.

## Продолжи работу

Зафиксируй в новом дневнике, что прочитано и какие данные проверены. Затем выполняй следующий научный шаг из current_state.json. Не начинай заново весь проект и не считай формальный отчёт или одобрение агента доказательством реальных связей. После работы оставь подробную запись для следующего ассистента.

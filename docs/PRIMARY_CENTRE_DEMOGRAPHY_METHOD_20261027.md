# Население центров и их основного окружения

## Что изменилось

Для всех 28 512 зарегистрированных местных центров рассчитаны описания изменения населения в 2002–2021 и 2010–2021 годах. На этот раз окружение берётся из нового основного распределения: каждый включённый населённый пункт относится только к одному центру. Прежние пересекающиеся окружения сохранены как самостоятельный результат и не переписаны.

Основное распределение включает 103 181 запись вокруг этих центров: 28 512 самих центров и 74 669 внешних участников. Повторов между центрами нет. Для 50 622 остальных записей из общего набора 153 803 мест этот расчёт не создаёт нового членства. Он не переносит их население к ближайшему центру.

У 13 650 центров после основного распределения осталась только собственная запись. Это важное ограничение: центр зарегистрирован по обслуживанию внешних населённых пунктов хотя бы по одной функции, но эти пункты могли получить другого основного центра. Отсутствие внешнего участника в таком распределении не означает отсутствия реального обслуживания. Следовательно, все 28 512 записей нельзя называть подтверждёнными многопоселенческими системами.

## Как определён тип

Использован опубликованный метод `centre_demographic_readout.py`. Числа складываются только по фиксированному составу нынешнего окружения, отдельно для центра, всех внешних участников и их сельской части. Сельский состав определяется типом населённого пункта в 2021 году. Историческое обслуживание и исторические границы из этих чисел не восстанавливаются.

Для полного сопоставимого состава увеличение суммы означает рост, уменьшение — убыль, точное равенство — отсутствие изменения. Дополнительный порог не вводится. Если хотя бы одна обязательная запись не имеет пригодного значения, направления всей компоненты не устанавливается. Доступная частичная сумма сохраняется, но не выдаётся за полное население.

Каждому центру назначена пара статусов: направление изменения самого центра и направление изменения его внешней сельской части. Отсутствие сельских участников обозначено отдельным статусом `no_external_rural`. Если тип внешнего населённого пункта неизвестен, отсутствие известного села не превращается в доказанное отсутствие сельского окружения. Статус `unknown` означает ограничение сведений, а не особую демографическую траекторию.

Это описательные сочетания. Они не доказывают причинные типы из концепции Word: например, одновременный рост центра и убыль сёл сами по себе не устанавливают миграцию из этих сёл в этот центр.

## Два варианта качества

Вариант `strict_direct_observed` требует первичного наблюдённого числа, переписной записи и права включения населения в сумму в обоих годах. Перечень допустимых признаков качества взят из опубликованного метода без изменений.

Вариант `accepted_values` использует все принятые кредитованные числа, сохраняя их происхождение. Он не называется полностью наблюдённым. В принятой базе нет отдельной пары исходных и эффективных чисел, поэтому сравнение этих двух вариантов не является сравнением raw/effective. Защищённые вторичные числа 2010 года также нельзя автоматически объявлять интерполяцией.

## Полученные различия

Для периода 2002–2021 годов полное совместное описание центра и сельского основного окружения есть у 11 739 центров по принятым значениям и у 11 728 по строгим первичным данным. Из принятых описаний: центр и сёла убывают у 8 601 центра; центр убывает, сёла растут у 1 017; центр растёт, сёла убывают у 824; обе части растут у 1 059. Оставшиеся полные сочетания включают точное отсутствие изменения одной из частей. Всего 13 670 центров имеют доказанно пустую сельскую часть основного окружения.

Для 2010–2021 годов полных совместных описаний по принятым числам — 11 759, по строгим первичным — 315. Среди 103 181 включённой записи у 91 415 значение 2010 года имеет признак защищённого вторичного числа с непроверенным точным охватом. Описательные статусы при переходе от строгого к принятому варианту отличаются у 26 212 центров из 28 512. Это изменение доступности и статуса доказательств, а не число населённых пунктов с ошибочно восстановленным населением. Среди центров, у которых обе части известны в обоих вариантах, ни одного перехода между направлениями нет: 0 из 11 728 для 2002–2021 и 0 из 315 для 2010–2021. Строго неизвестное совместное направление становится известным по принятым значениям у 11 и 11 444 центров соответственно. Остальные различия полного статуса затрагивают в том числе известность самого центра при пустой сельской части.

Дополнительно рассчитан отрезок 2002–2010 годов и отдельные двухотрезковые траектории центра и сельского окружения: 2002–2010 и 2010–2021. Они позволяют отличать устойчивую убыль от смены роста убылью, которая теряется при сравнении только крайних лет. Для каждого отрезка действуют те же требования к полноте и происхождению чисел.

Сравнение со старыми пересекающимися окружениями вынесено отдельно. Различие классов между ними отражает изменение состава окружения, а не изменение исходной базы населения.

## Воспроизведение

Новый код: `scripts/sgrt_zero/primary_centre_demography.py`. Проверки: `tests/test_sgrt_zero_primary_centre_demography.py` — пять тестов. Они проверяют исключение дополнительных контекстных узлов, уникальность основного членства, различение неизвестного сельского состава и пустого окружения, а также статус защищённых вторичных чисел 2010 года.

Входы: таблицы `level0/units.parquet`, `level0/memberships.parquet` нового основного распределения и опубликованная `context/analysis_reference.parquet`. Таблица старых демографических классов нужна только для сравнительного контроля. SHA входов и обоих программных методов записаны в `summary.json`. Полные данные сохранены в Parquet, включая отдельную таблицу происхождения населения каждого выбранного участника.

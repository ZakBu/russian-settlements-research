Основная таблица дополнительно содержит495 координатных использований у официальных годовых наблюдений; они наследуют принятый пространственный вывод и не добавляют новых переписных точек.

## Правила принятия и проверка

Устойчивые обычные случаи принимаются по непротиворечивому сочетанию точного нормализованного имени/типа, применимого административного контекста, уникальности кандидата, прямых сравнительных публикаций или именованного исторического кода и согласованной географии. Компоненты графа не могут содержать две записи одной переписи. Региональная уникальность имени не требуется там, где принятый административный контекст уже надежно различает места.

Точное имя без контекста, fuzzy score, близость точек, старое порядковое сопоставление, код неоднозначного уровня и неразобранное объединение/разделение дают только кандидата. Итоги территорий не получают точку населенного пункта. Качество самой точки и правильность официального FIAS ID отделены. Отсутствие query receipt или исторического полигона не является самостоятельным запретом.

Проверки правил фиксировали страты и исходные хеши; отдельно проверялись рискованные типы, крупные объекты, конкурирующие соответствия и исходные строки.405 координатных исходных строк и1175 Wikidata локаторов,120 строк исторического правила,24 новых примера применения и54 примера нового не-городского правила — ограниченные фиксированные диагностические проверки. Они не являются национальной вероятностной выборкой и не дают оценки точности99,9%. Дополнительно выполнены целые наборы проверок исходных полей и численных инвариантов. Все1414 новых связей после исправленияё/е повторно прочитаны из XLS. Все новые приложения имели отдельное решение о приеме.

Самокритика: пустой selector семейства в первой корневой проверке происхождения ошибочно создавал впечатление выполнения цикла. Условие выявлено, прежний документ сохранен, новый документ требует ровно84035 строк и действительно проверяет все носители. Неверная подпись индивидуального статуса Москвы2002 исправлена отдельной принятой сборкой; сами точки не менялись. Это основание проверять численность области проверки до утверждения «все проверено».

## ОКТМО и история

В основной таблице отдельно стоят нативный наблюдаемый ОКТМО2021 и текущий код связанной сущности. Последний не объявляется историческим кодом2002/2010 или датой юридического действия. Нативные10-значные значения отдельных регионов не дополнены нулями.

`identifier_snapshot_claims_candidates.parquet` содержит1465966 исходных утверждений ОКАТО/ОКТМО/ФИАС из снимков2009/2011/2021 с происхождением. Даты снимка и обновления не равны valid_from/valid_to. Восьмизначный ОКТМО2011 может обозначать муниципального родителя; из этого не создается юридическая трансформация в11-значный код НП. `historical_event_candidates.json` содержит44 кандидата события со ссылками и датами утверждений. Их статус кандидата сохранен. Полная доказанная история преобразований ОКТМО не получена.

## Почему пока нельзя получить99,9%

Три строки2021 Москвы/Петербурга/Севастополя содержат19159843 человека на уровне субъекта. До обоснованного разложения на физические НП максимум доли населения обычных НП в этом выбранном слое —86,981%. Суммирование муниципалитетов не доказывает население отдельного центра. Точка центра субъекта не закрывает эту проблему. Аналогичные субъектные строки старых лет удержаны. Крым и Севастополь явно находятся вне охвата российских переписей2002/2010, а не являются нулем или неудачей matching.

В2010 сумма выбранных записей на653824 ниже контроля: даже полные координаты не устраняют отсутствие этой известной численности. Нельзя распределить региональный остаток между НП. Оставшиеся именованные НП требуют массового административно-кодового сопоставления, проверки конкурентов и источников. Для ежегодных данных большинства малых НП точных опубликованных рядов нет в восстановленном наборе. Непроверенные исторические цитаты не заменяют их.

## Следующие практические итерации

1. Зафиксировать полный остаток по субъектам, источникам, населению и системному риску. Уже приложены списки переписных записей без точки/связи/цепочки. Отдельные очереди: федеральные уровни, конфиденциальные публикации2010, конфликт координат, конкурирующие НП, потенциальные события. Критерий: каждый остаток имеет явную причину и источник, ни одна кандидатная строка не попадает в принятое покрытие.
2. Следующий массовый запуск — согласование именованного собственного объекта современного поставщика с прямым административным контекстом и официальными кодами для одноименных НП, которые уже различены в принятых связях. Не новая ручная проверка всех деревень. Сначала профиль оставшихся групп и пробный батч; кандидатные случаи со сменой уровня/границ остаются отдельно. Критерий: проверенное правило, независимая фиксированная выборка, целые инварианты и новое покрытие по всем осям.
3. Одновременно восстановить точные первичные публикации2010 для наиболее массовых проблемных регионов и официальное описание федеральных физических уровней. Использовать уже сохраненные XLS/DOC, расширять скачивание только для доказанного отсутствия. Критерий: точные строки/хеши/локаторы, разобранная иерархия, непротиворечивые региональные суммы без распределения остатка.
4. Годовые ряды: сначала первичные цитируемые публикации для крупных городов/периодов и новые официальные таблицы, затем расширение к малым НП.34004 Lua-значения остаются исходными утверждениями до проверки конкретного источника, даты, территории и физической преемственности. Критерий: отдельное принятие населения и связи для каждого применимого источника/правила; национальный процент только при известном знаменателе.
5. История кодов/событий: конкретные официальные версии ОКТМО и акты, привязанные к принятым сущностям; объединения/разделения отдельными отношениями, границы отдельно от идентичности. Критерий: дата/уровень/доказательство и явные неизвестные интервалы, без превращения родительского кода в историю НП.

Сроки этих работ сейчас не оценены: неизвестен объем необходимых первичных публикаций и событий. Измеренный полный генератор кандидатов занял95,66 секунды и около2,94GiB RSS; это характеристика данного батча, не оценка времени достижения99,9%. Ограниченное число экономичных агентов работало в отдельных зонах записи; повторные проверки задавались конкретными выводами. Навыки установки/контекста/агентов/проверки науки установлены с исходниками и хешами. Сокращение токенов в процентах не заявляется: такой телеметрии нет.

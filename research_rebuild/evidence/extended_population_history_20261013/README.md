# Восстановленная дополнительная история населения собственных НП

Получен фактический длинный Parquet с 9045 буквальными датированными утверждениями P1082 для 1357 собственных населённых пунктов, привязанных к актуальному root.167 реально наблюдаемых лет:1617–2025. До 2002 года —2229 наблюдений для 272 НП.6153 наблюдения находятся вне календарных лет переписей 2002/2010/2021. Ещё2892 вторичных утверждения этих лет сохранены отдельно с do_not_override_native_census=True. Это не замена выбранных переписных значений.

Данные восстановлены из 29 имеющихся полных кэшированных снимков Wikidata (1450 объектов), без нового интернет-сбора.1357 объектов прошли консервативную проверку собственной физической идентичности: уникальный текущий собственный код НП среди всех текущих записей и кэшированных объектов либо уже принятая прямая собственная QID/P625-привязка; буквальное собственное имя, поддерживаемый физический класс, отсутствие противоречащих идентификаторов/типов и единственная собственная P625 в пределах 5 км от актуальной принятой собственной точки. Восстановление ведущего нуля ограничено документированным представлением собственного кода НП 10→11; произвольного муниципального 8→НП 11 нет. Строка исходного уровня «Населенный пункт», её код/название/регион и точный row1 сохранены в таблице привязок. Региональные, муниципальные и федеральные агрегаты не становятся собственными историческими наблюдениями НП.

Историческое отображение не требует наличия всех трёх переписей:82 привязанных НП сейчас не имеют полного full3. Привязка к нынешнему собственному объекту не доказывает историческое членство, непрерывность границ или историческую измеренность координат. primary_verification=primary_unverified, boundary_comparability=UNKNOWN, historical_coordinates_observed=False, current_point_reference_only=True. Сохранённая нынешняя точка — ссылка для отображения, не координата наблюдения 1617/1959/1989 года.

Каждая строка сохраняет буквальный P585, точность и календарь даты, целую неотрицательную величину и её исходную запись, единицу 1, GUID, normal/preferred rank, квалификаторы, ссылки P248/P854/заголовки и полный raw_statement_json. Подмножества P518/P642/P21, deprecated, отсутствующие/неоднозначные даты, несовместимые точность/литерал и неверные единицы удержаны. Явные исходные нули сохранены; отсутствия не превращаются в нули, интерполяции и остаточной аллокации нет.

Все GUID внутри результата уникальны. Разные значения в одну буквальную дату сохранены с флагом конфликта. by_year.csv содержит только описательные суммы для НП с единственным значением в данном году; это ограниченный исходными кэшами набор, не историческое население России и не национальное покрытие.

Ранее утверждённые внешние 10963 строки v3/v4/physical-extension упомянуты в Git, но их отсутствующие внешние GUID-файлы не были восстановлены: опубликованный stage71 содержит переписные таблицы, а не эти истории. Поэтому результат обозначен как recovered/reconstructed, принадлежность старому реестру — UNKNOWN, чистый прирост относительно старых 10963 не заявлен. Дополнительный ограниченный просмотр 81274 плоских строк module_qid_population только для уже 1357 привязанных QID обнаружил 305 известных GUID и 0 новых кандидатов; недостаточные unit/precision/scope такого плоского источника не могли бы автоматически стать подтверждёнными наблюдениями.

population_history_long.parquet и current_physical_bindings.parquet доступны непосредственно в этом каталоге для скачивания через Git, а оригинальные большие рабочие копии — /workspace/scratch/extended_population_history_20261013/. Structured Wikidata data: CC0; первичные источники в ссылках не объявлены независимо проверенными. Большие кэши в Git не копировались.

collect.py воспроизводит извлечение; validate.py повторно сверяет все 9045 исходных утверждений и актуальные UID/root/ссылочные точки. validation.json:PASS. scan_flat_candidates.py выполняет ограниченную проверку плоского кэша без продвижения неполной схемы в наблюдения. receipt.json и raw_source_manifest.json сохраняют хэши и ограничения. Исходный интегрированный файл, переписные численности, координаты, root-граф, sparse checkout и замороженные источники не изменены.

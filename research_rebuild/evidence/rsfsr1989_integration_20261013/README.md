# Расширение базы на перепись РСФСР 1989 года

Рабочая таблица — `population_1989_selected_long.parquet`; актуальные количества и SHA-256 — в `integration_receipt.json`. Это сумма выбранных наблюдений разных источников и типов численности, а не однородная оценка покрытия официального национального итога. Наличное, постоянное и неуточнённое население сохранены отдельными статусами.

`integrate.py` отдаёт приоритет первичной таблице Демоскопа/Госкомстата, затем региональным публикациям, энциклопедическим рядам и вторичным датированным утверждениям Wikidata. Повторные наблюдения сохраняются в `overlapping_observations.json`, конфликтующие вторичные значения и объекты вне РСФСР — в `excluded_observations.json`. Числа 2002/2010/2021 не заменяются.

Связь использует существующий root или самостоятельную историческую сущность, если отдельной записи современной переписи нет. Для самостоятельной сущности не создаются фиктивные численности следующих лет. `linked_census_years` перечисляет записи текущего root; наличие трёх годов само по себе не доказывает неизменность границ или точность каждой исторической координаты. Современная точка используется ретроспективно с явным статусом вывода о пространственной преемственности.

Ленинград представлен собственной численностью города 4 460 424 и отдельно отмеченной ранее принятой репрезентативной точкой. Дочерние города учитываются отдельно. Территориальная численность 5 023 506 из вторичного источника не прибавляется к собственному городу и его дочерним НП.

Контроли: 3 229 городов/ПГТ первичного источника точно дают 108 425 580, баланс мужчин и женщин выполнен; внутригородские районы исключены. Независимое чтение 62 городов из скана совпало с первичной таблицей после двух документированных исправлений ручного чтения. Это целевая проверка крупных городов, не случайная выборка. `large_growth_diagnostic.json` отмечает рост ≥2000% без автоматического удаления наблюдений.

Исходные статьи и крупные файлы хранятся отдельно. Публичные фактические выгрузки энциклопедий не включают полный текст статей. Условия использования источников различаются; единая лицензия всем данным не назначена.

Воспроизведение: `python bind_additional_rural.py`, затем `python integrate.py`. Путь к актуальному принятому слою переписей указан в скриптах и квитанциях; его SHA-256 проверяется отдельно. Для просмотра ряда можно использовать существующий `extended_demography_integration_20261013/query_series.py --census ... --primary population_1989_selected_long.parquet --source-record-id ...`.

Итог 13 октября: **20 424 объектов / 120 006 238 человек**, смешанный тип населения. Подробный русскоязычный отчёт: `docs/RSFSR_1989_RU_20261013.md`. Устранены повторы не только по root, но и по подтверждённому внешнему объекту и явному отображению исторической точки. Публикации 1989 могут включать перераспределение населения ЗАТО; Северск сохранён отдельно и не прибавлен к сумме. Это не оценка точного пространственного покрытия всех жителей РСФСР.

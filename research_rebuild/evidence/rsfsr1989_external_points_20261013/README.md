# Самостоятельные исторические НП 1989: внешние физические точки

Дельта содержит **16 НП / 531 120 жителей наличного населения переписи 1989 года**. Население, пол, исходные UID/локаторы/хеши — только из Демоскопа. Внешние источники используются для идентификации места и координат; их численности не используются.

`external_point_delta.csv` и Parquet готовы к интеграции отдельно от замороженной первичной связи 3 542 НП. Root вида `historical:1989:demoscope:QID`; anchor_source_record_id пустой. Статус bound_external_physical_point_historical_entity, no_individual_2021_census_match. Это новая историческая сущность с внешним идентификатором, не федеральный родитель и не фиктивная индивидуальная строка переписи 2021. Не утверждается полный трёхлетний ряд.

Проверены Колпино, Пушкин, Петергоф (историческое название Петродворец прямо присутствует в aliases), Кронштадт, Ломоносов, Павловск, Сестрорецк, Зеленогорск и восемь посёлков Санкт-Петербурга. Правило: буквальное русское имя либо явный исторический alias + физический класс P31 + административная цепочка P131 к Санкт-Петербургу Q656 + одна конечная координата P625 Земли. Административный муниципальный класс сам по себе недостаточен. Некоторые сущности имеют одновременно physical settlement и municipal classes: физический класс проверяется отдельно; значения 1989 относятся к исходному НП, а не административной территории.

Физические классы: Q515 город, Q2514025 посёлок, Q15078955 посёлок городского типа России, Q486972 населённый пункт. У Зеленогорска Q21130185 — деревня в бывшем муниципалитете Финляндии (физическое поселение); современное описание прямо указывает город в Курортном районе Санкт-Петербурга. Q2065736 культурная ценность НЕ используется как физическое доказательство. Метаданные классов и районов сохранены в context JSON.

Понтонный удержан: две недепрекейтед P625 координаты, автоматический выбор не сделан. Все проверочные атрибуты, реальные P31/P131/aliases, причины отказа находятся в entity_validation.json. 16 различных source UID, QID и исторических roots; координаты конечны. Исходные первичные файлы не изменены.

Кэшированные wikidata_oktmo_entities.tsv и module_qid_entities.jsonl.gz проверены; в TSV присутствуют все 17 исследованных QID, в модульном кэше нет. Хеши и фактическое число просмотренных строк — cache_lookup_receipt.json. Для окончательной проверки физических/муниципальных классов, aliases и административной иерархии получены текущие полные Wikidata entity JSON, с URL и SHA256 в physical_entity_receipts.json/context_entity_receipts.json. Это не координатное измерение 1989 года: coordinate_role=external_physical_settlement_point_reused_for_historical_1989_entity; historical_boundary_comparability=unknown; ретроспективная преемственность интерпретирована, юридические границы не объявлены одинаковыми.

`build_delta.py` воспроизводит CSV/Parquet из сохранённых JSON и первичного CSV без сети. `fetch_entities.py` описывает получение entity JSON. Поисковые ответы и выбранные кандидаты сохраняются. Массовый поиск столкнулся с 429; batch API — с 403; после этого использованы отдельные публичные Special:EntityData JSON. Никаких обходов ограничений доступа не применялось. Иные остаточные 1989 НП этим ограниченным запуском не разрешены.

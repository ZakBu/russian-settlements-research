# Дополнительное разрешение муниципального контекста по исходному коду

Четыре ранее неоднозначные или непривязанные связи верхнего муниципального уровня разрешены: Иркутск (617264), Смоленск (316570), Десногорск (25345), Сосновка (69). Всего 959248 человек в исходных строках НП получили более полный муниципальный контекст; это не прирост покрытия населения и не изменение численностей.

Использован только существующий исходный код: 11-значный код НП, либо десятизначное представление с восстановленным ведущим нулём, и его документированные первые восемь знаков. Этот код должен совпасть с единственной существующей строкой того же сырого региона и исходного уровня «Муниципалитет верхнего уровня». В неоднозначных именных случаях сохраняется также точное исходное имя. У Иркутска прежняя подпись «Город Иркутск» не находила точной строки; самостоятельное кодовое доказательство привязывает существующий муниципальный объект, а обе подписи сохранены.

Основание структуры: ОК 033-2013 в описании https://classifikators.ru/oktmo#info: «XX XXX XXX — муниципальные образования (8 знаков); XX XXX XXX YYY — населенные пункты (11 знаков)». Это неофициальное зеркало описания классификатора, что указано в receipt.json. Независимый первичный источник — описание БДМО «Если быть точным», атрибут10: «Код ОКТМО муниципального образования (первые 8 цифр)». Выдержка и хэши источников сохранены. Первые пять знаков для вычисления района не используются; новый муниципальный уровень не создаётся.

Алеутский муниципальный округ (654 человека) остаётся удержан: одинаковый код не позволяет выбрать единственную исходную строку. Семьдесят семь неоднозначных нижних связей также не получили уникального доказательства среди исходных именных кандидатов. Нижний уровень не создаётся для городских округов, где отдельной исходной строки этого уровня нет.

accepted_context_delta.csv — только четыре допустимых дополнения. Ключ: source_record_id + municipality_role.

# Bashkortostan and Amur follow-up resolutions — version 3

Version 1 and version 2 remain unchanged. This packet resolves all three high-population Amur Березовка source rows to the Ivanovsky carrier. The exact own-locality RU Wikipedia page Берёзовка (Ивановский район), page 5322681 revision 153646805, identifies Amur region and Ivanovsky district, the Berезовский сельсовет, and supplies own-locality coordinates 50.56819444, 127.86369444. The 2021 native carrier names Ивановский municipal district. The original 2002 row occurs in a distinct source-list locality group from the separate same-name village (population 214); the final numeric field is the Russian-majority share, not an administrative code. The 2010 original row and adjacent source context corroborate the Ivanovsky group.

Two same-place edges and retrospective representative point uses are emitted for 2002 (3593, direct published value) and 2010 (3136, protected secondary value; scope remains unverified). The current 2021 native row remains carrier. Population values and quality flags are unchanged; no population equivalence, allocation, boundary equivalence, or provider ID assertion is made. The article point is about 0.60 km from the 2021 native point.

The roster retains all 33 assigned UIDs in uid_dispositions_v3.csv. Version 3 closes 31 of the 33 assigned UIDs on a full observed three-year or dated lifecycle path. The two Энергетик (Башкортостан) source-year UIDs remain held: 2010 and 2021 observations are present, but no 2002 source UID or dated absence/inclusion event is yet established. Two-year continuity does not count as primary closure. The 33-UID roster and per-year credit ledger make this boundary explicit: each target has three year slots; each slot receives an actual source UID or dated typed lifecycle/absence path, otherwise the target is held. The only uncredited slots are 2002 for the two Энергетик records.

The packet also admits direct own-locality point uses for 2021 Федоровка (Уфа), whose page identifier exactly matches native OKATO, and 2021 Восточный (Октябрьский район), whose exact article county/name/type match the native row. The latter article carries no explicit locality code, so no provider ID match is asserted. These are point claims for the same-year rows, with no temporal edge.

The act itself was not reopened, and an exact effective day is not claimed. `available_year_paths.csv` records each year.

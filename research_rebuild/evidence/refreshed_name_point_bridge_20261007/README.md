# Повторное применение массового правила к новым принятым точкам

Использовано существующее правило уникального нормализованного имени и региона с дополнительным требованием одинакового типа. Учтены все принятые дельты точек, которые предыдущий SQL-запрос не включал. Для двух точек расстояние не превышает 5 км. Удерживаются конкурирующий год в графе, общие координаты разных объектов и конфликтующие старые координатные кандидаты. Популяционные выбросы отмечаются отдельно, исходные числа не изменяются.

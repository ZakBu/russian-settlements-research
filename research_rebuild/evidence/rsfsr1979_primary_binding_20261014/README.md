# Привязка первичных наблюдений1979

bind.py применяет существующий массовый компонент1989 к двум новым таблицам1979: именованные НП, исторический региональный namespace, тип, уникальность кандидата и собственная принятая точка. Это кандидатная/правиловая привязка, не доказательство точных исторических границ.

augment_1989.py добавляет уникальные физические места, уже принятые в1989, по буквальному имени/региону и предпочтению одинакового исходного административного контекста. Численность берётся только из1979.

Исходные bindings не являются итоговой принятой таблицей: последующая интеграция применяет конкретные исправления исторических тёзок и удержания. Актуальные факты: historical_censuses_integration_20261014; русский отчётdocs/RSFSR_1979_1989_RU_20261014.md.

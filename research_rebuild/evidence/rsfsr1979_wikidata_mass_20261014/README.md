# Буквальный вторичный ряд Wikidata 1979

`secondary_population_1979_long.parquet` содержит 4 167 GUID-наблюдений для 4 166 ROOT, извлечённых исключительно из literal date 1979 в существующих TSV и module JSONL. Сумма при выборе одного значения на ROOT — 65 443 174. Это не подтверждённая первичная перепись и не национальное покрытие. Несколько GUID на ROOT не складываются: значения совпадают, но источниковые утверждения оставлены отдельно.

Identity переиспользована из ранее проверенных 10 135 QID→собственный НП 2021 bindings. Муниципальные объекты не добавлялись, Крым и Севастополь исключены. Привязка QID и современные собственные координаты не доказывают неизменность объекта/границ в 1979; continuity inference и UNKNOWN historical boundary записаны явно. Одна отсутствующая точка текущей таблицы переиспользована из принятой ownpoint строки selected1989; point_proof_basis отмечает этот источник. В primary selected1989 lookup сохранены только контекстные поля, никаких значений 1989 как 1979 не использовано.

159 GUID обогащены полными утверждениями из существующего API cache: JSON qualifiers, quantity/unit, P585 precision, rank, references, P31/P625 и SHA ответа сохранены. Для 4 008 GUID qualifiers/unit/precision остаются UNKNOWN; отсутствие явных subset qualifiers не заявляется доказанным. 4 926 сырых строк без ранее проверенной identity сохранены отдельно в unbound_inventory.json и не включены в long table. 13 650 сырых строк включают повторы источника/OKTMO; дедупликация одинакового GUID/даты/количества сохраняет все locator proofs. Новых API запросов нет.

Население: primary_unverified, basis UNKNOWN, census method UNKNOWN, do_not_override_primary. Использовать как вторичную годовую серию/кандидат, не как confirmed primary. Источники Wikidata CC0. Каждое наблюдение содержит source_proofs_json с SHA, нулевым ordinal строки и буквальным исходником; receipt.json фиксирует входные байты, включая identity/point/selected1989. validation.json подтверждает replay всех использованных источниковых строк, собственные точки и положительные/нулевые буквальные целые количества. Исходные 1989, frozen/core и Git не изменены.

Воспроизведение: `python run.py`, затем `python validate.py`. Выходы также находятся `/workspace/shared/rsfsr1979_wikidata_mass`.

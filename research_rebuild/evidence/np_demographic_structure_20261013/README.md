# Собственная демографическая структура НП: буквальные опубликованные значения

Оба набора allsettlements (235/237 исходных атрибутов) проверены по полным схемам: **нет половых, возрастных или домохозяйственных колонок НП**. Присутствует национальная принадлежность и категории ответов. Муниципальные возрастные, половые и домохозяйственные показатели БДМО не используются для заполнения НП.

Из 155 414 связанных записей 2021 года 155 411 имеют собственный исходный уровень «Населенный пункт». Три федеральных агрегата заблокированы. 214 национальных/ответных колонок образуют 33 257 954 буквальные ячейки одной версии. **Каноническая версия — v20251217**; v20260925 хранится отдельными версионными наблюдениями той же переписи 2021 года. Версии не складываются и не превращаются в два независимых наблюдения. Категории и подкатегории также не складываются: возможны множественные ответы.

`build.py` читает Arrow-пакеты по 4096 строк. В компактные `np_structure_frozen_positive.parquet` и `np_structure_latest_positive.parquet` записываются только опубликованные положительные целочисленные значения НП. Источник, исходная колонка, исходный номер строки, SHA256 и единица сохраняются. **Отсутствие разреженной строки никогда не означает ноль.** Опубликованные нули, `-9` (подтверждённое источником подавление при малом населении), NULL и ошибки сохраняются без изменения в двух исходных широких Parquet, на которые ссылается `schema_inventory.json`. `field_profile.csv` отдельно считает каждый статус каждой колонки. `lookup.py` возвращает точную исходную ячейку, включая ноль/подавление/unknown. Эти широкие файлы необходимо включать в переносимый пакет вместе с манифестом.

Для канонической версии подтверждено 794 071 положительное значение, 20 825 629 опубликованных нулей и 11 638 254 подавленных значений. Unknown, NaN/Inf, прочие отрицательные и нецелочисленные значения не найдены. Полный прямоугольник клеток не материализуется в длинную таблицу: это сохраняет все состояния и избегает многогигабайтного временного раздувания.

# Половой состав из первичного источника переписи 2002 года

`sex2002.py` извлекает буквальные числа мужчин/женщин из официальной таблицы `1_TOM_01_04.xls`, лист `01-04`, колонки 2/3 (нумерация от нуля). Таблица охватывает городские поселения, сельские районные центры и сельские НП от 3000 жителей; отсутствие других НП не заполняется.

Связь — точный уже существующий `source_record_id` `2002:1_TOM_01_04.xls:0:<строка>`: последняя компонента является номером строки Excel от 1. Дополнительно проверяется буквальная подпись конкретного НП и равенство `мужчины + женщины = исходный итог`. Региональные/районные агрегаты и строка федерального региона исключены. Для строки Диксона отдельно допускается буквальная подпись «Диксонский район - городское население - пгт Диксон (рц)»: она называет один НП и её итог 1198 точно совпадает с уже существующим первичным НП. Правило и исходная подпись сохранены. Ни сходство имён, ни новый перенос идентичности не используются.

Проверено 2932 собственных исходных НП; 2932 буквальные подписи подтверждены. Получено **5864 действительных половых наблюдения**, без конфликтов суммы и без изменения любого существующего населения. Собственное опубликованное население покрытых строк — 91 385 076 человека за 2002 год. Через уже принятый `root` доступны **2760 якорей НП 2021 года**, но год этих значений остаётся **2002**. Они не являются половым составом 2021 года и не заменяют переписные/годовые численности. `np_sex_2002_bindings.parquet` сохраняет все кандидаты и удержание; `np_sex_2002_anchor_links.parquet` хранит отдельную связь с якорями. Исторические половые значения вне этих буквальных первичных строк не выдумываются.

Текущий интегрированный Parquet сам содержит только население, без мужских/женских полей. Возрастной и домохозяйственный состав НП из имеющихся источников не опубликован/не извлечён в этой работе; отсутствие фиксируется явно.

```bash
python build.py
python sex2002.py
python lookup.py --source-record-id '2021:data_allsettlements_anon_156_v20251217.parquet:parquet:10' --field 'Русские (русаки, сибиряки)'
```

Полные результаты: `/workspace/scratch/np-demographic-structure-20261013/`. Ни одно замороженное входное значение не изменено; население и муниципальные агрегаты не распределяются по НП.

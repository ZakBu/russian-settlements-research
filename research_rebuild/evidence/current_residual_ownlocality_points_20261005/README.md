# Точки собственных записей 2021 года

Применено готовое правило точной исходной строки и локалитета ФИАС уровня 6 к подготовленной когорте текущих записей. Дубли одной точки в пределах переписного года удержаны. Пакет добавляет только координатную ось; он не создаёт межгодовых связей и не меняет население. У 23 строк уже есть межгодовая идентичность, поэтому для них координата одновременно закрывает совместную ось; остальные строки дают только пространственное покрытие.

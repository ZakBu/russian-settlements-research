# Compatible native printed type-prefix bridge (candidate only)

Pinned working state: stage 10. This packet proposes two actual new same-place UF unions: Красные Ткачи (2010→2021) and Тырма (2010→2021). Both historical components already contain 2002 and 2010 and own accepted representative points. Proposed complete-chain population gains are 6,660 / 5,876 / 5,711 in 2002 / 2010 / 2021. No census population or year is synthesized. These are simulated gains, not admitted coverage.

The rule strips only an exact initial printed prefix followed by whitespace, and only when compatible with the parsed type. It preserves lexical letters (including ё), punctuation inside names, and numbers. Prefixes: п, п., г, г., с, с., д, д., х, х., ст, ст., пгт, пос., дер. Matching uses exact resulting alias and region. Type is ignored when counting all plausible unresolved alias competitors. Explicit county must agree. A missing-county competitor blocks the county rule; missing-county endpoints require region-unique aliases and previously accepted points in both components within 5 km. Known events, repeated years, component county contradictions, shared same-year points, conflicting accepted alternatives and contradictory native coordinates block candidates.

Only 11 selected observation names retain a requested printed prefix; most selected names have already been parsed. Six pair opportunities remain, of which four are already connected and two are new. Both new edges have explicit same-county support. Neither uses a missing-county exception.

The two candidate current-year point uses copy accepted historical-component representative points. They are explicit continuity inferences, not historical measurements or independent provider identifier bindings.

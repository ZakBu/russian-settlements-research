# Омонимы: одинаковые имя, тип, регион и явный район

Принятие требует одного исходного НП с этим ключом в каждом году. Район берётся из поля источника, не из догадки по населению или порядку строк. Нормализация убирает только обозначения административного уровня; изменение топонима района не скрывается. Есть принятая точка хотя бы одного конца. При двух точках расстояние до 5 км. Общие точки разных объектов, противоречащие кандидаты и повтор года в графе удерживаются. Перенос точки обозначен как пространственная преемственность, границы и численность не объявляются сопоставимыми.

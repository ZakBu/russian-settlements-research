# Массовый исторический слой1979/1989

Актуальный русский отчёт: docs/RSFSR_1979_1989_RU_20261014.md. Таблица population_1979_1989_long.parquet/CSV.gz хранит выбранные источниковые наблюдения, точки, происхождение, связьroot и ограничения. Это смешанный тип населения, не однородное национальное покрытие. integration_receipt.json фиксирует входы/выходы; validate.py проверяет хеши, суммы, уникальность, точки, пол и наличие записей пяти лет.

# A112 v5: Voronezhsky sovkhoz 2002→2010 source review

This packet contains one same-place edge candidate for parent application review and the already accepted current point context. It makes no canonical changes and claims no new population.

The 2002 regional workbook has one exact settlement record: `посёлок птицесовхоза "Воронежский"`, population 1,774, under the Voronezhsky rural council in Novousmansky district (physical row 1,167). The 2010 regional workbook has one corresponding row, `посёлок совхоза "Воронежский"`, population 1,876 (row 7,516). The current 2021 source has one exact name/type row, population 1,846, under Novousmansky municipal district, with OKATO 20225885001 and an accepted own-locality point.

The 2009 classifier has one code-bearing record `п свх "Воронежский"` with OKATO 20225885001. This directly ties the current row to the same named state-farm locality, accounting for the older `птицесовхоза` wording. There is no 2011 GeoKLADR record for this code, so the packet does not use it as a coordinate bridge. The existing Graph68 component snapshot places the 2021 row in the 2010 row’s component and marks its own point accepted. If the candidate edge passes the root’s current graph collision check, it adds the 2002 year to that existing 2010/2021 component.

Exact row locators, hashes, point context, and source pins are in the candidate CSV and `receipt.json`.

# Первичные НП переписи 1989: улучшенная геопривязка

Фактически представлены **3 542 НП и 110 100 916 жителей наличного населения**. Из них **3 541 НП / 105 640 492 жителей** привязаны к существующим accepted собственным точкам; **Ленинград / 4 460 424 жителей** — к отдельно разрешённой существующей федеральной репрезентативной точке. Это разные координатные роли, не повышение качества ownpoint. Исходные 3 803 НП / 112 048 688 жителей не выдаются за полностью связанные: остаток 261 НП / 1 947 772 жителей.

Первый результат сохранён в `baseline_receipt.json` (3 235 НП / 100 145 356). Финальные `primary_bindings.csv`, `primary_bindings.parquet` и `receipt.json` воспроизводит `bind.py`. Реестр 2002/2010/2021 читается пакетами Arrow; исходные городские и сельские CSV сохраняются без изменений. SHA256 входного core и федеральной оси, выходов указаны в receipt.

Правило: буквальное нормализованное имя + явно квалифицированный исторический регион + физический тип. Исторический город при конкуренции квалифицируется текущим типом город; исторический ПГТ — город/пгт, при отсутствии таких кандидатов сохраняются сельские кандидаты, без искусственного запрета преобразования типа. Все первоначальные roots разных типов сохранены в all_type_candidate_roots. Точное административное название может разрешить одноимённость. Новейший однозначный физический snapshot выбирается 2021→2010→2002; несвязанные старые roots сами по себе не доказывают конкурирующие места. Старые конечные собственные точки дальше 5 км остаются настоящими конкурентами и блокируют такой выбор. Никакие графовые рёбра/roots не меняются.

Конечная existing accepted точка выбирается по самому позднему подходящему году. Поглощённые НП могут использовать собственные точки старых лет при однозначном квалифицированном имени. Координатная роль ordinary — accepted_settlement_ownpoint_reused_as_historical_reference. Современный ориентир является ретроспективной интерпретацией; сравнимость границ unknown, полная трёхлетняя непрерывность не утверждается.

Единственное федеральное исключение — Ленинград: source_cityproper 4 460 424, координаты 59.9390012 / 30.3158184 из уже принятой common federal axis, source UID 2021:…:126656. Статус bound_existing_territorial_reference_as_historical_city_center_inferred_continuity, coordinate_role=accepted_territorial_reference_point_used_for_historical_city_center_inferred_continuity. Это репрезентативный городской ориентир, не центроид территории. Население полной федеральной территории не заимствуется; дочерние НП сохраняют собственные исходные UID и не заменяются федеральной численностью. Москвы касается такое же ограничение city_proper_not_full_federal_territory; фактически она использует существующую ordinary accepted точку.

Региональные алиасы записаны явно в region_aliases.json. По исходным HTML-заголовкам исправлено перенесённое первым парсером квалифицирующее имя после переименованных горсоветов; замороженные источники сохранены. Явные исторические названия городов используют существующие проверенные reference bindings и разрешённые пары: Горький→Нижний Новгород, Куйбышев→Самара, Калинин→Тверь, Орджоникидзе→Владикавказ, Иошкар-Ола→Йошкар-Ола, Георгиу-Деж→Лиски (исходный горсовет прямо помечен ныне Лискинский). Неполные буквальные суффиксы `(рц` убраны только из имени для поиска, исходная строка сохранена. Ни fuzzy matching, ни численность как критерий выбора не используются.

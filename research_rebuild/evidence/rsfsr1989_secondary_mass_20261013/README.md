# Вторичные буквальные наблюдения населения 1989 года

Восстановлены 8 375 уникальных утверждений P1082 для 8 374 собственных населённых пунктов либо явно выделенных исторических городских субъектов Москвы и Ленинграда. Сумма по одному значению на субъект: 74 323 681–74 323 762; один субъект имеет противоречащие значения. Это сумма восстановленных источниковых наблюдений, **не подтверждённый национальный итог переписи**.

Извлечены только буквальные датированные значения 1989 года из существующего общероссийского кеша Wikidata; deprecated и неизвестные ранги исключены, повторные строки одного GUID удалены. Привязка: уникальный собственный код НП из 10/11 цифр (допустим ровно один ведущий ноль), буквальное имя и согласующаяся собственная принятая точка; дополнительно допускается существующая уникальная собственная привязка QID/P625 с теми же проверками имени и точки. Восемь цифр муниципального кода не превращаются в код НП. Новая административная кодировка издателя — недатированное источниковое утверждение, не юридическая история границ.

Москва и Ленинград представлены как исторические **города**, а не население нынешних федеральных территорий вместе с дочерними НП. Крым и Севастополь исключены из обычной привязки РСФСР. При объединении с первичным источником нужно вычитать пересекающиеся UID: в списке 62 городов совпадают 34; непересекающаяся вторичная сумма составляет 51 213 553–51 213 634. Эту сумму нельзя автоматически прибавлять к итогам источника иной территории/сферы населения.

У плоского кеша не сохранены квалификаторы, единица количества, точность даты и ссылки утверждения. Эти поля явно UNKNOWN; каждое наблюдение secondary/primary_unverified, сопоставимость исторических границ UNKNOWN. Принятая современная точка — только ссылка, не историческая координата. Значения не заменяют первичные данные. Данные Wikidata CC0.

`collect.py` воспроизводит извлечение; `validate.py` проверяет все сырые строки, уникальность GUID и UID. `receipt.json` фиксирует входы, SHA256, удержанные случаи и исходящие файлы. Parquet доступны здесь и в `/workspace/scratch/rsfsr1989_secondary_mass_20261013/`. Достичь 120 млн только этими кешированными наблюдениями не удалось; крупные города без буквального утверждения 1989 года не заполнялись догадками.

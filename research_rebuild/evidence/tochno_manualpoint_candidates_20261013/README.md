# Проверка новых координат «Если быть точным» и переноса по принятой цепочке

Воспроизведение: `python audit.py`. Вход — применённое состояние `/workspace/scratch/tochno-enrichment-20261013/applied/`. Межверсионные ссылки взяты из уже проверенного присоединения собственных строк 2021 года. Хеши снимков, документации и принятых событий закреплены в `receipt.json`. Исходные значения не менялись; национальное применение не выполнялось.

Первый приоритет — перенос уже принятой точки внутри уже принятой компоненты идентичности. Проверка допускает ровно три конечных аддитивных наблюдения НП, уникальные годы 2002/2010/2021 и минимум одну принятую точку. Исключаются федеральные города и Крым, части/агрегаты, известные принятые события, противоречащие исходные координаты и совпадение донорской точки с другим объектом целевого года. Принятые донорские точки должны согласовываться в пределах 5 км. Только две компоненты имеют недостающую точку; обе удержаны из-за расхождения уже принятых донорских точек. Допусков и прироста нет. Новые связи идентичности не создаются.

Второй приоритет — новые поля версии v20260925. У 148 собственных строк 2021 года внутри обычной полной принятой трёхлетней цепочки отсутствует принятая точка и есть конечные сводные координаты нового источника. `latest_native_coordinate_routes.csv` сохраняет нативный UID, исходную строку новой версии, код, название, население, правило межверсионной привязки, ссылку Яндекс и исходный кандидат координат. Это кандидаты, а не принятые собственные точки.

Описание набора (раздел 2 и атрибуты 10–12) прямо указывает смешанное обогащение DaData, Википедией, ФИАС и ручной проверкой. Поля `latitude`/`longitude` не имеют построчного признака ручного происхождения. `yandex_maps` определён как ссылка на НП, но проверенные фактические ссылки — вид карты `maps/?ll=долгота_%2Cширота&z=15`; они повторяют сводные координаты и не содержат идентификатора объекта Яндекс. Поэтому ручное происхождение и связь внешнего идентификатора не утверждаются. Из нового файла не принята ни одна точка на основании такого предположения.

`held_components.csv` содержит причины, `accepted_point_use_delta.csv` — пустую схему точек, `projected_new_credits.csv` — пустую схему предварительного прироста. Координатная правильность, связывание идентификатора провайдера, историческое прямое измерение и сопоставимость границ остаются отдельными утверждениями.

# Moscow inner-territory child localities (bounded review)

This packet supplies representative physical-locality points and an explicit source-year availability path for the four additive 2002 Moscow child rows. It is a spatial-axis addition only. It creates no population-year credits and no ordinary census-history identity edges.

The 2002 source is official TOM1 table 4, sheet 01-04, rows 2292, 2299, 2300, 2301. The reviewed Moscow territorial override identifies exactly these four plus Moscow row 2155 as children of the 2002 parent row 2154 (10,382,754), with exact total conservation. The territorial overlay continues with Moscow territory totals in 2010 and 2021. Do not sum child populations atop the Moscow territory total.

For 2010/2021, the project’s accepted federal-territory layer has a Moscow territory observation, not an individual count for these four localities. This packet records those years as not separately published on the territory layer; it does not assert zero, disappearance, or a 1:1 population series. No district or aggregate residual is assigned to a child.

Point semantics: each point is a representative location of the named physical place, reused for the 2002 source row. None is an exact census-day coordinate or settlement polygon. Vostochny uses a settlement history source; the Moscow district article coordinate was deliberately excluded. Vnukovo uses the former PGT article, not the airport or modern district. Nekrasovka is limited to the old locality, excluding post-2011 Lyubertsy Fields; exact historic boundaries remain unknown.

Point credit claims are distinct from population credit. The outside-common audit flags all four as lacking accepted baseline own points. Any integration should add only the spatial representative uses and leave coverage denominators, native population totals, and primary/uncredited population accounting unchanged.

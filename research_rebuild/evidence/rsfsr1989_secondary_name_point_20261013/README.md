# 1989: вторичная привязка физического НП по имени и собственной точке

Код не обязателен для этой отдельной привязки: точное буквальное имя и единственная P625 кеша должны совпасть с единственным собственным физическим НП 2021 с принятой точкой в пределах 5 км. Точка квалифицирует место/регион; НП Крыма и Севастополя исключены. Уже выбранные текущие субъекты и конкурирующие QID не получают повторного кредита. По первому географическому правилу прошло 1 401 кандидата.

Проверены полные Wikidata P31/P1082/P625 всех кандидатов, 50 предметов за HTTPS/TLS запрос. HTTP429 соблюдался с Retry-After=15 сек; повторные запросы ограничены и между сетевыми запросами 4 сек. Определения типов сохранены в class_batch*.json: город, пгт, село, деревня, посёлок, хутор, аул, станица и документированные подтипы. Муниципальные P31 блокируют даже при наличии физического типа; административный тип без физического типа также не допускается. Дополнительно требуются единственная актуальная P625, согласие собственной точки, точный GUID/количество/год, единица 1, допустимый ранг и отсутствие явных subset-квалификаторов.

Принято **1 397 новых GUID/субъектов и 1 828 722 человека** относительно варианта OKATO. Удержаны четыре кандидата: муниципальные/смешанные/административные типы либо неоднозначная полная P625 (Деденево). Полный заменяющий набор: 10 050 собственных субъектов/исторических городских ссылок, 10 051 утверждение, сумма 78 514 614–78 514 695. Это источниковая вторичная сумма, не национальный подтверждённый итог переписи. Окончательное объединение с первичными источниками требует приоритета первичного значения и дедупликации anchor/root; эту новую сумму нельзя прибавить к старому полному набору.

Основание наличное/постоянное и исторические границы остаются UNKNOWN. Полные JSON утверждений с P459 (метод), P1013 (основание), P585 (точность года), ссылками, P31/P625 и хешами ответов встроены в новые строки Parquet. Разнородные методы не объявляются единой переписью. Современная точка — только явная ссылка, не историческая координата. Никакое неизвестное значение не заменено нулём.

`run.py` и `enrich_and_validate.py` воспроизводят маршрут; replay всех 10 051 исходных строк PASS, повторных GUID/anchor bindings нет. Полные ответы API живут вне Git в scratch/api_cache и перечислены с хешами в API_response_manifest.json. Компактные CC0 Parquet находятся здесь и в scratch. Входные замороженные файлы не изменены. Модульный preflight рядом — только инвентарь следующей отдельной проверки, не принятые значения.

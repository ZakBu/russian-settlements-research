# Косая Гора: отдельная переписная запись до включения в Тулу

Закон Тульской области от 06.07.2005 № 594-ЗТО прямо называет посёлок
городского типа Косая Гора среди территориальных единиц, присоединённых к
городу Туле. Страница текста закона, полученная из ГАРАНТ по адресу
`https://base.garant.ru/30313721/`, сохранена рядом. Точная дата официального
опубликования и вступления закона в силу в сохранённом тексте не установлена;
известен год преобразования.

Официальная строка переписи 2002 года: 18 131 житель (Том 1, таблица 4, строка
1949; исходная метка «пгт Косая Гора»). Для физического места взята точка
GeoNames RU PPLX 54.118960, 37.544590 (ID 544293), связанная с Wikidata
Q4234809 через P1566. Wikidata P625 (54.116389, 37.560833) находится примерно
в 1,1 км. Обе точки подтверждают локальный масштаб места; ни одна не является
переписным измерением.

Получателем территории выступает город Тула. Его выбранные официальные итоги
2010 года (501 169) и 2021 года (473 622; ОКТМО 70701000001) приводятся только
как контекст: отдельную численность бывшей Косой Горы в эти годы не создаём и
не прибавляем Тулу поверх уже учтённой строки города. В 2002 году старая
отдельная запись локализуется собственной точкой; это событие-включение, а не
обычная трёхлетняя `same_place` связь. Сопоставимость границ и населения с
Тулой в целом остаётся неизвестной.

Результат изменяет только event-aware пространственное покрытие 2002 года.
Обычный identity graph и знаменатели переписей не меняются. Воспроизвести
пересчёт можно командой:

```sh
python research_rebuild/mass_linkage/recompute_event_aware_coverage_with_kosaya_gora_20261005.py
```

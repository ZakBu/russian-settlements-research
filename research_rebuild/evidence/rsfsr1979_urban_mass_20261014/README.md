# РСФСР 1979: массовое извлечение опубликованной городской таблицы

Получены **3045 именованных городских НП**: 1002 строки «г.», 2039 «пгт», 4 «кп». Сумма наличного населения **95 373 867 человек** точно совпадает с независимо извлеченным опубликованным общероссийским городским итогом другой таблицы reg1. Все 3404 числовые строки reg2 удовлетворяют оба пола = мужчины + женщины. 359 внутригородских подразделений сохранены отдельно и исключены из суммы НП. Точное совпадение итогов является проверкой извлечения опубликованной рамки, а не доказательством исторической идентичности, координат или отсутствия проблем закрытых городов.

Источник: https://www.demoscope.ru/weekly/ssp/rus79_reg2.php — «Всесоюзная перепись населения 1979. Таблица 1с. РГАЭ. Ф 1562. Оп. 336. Д. 5943–5951». Машиночитаемая публикация Демоскопа архивной первичной таблицы; изображения архивных дел не просмотрены. Наличное население установлено оглавлением переписи и контрольной таблицей https://www.demoscope.ru/weekly/ssp/rus79_reg1.php. Запросы 2026-10-14 прошли HTTPS с нормальной проверкой TLS, без insecure-флагов. Сырые HTML в `/workspace/shared/rsfsr1979_urban_mass`; SHA-256 каждой версии, размер и локатор записаны в `receipt.json` и строках CSV.

`urban_settlements_1979.csv` — факты непосредственно из источника; `all_numeric_source_rows.csv` — те же факты вместе с внутригородскими подразделениями; `official_controls.csv` — опубликованные итоги наличного городского, сельского и всего населения РСФСР. `source_headers.json` сохраняет заголовки. `ingest.py` воспроизводит извлечение (Python + bs4). HTML tr — порядковый номер всех tr документа начиная с 1; берутся только непосредственно вложенные td/th. Тип НП допускается только при явном префиксе, заголовки и городские районы не становятся НП. Для федеральных городов имеются явные правила контекста: «Ленинградский горсовет» и «г. Москва и населенные пункты,подчиненные Московскому горсовету». Все 88 исходных региональных контекстов сохранены, включая вложенные автономии.

Факты остаются `source_native_unlinked`, `candidate_not_accepted`, `not_admitted`: эта работа не принимает ребра идентичности или координаты. Для повторных имен необходим административный контекст; receipt перечисляет четыре группы повторов имени в регионе. Исходные пояснения «ныне» в имени не удалены. Постоянное население здесь не извлекалось; наличные и постоянные числа нельзя подменять или складывать.

Москва в native1979 таблице — 7 830 509, Зеленоград — отдельные 129 820; подчиненные поселения тоже отдельны. Ленинград — 4 072 528 с отдельными подчиненными НП. Нельзя приравнивать собственно город к полной федеральной территории или второй раз добавлять дочерние НП поверх территориального итога.

`book_spot_comparison.csv` сопоставляет 12 крупнейших городов с уже прочитанными 1979 клетками книги «РСФСР. Городские поселения», 1991, которая описывает городской реестр 1989 и ретроспективные числа. Равенство 9 из 12; различаются Москва (7 830 509 здесь / 7 933 034 в книге) Куйбышев/Самара (1 216 233 / 1 206 133) и Уфа (969 289 / 978 477). Обе версии сохранены: возможны различия территориальной рамки или публикации, которые требуют отдельного подтверждения; книга не переписывает native1979.

Закрытые города/ЗАТО: полнота отдельных закрытых НП не утверждается. Контрольное совпадение не исключает исходного распределения закрытого населения внутри публиковавшихся агрегатов. Вторичные численности закрытых городов не добавлены поверх первичной таблицы; остаток не распределен, неизвестное не превращено в ноль. Для допуска таких строк нужны отдельное доказательство рамки и исключение двойного счета.

Полные факты 1979 сформированы до индивидуальных досье. Никакие файлы 1989, core или Git этой работой не изменены.

## Дополнение: сельская публикация reg3

`rural_centres_1979.csv` извлекает **868 явно именованных НП**, наличное население **5 184 291**. Заголовок источника называет сельские райцентры, однако реальные строки также включают дополнительные поселения (например, подмосковные дачные поселки без отметки «рц»). Поэтому это опубликованная ограниченная сельская таблица, а не полный сельский реестр и не только строки с явной отметкой райцентра. Сырые типы сохранены; тип «дп» в этой таблице сам по себе не переводит наблюдение в городской reg2. Совпадений по буквальному региону + очищенному имени + исходному типу между reg2 и reg3 нет; это ограниченная проверка возможного двойного счета, не доказательство полной непересекаемости исторических рамок.

Цитата: «Всесоюзная перепись населения 1979 года. Таблица 1с. РГАЭ. Ф 1562. Оп. 336. Д. 3831–3838». Нормальный TLS-запрос к `https://demoscope.ru/weekly/ssp/rus79_reg3.php` оказался успешным после двух timeout на www-хосте. SHA-256 HTML `27fc0a340bf778f4a9bc3b8ec862c546b0328385b44dca5b3edfd7efe7743d12`; HTML сохранен вне Git. Все 868 строк удовлетворяют балансу полов. Ни одна числовая строка не осталась без явного типа; parser поддерживает буквальные «станция», «поселок», «хутор», а исходные кавычки/опечатки сохраняет. Последняя точка исходного имени убирается для служебного parsed-name; исходная строка не меняется. В HTML нет районных заголовков для этих НП, поэтому административные районы нельзя выдумывать.

`rural_source_headers.json`, `rural_centres_all_numeric_1979.csv`, `rural_receipt.json`, `ingest_rural.py` сохраняют факты и воспроизводимость. Общий сельский контроль РСФСР 42 177 082 в `official_controls.csv` не является контрольной суммой этой ограниченной выборки. Остаток не распределен. Никакого прироста принятого покрытия эти исходные факты сами по себе не утверждают: привязки и координатный допуск выполняются отдельно.

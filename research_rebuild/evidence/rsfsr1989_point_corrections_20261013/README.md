Отдельная поправка точки Октябрьского

Замороженный Delta2 ошибочно связал строку Demoscope tr1312 (Скопинский горсовет, 5599 человек наличного населения1989) с одноимённым Октябрьским Михайловского района Q2017643. Собственная статья «Октябрьский (Скопин)» публикует точку53.789949,39.476222 и явно описывает бывший рабочий посёлок, включённый в Скопин2004. Таблица населения статьи отдельно подтверждает5599 за1989; число в поправке берётся только из Demoscope.

JSON применяется по source_record_id. Новый самостоятельный исторический root не утверждает связь с современной переписной записью. Q4333090 оставлен лишь кандидатом; external_id пуст. Точка относится к опубликованному собственному бывшему посёлку, не к центру Скопина. Границы и ретроспективная непрерывность неизвестны/предполагаются соответственно. Исходные Delta2 и core не изменены.

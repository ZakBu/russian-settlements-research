# Bounded native rural type and printed designator continuation

This packet uses actual State50: explicit `load(49)` followed by the frozen native2010_remaining_county_rule_mass stage50 application. It does not depend on a mutable report, does not duplicate EAO stage51, and excludes all EAO records. The frozen stage49 mixed/direct/formation scope snapshots are unioned with actual State50 finite native histories to measure exclusive source-ID gains.

Discovery targets ordinary, currently pointed, already accepted native2010–2021 components lacking native2002. It retains every same normalized own-name regional rival in all three censuses before filtering by independently sourced county and compatible rural settlement class. Native county uniqueness is required; region uniqueness is only a shortcut. Three named already accepted native full3 histories may establish a specific historic/current county caption association. Literal printed type and ownership designator abbreviations are normalized deterministically; no fuzzy name aliases, population equality, growth limits or new counts are used.

Every accepted old row has an independently printed historical county header and exact raw own label/count leaf witness. Adjacent type/name cells may form the exact published label. Real same-county native2010 rivals, repeated graph years, missing or contradictory historic source county and conflicting physical points are held. A current own physical point is reused only as a representative identity point, without asserting an historical census coordinate or boundary comparability. Source population, quality, names and types remain unchanged.

`prepare.py` creates the source checks, rivals, accepted edges/points and receipt. `apply.py` independently verifies pins and replays the exact State50 before/after. `verify_mixed.py` reproduces the frozen State50 axes and computes native source-ID union differences for finite, original mixed, direct lifecycle and formation axes. The receipts are authoritative for counts and outcomes.

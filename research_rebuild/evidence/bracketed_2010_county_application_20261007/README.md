# Районный контекст строк 2010

Приняты однозначные целые НП между двумя уже связанными разноимёнными строками той же таблицы, не дальше 20 физических строк с каждой стороны. Оба якоря имеют один район в принятых 2021 цепочках, а у объекта район подтверждён в 2002 и 2021. Имя, тип и регион совпадают, 2002–2021 уже связаны, конкурирующие строки и события исключены при генерации. Исходный район 2010 не переписан: контекст — явный вывод. Проверены буквальные строки всех применённых скобок. Точки перенесены как пространственная преемственность; независимость старых координат, границы и точность защищённых чисел 2010 не заявлены. Неперенесённые книги удержаны для отдельного восстановления источника.

# Priority additional rural 1989 source search — 2026-10-14

No new 1989 settlement populations were obtained. This package records a bounded search and prevents mistaking the four readily available 2002 regional workbooks for comparative 1989 sources.

Existing archives/manifests were checked first. `existing_workbooks_audit.json` pins all four exact workbooks and their worksheet structure. The 6,481 explicit rural-type 2002 reference rows are outside Git at `/workspace/shared/rsfsr1989_additional_rural/priority_2002_np_reference_rows.csv`; each retains source SHA-256, sheet/cell locator, literal count and explicit absent-1989 status. These are reference rows, not additions to 1989 or linkage admissions. Type-prefix extraction is conservative and incomplete for some railway/special types; its sums are not comprehensive coverage claims. Missing type rows and administrative residuals were not allocated.

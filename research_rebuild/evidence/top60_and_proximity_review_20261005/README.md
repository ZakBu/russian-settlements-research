# Топ-60, совпадающие точки и 5-км связи

Этот выпуск инвентаризирует 60 крупнейших записей без принятой прямой точки, координатные коллизии всего принятого графа и межгодовые кандидаты точного нормализованного имени/региона в радиусе 5 км. Тип записи остаётся отдельным признаком: смена типа может быть реальным событием и сама по себе не доказывает сопоставимость населения. Скрипт не меняет принятые реестры.

`top60_coordinate_and_identity_candidates.csv` отделяет принятые точки от сырых точек поставщика, GeoKLADR и Wikidata; `top60_existing_point_carrier_candidates.csv` перечисляет совпавшие по точному имени/типу/региону записи с уже принятой точкой. Это кандидаты, а не связи. `accepted_same_year_coordinate_collisions.csv` перечисляет записи с одинаковой принятой точкой внутри года. `new_component_compatible_candidates_within5km.csv` содержит новые пары с точками, совместимые по текущему графу; все строки требуют проверки событий, охвата и исходных ограничений.

5 км — радиус поиска, а не точность координат. Полные SHA-256, counts и ограничения — в `summary.json`.

### 2026-10-05: упрощённое применение правила

По запросу применено простое массовое правило к новому набору точек: одинаковые нормализованные имя и регион, взаимно ближайшая пара, расстояние до 5 км, отношение положительных численностей не больше 2. При объединении весь текущий граф проверен на наличие двух записей одного года в компоненте. Из 937 новых кандидатов приняты 336 межгодовых связей; при полном добавлении пакета конфликтов по годам не возникает. Ещё 117 положительных пар за пределом 2x и все 10 пар за пределом 20x оставлены в исключениях; по 479 парам с нулём/неизвестным значением коэффициент изменения не вычисляется, они не включены в автоматическое принятие. Числа переписи не исправлялись.

Из топ-60 записей без прямой принятой точки перенесены уже принятые точки на четыре точные уникальные пары: Дыгулыбгей-2010, Дубовка-2010, Цибанобалка-2021, Углекаменск-2021. Население этих строк — 29 170 в 2010 и 10 940 в 2021 году; в 2002 году точек из топ-60 этим шагом не добавлено. У новой точки каждой строки нет точного совпадения с другим принятым point-use того же года. Сырая ошибочная общая точка поставщика для Цибанобалки не перенесена; использована точка принятой исторической записи GeoKLADR.

Добавлено 340 решений связи (336 массовых + 4 топ-60) и 4 point-use в виде небольших additive CSV delta-таблиц в `simple_rule_application/`. Полные базовые ledgers не перезаписаны. Число 336 — результат правила по всей когорте, не оценка точности по выборке. 60 строк фиксированной выборки сохранены как диагностический срез; без независимой разметки истинности он не даёт доверительного интервала false-match rate. Ни сопоставимость границ/населения, ни точность точки на дату переписи не заявлены.

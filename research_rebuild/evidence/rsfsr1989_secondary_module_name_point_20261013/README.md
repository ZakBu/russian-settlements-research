# Дополнительные буквальные утверждения 1989 года из статистического модуля

Модульный кеш содержит 2 115 буквальных утверждений 1989 года. После исключения QID принятого OKATO-набора и уже проверяемого маршрута имени/точки осталось 251 (максимальная сырая сумма 562 227). Из них 115 имели единственную доступную модульную координату и собственный принятый НП 2021 рядом. Этот preflight — только кандидатная очередь; исходные международные предметы не дают кредита без уникального российского собственного НП.

Все 115 предметов проверены полным Wikidata API: буквальная метка, единственная P625 и собственная принятая точка в пределах 5 км, физический тип P31 без муниципальных/смешанных типов, уникальные текущие anchor/root, точный GUID/количество/1989 год, единица 1, допустимый ранг и отсутствие явных subset-квалификаторов. Принято **85 новых GUID/субъектов, 17 285 человек**. Остальные удержаны главным образом по отсутствию точного уникального имени/собственной точки. Аналогичные названия и отсутствующие координаты не достраивались.

`additional_module_population_1989_long.parquet` — только эти 85; полный заменяющий набор `secondary_population_1989_long.parquet` включает предыдущий main name/point набор: 10 135 субъектов, 10 136 наблюдений, сумма 78 531 899–78 531 980. Не складывать полный набор и дельты. Итоговая интеграция с первичными источниками требует первичного приоритета и дедупликации anchor/root. Ни одна сумма здесь не объявлена подтверждённой национальной переписью или достижением 120 млн.

Основание населения и сопоставимость исторических границ UNKNOWN; метод P459, основание P1013 и точность P585 сохранены в JSON полного утверждения. Все новые строки содержат P31/P625/источниковые ссылки и SHA ответа API, строку исходного population.jsonl.gz и строки entity.jsonl.gz. Современная точка — ссылка, не историческая координата. Исходные замороженные наборы не изменены.

`run.py`, `enrich_validate.py`, receipt/validation и кандидатный preflight воспроизводят проверку. Replay всех 10 136 источниковых строк PASS; повторов GUID и anchor bindings нет. Полные ответы API находятся вне Git в scratch/api_cache; compact Parquet и JSON доказательств доступны здесь. Wikidata CC0.

Числа относятся к выбранным переписным записям, не к уникальным местам за все годы. Отсутствие прямого point-use на точном ID источника не исключает кандидата или отдельного пространственного представления через территорию, событие либо объединение частей. Федеральные итоги выделены отдельно. Реестры не изменялись.

Федеральные итоги без отдельного прямого point-use: Санкт-Петербург 2002; Москва и Санкт-Петербург 2010; Москва, Санкт-Петербург и Севастополь 2021. Они представлены отдельным территориальным слоем в широком показателе; это не неизвестное местоположение городов. Метка scope 2010 в selected ошибочно общая `settlement`; здесь федеральные итоги отделены по совпадению имени и региона. Полные исходные строки: `federal_aggregate_rows_without_direct_point.csv`.

Уточнение старого inventory: 2010 имеет 16 479 НП без прямой точки / 2 120 828 жителей, а не прежние 16 482 / 2 126 316. Прежний скрипт отфильтровал три уже принятые строки с пустым optional target_year (Вардане-Верино 297, Орел-Изумруд 5 167, Татьяновка 24). Точный target-source-ID join устанавливает год по selected; их координаты уже приняты. Ещё два null target_year относятся к 2021. Противоречащих непустых годов нет. Старый артефакт сохранён без изменений.

Часть численностей 2010 — защищённые вторичные значения. Исходное качество, названия и номера частей сохранены; это не подтверждение точности каждого значения. `осёлок Кудряшовский`, `осёлок Мочище` и `п Красные Ткачи` воспроизведены буквально из selected, без скрытого исправления названия.

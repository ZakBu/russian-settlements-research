# Однозначный муниципальный код при нескольких исходных строках

Для всех 78 оставшихся случаев код родительского муниципалитета однозначен: 77 нижних связей (163836 человек в исходных строках НП, 9 разных кодов) и одна верхняя связь Алеутского округа (654 человека). Это 164490 человек с более полным кодовым контекстом, без прироста покрытия населения.

У каждого случая ровно две уже квалифицированные исходные муниципальные строки. Проверены все именные кандидаты: одинаковый сырой регион, ожидаемый исходный уровень, точное имя родителя, а для нижнего уровня — также точная исходная верхняя подпись. Во всех кандидатах один и тот же существующий нормализованный код8, и он совпадает с документированными первыми8 знаками собственного кода НП11. Представление исходного кода10 восстанавливает только ведущий ноль. Некорректный код, несколько разных кодов или отсутствие такого доказательства блокировали бы допуск. Код НП8, если встретится, допускает только точное существующее кодовое утверждение с теми же квалификаторами, без вычисления иерархии.

Статус `verified_parent_code_multiple_source_claims` подтверждает кодовую ассоциацию для обращения к наблюдениям БДМО по этому коду. Он не выбирает одну из двух исходных переписных строк муниципалитета. `municipality_source_row_ambiguous=True`, `municipality_raw_attribute_row_selected=False`, `boundary_comparability_asserted=False`. История границ, сопоставимость межгодовых рядов и историческое членство НП не утверждаются. БДМО-показатели остаются муниципальным контекстом, а не собственными численностями или характеристиками НП; версии и повторные наблюдения сохраняются.

Основание структуры кода и первичное описание БДМО сохранены в соседнем `tochno_context_code_resolution_20261013`; эта работа наследует их замороженные хэши. Источник муниципальных утверждений — v20251217, перепись-источник2021, действительная административная дата неизвестна. Страна: Российская Федерация; пространство кодов: RU_OKTMO.

`accepted_code_context_delta.csv` содержит78 допустимых кодовых связей с полным списком исходных row1-локаторов. `all_source_claim_rows.csv` сохраняет все156 утверждений отдельно, включая каждый сырой код, имя, уровень, регион и верхнюю подпись. Ключ дельты: source_record_id + municipality_role; ни один единственный муниципальный row1 не объявлен выбранным. `held_code_context.csv` содержит заголовок, новых удержаний нет. Скрипт `run.py` читает только78 строк узкого предыдущего результата и шесть колонок исходного Parquet через DuckDB с явным CSV dialect.

Четыре ранее разрешённые однострочные связи и все первоначальные замороженные мосты/Parquet не изменены. Применение этой самостоятельной дельты выполняет корневой агент.

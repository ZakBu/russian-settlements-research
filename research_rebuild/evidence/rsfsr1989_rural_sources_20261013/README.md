# Сельские населённые пункты РСФСР: перепись 1989

Получена и разобрана опубликованная таблица Демоскопа «Численность сельского населения РСФСР — жителей сельских населенных пунктов — районных центров по полу»: https://www.demoscope.ru/weekly/ssp/rus89_reg3.php.

`rural_district_centers_1989.csv`: **574 самостоятельных сельских НП, 3 623 108 человек** (1 730 587 мужчин, 1 892 521 женщин). Это районные центры, а не все сельские поселения. Каждая строка сохраняет исходное название, историческую область/республику, путь заголовков, номер HTML-строки, URL, SHA256 и собственный source_record_id. Связывание с современными НП не утверждается. Мужчины + женщины = всего для всех 574 строк; повторных исходных локаторов и пар область/название нет.

`receipt.json` фиксирует проверенные суммы и хеши; `source_headers.json` сохраняет все территориальные заголовки. `ingest.py` воспроизводит CSV из сохранённой страницы CP1251. Исходный файл страницы указан в `initial_discovery.json`; при переносе скрипт автоматически ищет тот же файл рядом с собой. Скрипт не распределяет районную численность по НП.

Территориальная таблица `rus89_reg1.php` сообщает 108 425 580 городских и 38 974 957 сельских жителей РСФСР. Это контекст, не дополнительное покрытие НП. Даже при полном покрытии городского населения добавление найденных районных центров даёт максимум **112 048 688** человек; до цели 120 млн остаётся **7 951 312**. Нельзя заявлять достижение 120 млн по этим источникам. Нельзя второй раз прибавлять городские НП 1989 года, ставшие сельскими позже.

Обнаруженный официальный индекс Демоскопа переписи 1989 года содержит только территориальную таблицу, городские поселения и сельские районные центры; `rus89_reg4.php` возвращает 404. Проверенные страницы Lingvarium (включая `/russia/BD/02c.shtml`, `/russia/BD/1989.shtml`, каталог `/russia/BD/` и `/russia/`) возвращают 503 по HTTPS; HTTP-вариант проверенной страницы — 404. Это ограничение доступности на момент проверки, а не доказательство отсутствия более подробных региональных источников. Поисковая выдача в дальнейших запросах не дала извлекаемых результатов; дополнительные сельские таблицы не получены. Сырые ответы, URL и ошибки сохраняются в discovery/receipt-файлах. Региональные архивные тома и сканы требуют отдельного получения и проверки.

Отрицательные/нечисловые значения здесь не встретились; территориальные заголовки с пустыми ячейками не превращены в нулевые наблюдения. Никакие агрегаты, оценки или распределённые значения в CSV не включены.

Основание проверено по буквальному источнику reg1 и reg3: «ТОМ 1. Часть 1. Таблица 3. Численность наличного населения». Контроль и сельские строки относятся к наличному населению (`present`), не постоянному.

# Дыгулыбгей: принятый физический путь через изменения статуса

В переписях 2002/2010/2021 есть наблюдения одного села в Кабардино-Балкарии: 20 355 / 20 228 / 20 852. В 2002 году источник пишет «Дугулубгей», в 2010/2021 — «Дыгулыбгей». Записи имеют тип «село», относятся к одной республике и исторически соотносятся с Баксанским районом/городским округом. При этом нельзя приписывать селу код города Баксан или считать население самого города/округа его населением.

Для 2010 сохраняется `secondary_confidentiality_protected_value_exact_scope_unverified`. Значение 20 228 не повышено до официального точного первичного значения. Данные 2002/2021 в принятых источниках прямые; 2021 официальная таблица отдельно перечисляет сельскую строку Дыгулыбгей и проверяет сумму с отдельными городским и окружным итогами.

Принятая точка села (43.6605157, 43.5399799) из переписной записи 2021 года используется для всех лет ретроспективно. Она не является измерением на дату переписи. Отдельный event-aware путь был принят до этой записи; именно эта запись включает его в актуальную event-aware сводку. История включения села в Баксан и восстановления статуса описывается только вторичными источниками; точные юридические даты/охват не утверждаются. Сопоставимость границ и численности не утверждена.

`event_aware_coverage.json` добавляет только эти три сельские наблюдения. Канонический identity graph, национальный selected frame, отдельные городские числа и знаменатели не изменяются.

# East alternative own-place point sources, 2026-10-09

This source-only packet targets the exact 81 original missing-ownpoint whole settlement rows. The literal-part row is excluded. No identity edge, population observation, or coordinate is admitted.

`geonames_cached_own_place_candidates.csv.gz` provides 184 actual class-P GeoNames source features for 64 target UIDs. Candidates use normalized actual source own names and Russian first-order region codes, retain all namesakes, and explicitly mark guessed compound-label aliases. The original RU.txt line, actual feature ID, P-class subtype (including abandoned/historical places), administrative codes, modification date and source zip hash are preserved. Provider population fields are raw provider attributes, never census observations. Transliteration normalization and estate aliases generate candidates and establish no identity by themselves. Source archive `geonames_RU_20260907.zip` and its admin1 table are pinned in `geonames_source_pins.json`.

`nominatim_own_feature_candidates.csv.gz` preserves 88 actual OSM/Nominatim source features returned by 81 successful standard TLS searches of original own settlement name, original native county where available, and region. Source feature type/ID, point, address, extra tags, names/old names, and bounding boxes remain separate original attributes. `nominatim_capture_receipt.json` retains every exact request URL, time and response hash. Raw responses were stored in task-specific RAM; `nominatim_all81_capture_bundle.json.gz` durably preserves all actual responses together with their original capture receipts and RAM byte hashes.

Additional `nominatim_v2_*` files contain separate fallback requests for originally empty queries. They remove county wording and use exact own name or explicitly speculative estate/station-label variants; the original 81-request files remain frozen. Fallback ambiguity must be reviewed against native own codes, county/subcounty names and rival physical places.

Nominatim requests run sequentially at intervals of at least 1.1 seconds. HTTP429 stops a collection immediately, without retry loops. An OSM railway station, platform, municipality, administrative district, address building or unrelated commercial feature cannot establish the own NP point. A named residential settlement node or named residential compound footprint needs its own original scope and county confirmed. Polygon representative points are provider search centroids, not measured locality geometry. Modern coordinates have unknown measurement dates and imply no boundary comparability. All historical census populations are unchanged.

The East agent owns all review and admissions, using independently reopened native source headers, codes and any supported old-name/type history. `receipt.json` and `asset_manifest.json` record this collection and preserve input/output pins.

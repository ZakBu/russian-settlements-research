# Применение крупного пакета межгодовых связей

Применены связи из соседнего source-reviewed пакета с проверкой каждого выбранного исходного ID, года, численности, SHA и отсутствия повторного года в компоненте. Точки целого НП перенесены по принятой идентичности, варианты названий подтверждены в исходном разборе. Исходные числа, включая защищённые 2010, не изменены; расхождения с официальными альтернативами сохранены в рецензии. Нет утверждения об неизменных границах.

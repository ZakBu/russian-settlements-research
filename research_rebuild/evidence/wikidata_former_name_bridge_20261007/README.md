# Own-entity former-name bridge, candidate reserve only

54 new candidate edges and 47 candidate point uses. The stage-11 simulation adds full-three-census covered population of 15,989 (2002), 16,636 (2010), and 14,944 (2021). No accepted ledger is modified and every output edge/point remains candidate_only. Root must independently reproduce the pinned baseline and review before admission.

The finite pool is cached own-entity Russian aliases/P1448 and own Wikipedia former-name infoboxes attached to existing exact-code/current-own-label Wikidata bindings, plus one two-QID live API fetch. 1,248 former-name witnesses yielded 2,226 unique old/current pairs: 100 existing connections excluded, 2,072 conflicting/context-deficient pairs held, 54 eligible. This is the actual unprocessed candidate reserve, not repeat counting of the ordinary same-name county pool.

Eligibility requires exact own former-name witness, same source region, explicit matching county (or the documented Berdykel county transfer), unique locality name within year/county, no repeated-year graph, an accepted current locality point agreeing with its own entity P625 within 5 km, and accepted old/current points within 5 km where both exist. Existing old source point candidates over 5 km and an old-name locality still separately present in the current county block eligibility. Printed type differences are retained; alias evidence is distinct from dated rename evidence. Boundaries and population comparability are not asserted. Point transfer is representative-point continuity, not a historical coordinate measurement.

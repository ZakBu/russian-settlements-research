# Власиха: принятый путь 2010–2021

Для Власихи есть одобренная физическая преемственность между двумя годами: официальная строка Росстата 2010 года и выбранная переписная строка 2021 года. Значения населения — 26 359 и 28 240. В 2010 году старый вторичный слой содержал 25 394; эта альтернатива сохранена, а первичным значением выбрана строка официального Росстата.

Для Московской области официальная таблица 2002 года не дала строки Власихи этого типа/региона. Поэтому 2002 не добавляется, не получает ноль и не входит в трёхпереписную цепочку. `event_aware_coverage.json` считает только зарегистрированные 2010 и 2021 годы как один принятый двухлетний путь.

Для обеих записей применяется текущая принятая репрезентативная точка Wikidata P625: 55.685000, 37.191667. Это не историческое измерение, не привязка внешнего идентификатора к старой переписной записи и не основание считать границы/охват населения одинаковыми. Современный ОКТМО 46773000051 относится к текущей записи 2021 года; историческое преобразование ОКТМО не утверждается.

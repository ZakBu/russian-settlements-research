Результат получения данных

Скачаны полные JSON-тела каталога оператора Wildberries из Wayback, сохранены исходные gzip, HTTP-заголовки и распакованные JSON. Это реальные данные объектов, а не ссылки на возможные источники. Снимки датированы фактическими архивными захватами и заголовками memento-datetime/original HTTP date. Дата коммита ни в одном случае не заменяет дату наблюдения.

Для всех семи исходных gzip SHA1-base32 совпал с CDX digest; локально закреплены и SHA256 исходного тела, и SHA256 распакованного JSON. Каждый раздел ru имеет уникальные ID. Все нормализованные координаты присутствуют и укладываются в допустимые широту/долготу. Это техническая проверка, не независимое подтверждение каждого адреса или работы пункта.

Готовый объектный слой

wb_history_normalized.parquet:197822строки всех стран;186615строк разделов ru;семь архивных дат. Поля включают дату и timestamp захвата, ID, страну источника, адрес, широту/долготу, исторические typePoint/pickupType/dtype/isWb/isHkn/isSortCenter/isExternalPostamat/status, число примерочных, время работы и исходный URL. Столбец client_point_confirmed_from_flags оставлен неизвестным: содержимое флагов не превращено автоматически в доказанный тип обслуживания. opening_date неизвестна.

wb_history_ru_normalized.csv.gz — тот же объектный слой только ru для чтения без Parquet. Присутствие ID в снимке означает его цифровое присутствие в каталоге на эту дату, а не открытие тогда. Отсутствие в другом снимке не объявляется закрытием. Раздел ru — метка оператора, не проверенная неизменная государственная граница.

Схема типов существенно изменилась

В снимках2022/2023 поля typePoint нет. Есть альтернативные сырые pickupType3/4, isWb, dtype и отдельные технические флаги, но их историческая семантика не подтверждена внешней спецификацией. Они сохранены; обратного присвоения текущего типа старым surviving ID не выполнено.

В2024 typePoint присутствует у34371из35105ru-объектов. Распределение:1—11018;8—19917;7—2946;5—432;прочие58;неизвестно734. Уже это не совпадает с современным focus8/34.

Переходы наблюдаются только среди сохранившихся ID и служат диагностикой схемы, не готовой классификацией исчезнувших объектов или всех исторических типов. Таблица WB_type_transitions.csv содержит полную матрицу как для всех общихID, так и для совпадений<=100м.

Примерочные: полезный сырой признак с изменившейся полнотой

Поле fittingRooms существовало во всех исторических снимках. Но заполнено оно не одинаково. На29.09.2022:17833/22792записей,изних17825>=1;на11.03.2024:30131/35105,изних30124>=1;в принятом снимке21.10.2026:91039/91043,изних78268>=1. Встарыхсрезахпочти5000пропусков,в2026только4.

Среди общихID2024/2026 с координатами<=100м:26040имеют>=1примерочной в обоих снимках;3804имеют пропуск в2024 и>=1в2026;34переходят positive→zero;6zero→positive. По3804невозможно отделить улучшение заполнения от реального появления примерочных; однако сами ID уже присутствовали в старом каталоге, и считать их вновь появившимися объектами нельзя. Исходы «точки с заявленными примерочными» допустимы с отдельным учётом этой неполноты, но не равны всей сети ПВЗ.

fitting_rooms_profiles.csv и fitting_rooms_transitions.csv сохраняют соответствующие проверки. Для непрерывной классификации нельзя незаметно заменить пропуски нулями. Булево fitting_rooms_at_least1_observed означает только положительное наблюдение, а исходное nullable fitting_rooms сохранено.

Полная таблица WB_id_continuity.csv. Для каждого снимка также сохранён сжатый CSV общихID с координатами обеих дат, сдвигом, исходными типами и текущими признаками привязки. Эти файлы предназначены для аудита идентичности; историческая география не должна строиться только на нынешних выживших ID.

Вывод для следующего расчёта

Историческую привязку к принятой оси поселений можно выполнять симметрично по собственным старым адресам/координатам и тем же правилам для современного каталога. Требуется держать отдельно allcatalog, заявленные примерочные и типовые профили. Ни один из полученных снимков не датирует первое открытие ПВЗ. Самый ранний полученный срез —сентябрь2022;национальная история до2021этим не получена.

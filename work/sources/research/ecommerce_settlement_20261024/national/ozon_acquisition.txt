Условия интерпретации
Это существенно более содержательный национальный кандидат, чем прежние 50 лексических сигналов Ozon, но именовать его официальной полной сетью нельзя. Отсутствие в снимке не доказывает отсутствие ПВЗ. Нужна проверка регионального покрытия и геопривязка к единой национальной географии. Группы city-label не равны административному реестру поселений; есть одноименные НП и неунифицированные адреса (3610 разных первых компонентов). Не определять регион простым разбиением адреса по первой запятой. Индивидуальных дат открытия/закрытия нет. С WB от21.10.2026 сравнивать только как разновременные срезы; не присваивать Ozon октябрьскую дату WB. Сырой массив не публиковать как открыто лицензированный: лицензия не обнаружена.

Пять фактически проверенных каналов
1. Официальные публичные страницы и карта: https://pvz-map.ozon.ru/, https://www.ozon.ru/geo/, https://seller-edu.ozon.ru/fbo/warehouses/adresa-skladov-fbo . Обычные запросы urllib без учетных данных закончились HTTP307 redirect loop (?__rr=9), ответ по164байта без таблиц. Ответы и statuses сохранены в ozon_http_probe_initial.json и *_response.html. Обход защиты/CAPTCHA не предпринимался.
2. Официальный integration endpoint https://xapi.ozon.ru/principal-integration-api/v1/delivery/variants : фактический запрос без авторизации — HTTP401,0байт; сохранено в ozon_probe_results_second.json. Токены/ключи не запрашивались. Дополнительный первичный контекст: https://dev.ozon.ru/community/1851-Spisok-PVZ/ (14.01.2026) обсуждает Excel-список ПВЗ/ППЗ на странице складов; модератор уточняет, что Seller API возвращает только ПВЗ, работающие как пункты приема. Эта выборка не гарантирует полноту потребительской сети.
3. OpenStreetMap/Overpass — резерв, заведомо не полный реестр: выполнен национальный запрос brand/operator по Ozon/Озон внутри RU, текст сохранен ozon_osm_overpass_query.txt. overpass-api.de — SSL handshake failure; overpass.kumi.systems — timeout55секунд; maps.mail.ru/.../interpreter — HTTP504. 4. Публичный GitHub API: поиск 'ozon pvz' дал29репозиториев; просмотрены названия/описания всех результатов. Репозиторий nutrygo-pvz дал реально скачанный снимок выше. Точный остаточный blocker
Официальный современный полный слой и его независимая полнота не установлены. Доступен большой сторонний августовский снимок с фиксируемым происхождением и хорошей внутренней целостностью, пригодный как явно маркированный кандидат для исследовательской геопривязки и дальнейшей выборочной верификации. Причинный анализ и история открытий этим получением не обеспечены.

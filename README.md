# Расселение России: связанные переписи и районы тяготения

Материалы магистерской диссертации о том, как менялась сеть населённых пунктов России в 2002–2021 годах и как устроены сельско-городские районы тяготения (СГРТ).

## Состояние работы

| Часть | Состояние |
|---|---|
| **База населённых пунктов по переписям 2002, 2010 и 2021 годов** | **Готова.** 465 929 записей переписей связаны в 173 242 межпереписные группы записей. Из них 142 765 — полные ряды с численностью и координатами за все три переписи. В рабочий слой попадает 99,6% / 99,5% / 99,7% населения страны. → [POPULATION_BASE.md](POPULATION_BASE.md) |
| **Районы тяготения** | **Рассчитан национальный базовый вариант локального обслуживания:** 153 800 пространственных НП, 14 отдельных слоёв ближайших направлений, 2 153 200 строк результатов. Получены 58 333 однофункциональные единицы; у 15 488 НП-центров есть населённые внешние кандидаты хотя бы по одной функции. Это перекрывающиеся функциональные варианты, полная многоуровневая система СГРТ ещё не установлена. → [Национальный проход](sgrt/mass/README.md) |

**Хозяйственный контекст включён:** первичная родительская территория установлена для 153 786 НП; частичная численность работников организаций за 2025 год наблюдается у 11 682 НП. Полный отдельный слой ФНС содержит 2 049 517 юридических лиц; адреса их рабочих площадок неизвестны. Муниципальные сельхозитоги и работники юрлиц не распределяются по сёлам. → [Данные и ограничения](sgrt/mass/CONTEXT.md).

**Проверка на конкретных местах:** [Учалинский район](sgrt/local_systems/README.md) — документированные школьные территории разных ступеней, ФАП, дорожные времена и хозяйственная база. [Первый региональный пилот](sgrt/pilot/README.md) сохранён как предыдущий сценарный расчёт; его чрезмерные ареалы по городским массам не принимаются за СГРТ.

Национальные данные и [атлас, 18 страниц](https://github.com/ZakBu/russian-settlements-research/releases/download/sgrt-mass-local-systems-20261024-v1/mass_atlas.pdf) опубликованы в [отдельном релизе](https://github.com/ZakBu/russian-settlements-research/releases/tag/sgrt-mass-local-systems-20261024-v1); все 465 файлов скачаны и проверены SHA. Каталог — [data/mass_catalog_20261024.json](data/mass_catalog_20261024.json). Основным скачиваемым набором остаётся готовая база населения.

Основа исследования СГРТ — концепция научного руководителя «Динамическая типология сельско-городских районов тяготения» ([Word](research_context/primary/word_concept.docx), [текст](research_context/primary/word_concept_extracted.txt)).

## Как начать

**Человеку:** прочитайте этот файл, затем [POPULATION_BASE.md](POPULATION_BASE.md) и [sgrt/README.md](sgrt/README.md).

**ИИ-агенту:** сначала [AGENTS.md](AGENTS.md) — правила работы и стандарт текстов.

**Получить данные.** Данные хранятся в релизах GitHub, а не в истории Git. Команды скачивают и проверяют базу населения (около 56 МБ):

```bash
git clone --depth 1 https://github.com/ZakBu/russian-settlements-research.git
cd russian-settlements-research
python scripts/research_data.py fetch
python scripts/research_data.py verify
```

Другие наборы: `python scripts/research_data.py list --profile all`. Подробнее — в [AI_START_HERE.md](AI_START_HERE.md).

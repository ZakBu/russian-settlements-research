# Проверка решений этапа II

- [ ] Протокол/пороги matching и код закреплены до просмотра контрастов.
- [ ] Четыре показателя отвечают разным вопросам; raw denominators сохранены.
- [ ] Источники/границы/федеральные массы не определяют главный контраст.
- [ ] Исходно крупнейшая группа и набор точек фиксированы2002; ties имеют правило.
- [ ] Совпадающие координаты и нулевые знаменатели явно отмечены.
- [ ] Matching использует только2002; unknown не приравнен к отсутствию риска.
- [ ] Полный реестр, balance, unmatched и common support опубликованы до кейсов.
- [ ] Сходная убыль после matching обозначена outcome-conditioned description.
- [ ] Две сильные пары и один контрпример не используются как случайная выборка.
- [ ] Эффекты по всем парам приведены с зависимостью/повторным использованием единиц.
- [ ] Проверки25/50/100км и сдвига представлены без выбора лучшего результата.
- [ ] Все inferential claims имеют целевую совокупность и откалиброванный способ вывода, либо остаются описательными.
- [ ] По каждой паре различены факт, источник, альтернативное объяснение, гипотеза.
- [ ] Ближайшая прежняя статья авторов явно отделена по данным/единицам/мере.
- [ ] Главный результат можно сформулировать географу без обсуждения алгоритма.
- [ ] Отрицательный итог допускается без расширения конкурса моделей.

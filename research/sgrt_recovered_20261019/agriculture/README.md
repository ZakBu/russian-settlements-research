# Аграрная структура муниципального окружения СГРТ

Основной результат — доля населённых пунктов расчётной зоны, муниципалитеты которых имеют определённый наблюдаемый аграрный профиль. Это **не доля посевов СГРТ и не измеренная локализация полей**. МО не приравнивается СГРТ: сохраняется полная матрица НП → МО 2021 → расчётный центр, включая разбиение одного МО между несколькими зонами.

Источник: Росстат, БД ПМО; обработка «Если быть точным», фиксированная версия 18.09.2025. Исходный Parquet содержит 8 832 750 наблюдений. Описание: https://tochno.st/datasets/bdmo . Архив получен в подтверждённом GitHub Actions artifact; полный ZIP SHA256 `80dc50aa7520474dc5a498269551330208461bedc8e01395f90557a8fb9cea96`, Parquet SHA256 `e6ca2906f49fd0fe561ae98f535206990cebc2675884571bced546c3374c198d`; оригинальная квитанция — `source_manifest.json`. Дата версии источника отличается от даты анализа.

## Профили муниципалитетов

Сохраняются исходные ОКТМО, `oktmo_stable`, история, годы действия кода, год наблюдения, показатель, категории хозяйств и единицы. Используются МО верхнего уровня и «Хозяйства всех категорий». Площадь — показатель `Y48007018`, гектары; номинальная продукция — `Y48007010`, тысячи рублей. Для временных рядов сохраняются все доступные годы 2006–2024 без переноса муниципальных значений на исторические СГРТ. Текущие рубли не являются реальным ростом продукции.

Для профиля 2021 берутся шесть непересекающихся наблюдаемых агрегатов культур: зерновые и зернобобовые; технические; кормовые; картофель; овощи; продовольственные бахчевые. Названия категорий фиксируются в коде и `schema.json`. Подгруппы не прибавляются к родительским агрегатам. Остаток total минус сумма шести групп вычисляется только как диагностический баланс; он **не является фиктивной седьмой/шестой наблюдаемой группой**.

Отрицательные величины, повторные строки МО–год–группа и превышение суммы групп над общей площадью более чем на 2% (численный допуск 10⁻⁸ га) изолируются. Муниципальный профиль — наблюдаемая группа с долей не менее 0,5 общей посевной площади. Если такой группы нет, `mixed` допускается только при наличии всех шести групп и покрытии ими не менее 90% total. Иначе профиль `missing`. Ноль допустим только при наблюдаемом total=0 без положительных значений групп.

## Зональная композиция

Основной вес — число НП: муниципальный профиль каждого НП даёт один голос в его расчётной зоне. Покрытие — доля НП зоны с допустимым муниципальным профилем. При покрытии ≥0,8 тип зоны определяется доминированием одного профиля ≥0,6 среди покрытых НП; иначе `mosaic`. При недостаточном покрытии — `missing`. Это композиция **муниципальных профилей окружения**, не структура фактических посевов внутри зоны.

Чувствительность: веса населения 2010 и 2021, пороги покрытия 0,6/0,7/0,8/0,9/1,0 и доминирования 0,5/0,6/0,7. Нулевые значения 2010 не удаляются. При нулевой сумме населения зоны веса заменяются равными; основной count-вариант не зависит от демографического outcome. Вариант населения 2021 является только чувствительностью, поскольку это одновременно конечная дата демографического анализа.

`zone_functional_main.csv` — основной функциональный профиль для объединения с демографией и RFSD. `zone_functional_composition.parquet` содержит все варианты и доли профилей. Отдельные `zone_crop_context*` и `zone_crop_profile_main.csv` содержат **диагностическое распределение гектаров** для полностью известных структур, с другими основаниями покрытия; их нельзя подменять основным функциональным результатом.

Мост относится к контексту переписи 2021. Он не доказывает муниципальную принадлежность НП в 1989/2002/2010, и `oktmo_stable` не означает неизменность границ. Временные ряды сохраняются на исходном муниципальном уровне; их использование в постоянных исторических границах требует дополнительного юридического crosswalk.

## Запуск

```
python research/sgrt_recovered_20261019/agriculture/run.py \
 --source /workspace/scratch/202266b2aadb/recovery_inputs/columnar/agriculture.parquet \
 --panel research/sgrt_recovered_20261019/data/panel.parquet \
 --membership research/sgrt_recovered_20261019/model/nearest_membership.parquet
```

Запускать после завершения экспорта модели. Чтение исходных данных потоковое, batch 50 000. Повторный запуск может использовать сохранённые извлечённые ряды только после проверки закреплённого SHA исходного Parquet. Итоговые проверки: сохранение каждой муниципальной суммы при диагностическом распределении, сумма матричных весов по МО=1, уникальность ключей, допустимость покрытия и сохранение категории missing.

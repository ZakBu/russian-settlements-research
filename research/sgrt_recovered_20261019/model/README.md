# Восстановленное демографическое ядро СГРТ

Все числа в этой папке получены новым запуском после сброса среды. Предыдущие сообщения и результаты не использованы как вычисленные наблюдения. Основной запуск `run_model.py` завершён с кодом0; полный перебор чувствительности входит в запуск. Действительное завершение и SHA основного membership находятся в `FINISHED.json`, хеши неизменяемого базового набора — в `SOURCE_READY.json`.

## Пространственные правила

Основной срез —2010. Кандидаты: города/ПГТ с положительным исходным населением, положительные локальные максимумы сельской людности в10км и два внешних территориальных якоря Москвы и Санкт-Петербурга. Тип берётся именно из `settlement_type_2010`, а не будущего статуса. Сельские максимумы — кандидатные узлы; административная или сервисная центральность ими не доказана. Происхождение каждого центра указано в `center_origin`.

Низовые районы: ближайший по сферическому расстоянию центр в100км, с сохранением каждого собственного центра. Координаты2021заморожены для сопоставимости; утверждение об исторически измеренных координатах не делается. Не назначенные наблюдения сохраняются в `UNASSIGNED`, включая их исходные населения. Нули2010 не исключаются и не интерполируются:142570наблюдений, в том числе21246нулевых значений2010.

Отдельное потенциальное поле: `A_ij=P_j,2010/(d_ij+5)^2`, нормированные веса по всем центрам в100км. Колонки `raw_huff_*` относятся только к этому полю, не квероятности принадлежности ближайшему центру. Геометрический отрыв `nearest_margin_km` и вероятностный отрыв `raw_huff_probability_margin` разделены. Нормированные веса не являются эмпирически откалиброванной вероятностью поездки.

Верхняя иерархия строится снизу вверх: сильнейший потенциальный центр со строго большей исходной массой в100км становится родителем, если внешнее поле превышает собственное `P/5²`. Это явный строгий сценарий самостоятельности, а не функциональный порядок. Все низовые единицы и их цепочки сохранены; `nested_aggregates` содержит каждый шаг укрупнения без потери меньших уровней. Отдельно пересчитаны пороги отношения внешнего/собственного поля0.1,0.5,1 и расстояния от каждого наблюдения до конечного корня.

Две внешние федеральные массы действуют только в поле и иерархии. Они не прибавляются к населению когорты и имеют нулевое число наблюдаемых членов; `empty_center_ledger` явно сохраняет их статус. Число центров и число непустых исходных районов поэтому различаются. `UNASSIGNED` — остаточная корзина, не центр.

## Динамика и проверки

Основная геометрия2010фиксирована при анализе2010–2021. Вэтих же единицах сохранено сравнение2002–2021; это ретроспектива в геометрии2010, а не независимая модель исходного2002поля. Независимый базовый2002расчёт создаётся отдельным `run_2002.py` в соседнем `model2002`, без изменения основного набора. Внём массы, городские статусы, локальные максимумы и иерархия определены исключительно по2002.

Для динамической геометрии2021центры заново отбираются по наблюдаемым массам и статусам2021в исходной сопоставленной когорте, при неизменных координатах. При неизменном списке центров ближайшее назначение было бы тождественным, поэтому изменение списка центров явно записано в конфигурации. Точное симметричное разложение использует объединение старых и новых центров и остаток `UNASSIGNED`:

`ΔN = Σ[(z0+z1)/2·(n1−n0)] + Σ[(n0+n1)/2·(z1−z0)]`.

Это разложение демографического эффекта и переразметки, не причинная оценка и не измерение миграции. Сумма эффекта переразметки по всей когорте равна нулю. Переходы ноль→положительное, положительное→ноль и ноль→ноль сохраняются отдельно; процентное изменение при нулевой базе не определено. Термин `non_decline` включает отсутствие изменения, а не только рост.

Пространственные модели не доказывают фактических сервисных, административных или трудовых потоков. Показатели валидации не использованы для настройки параметров. Плоская гравитация опубликована как обязательная структурная альтернатива, а не заменена незаметно ближайшим назначением.

## Файлы

- `nearest_membership`: исходный НП→расчётный центр; исходные населения; расстояния, конкуренты, происхождение и корень.
- `centers`: полный набор центров, массы всех лет, родитель, корень, цепочка и тип происхождения.
- `zone_trajectories`: население центра, окружения и района, абсолютное/относительное/log1pизменение и переходы нулевых значений.
- `nested_aggregates`: неизбыточные суммы на каждом шаге вложенной иерархии.
- `dynamic2021_membership`, `fixed_dynamic_decomposition`: динамическое назначение и точное разложение.
- `flat_gravity_membership`, `flat_zone_trajectories`: плоская альтернатива с явным `anchor_forced`.
- `parameter_sensitivity.csv`:27комбинаций beta1/2/3,d0=2/5/10км,R50/100/200км; ближайшие назначенияR50/100/200; локальные максимумы5/10/20км; основной плоский benchmark.
- `upper_hierarchy_sensitivity*`, `empty_center_ledger`, `illustrative_case_recomputed`: дополнительные независимые от районирования аудиты.

Табличные результаты сохранены одновременно вParquet иCSV.gz. Полное чтение каждого проверено после записи; крупные файлы публикуются атомарным переименованием. `readback_validation.json`, `invariants.json`, `test_results.log` отделены от независимой проверки статистика. Самотест `test_model.py` фактически выполнен:6/6PASS. `flat_configuration_invariant.json` отдельно подтверждает нулевое расхождение дефолтного плоского поля, явной конфигурации beta2,d0=5,R100 и сохранённого результата. Текст `d05` в имени сценария означает d0=5км, а не0.5.

## Воспроизведение

Изкорня репозитория, после сборки свежей панели инженером данных:

```
python research/sgrt_recovered_20261019/model/run_model.py
python research/sgrt_recovered_20261019/model/upper_hierarchy_audit.py
python research/sgrt_recovered_20261019/model/test_model.py
python research/sgrt_recovered_20261019/model/check_flat_configuration.py
python research/sgrt_recovered_20261019/model/run_2002.py --skip-sensitivity --out research/sgrt_recovered_20261019/model2002
```

Ниодна из этих команд не изменяет первичные источники или `sources/`. Для повторения в отдельной папке у основного CLI есть `--panel` и `--out`. Контролируемые изменения копии2002перечислены в `controlled_2002_copy.json`.

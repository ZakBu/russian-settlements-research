## Замороженные входы

Используется ранее сохранённый `SGRT_RESULTS.zip` (488 078 899 байт, SHA256 `19ab8b59dd1e90ffce9c0976366b0a3b2bd39f11157570878497f239834210cf`). Его внутренняя структура содержит `research/sgrt_recovered_20261019/` и `inputs/`. Распакуйте его в выбранный каталог, например `restored/extracted/`. Новый архив этапа не дублирует все 488 МБ и книги проекта. SHA необходимых входов сохранены в `data/immutable_input_manifest.json`.

Точные кодовые данные 2016 относятся к современной справочной оси2021; документы функций относятся к своим датам. Точка юрлица, объект учреждения и его внешнее окружение различаются. Входы и прежняя демография остаются read-only.

## Запуск

Установите Python3.12 и зависимости из `requirements.txt`. Из корня нового этапа:

```bash
python -m pip install -r requirements.txt
python replay_pilot.py --root . --out ../fresh_anchor_replay
```

Каталог результата должен быть новым или пустым. Сценарий заново строит документированный граф, все сравнительные модели и18 outside-сценариев, затем сравнивает все29 CSV/Parquet-таблиц целиком: rtol0,atol1e-12. Реальный выполненный результат: [REPLAY.json](REPLAY.json). Это повтор замороженного пилота, не новое сетевое получение источников и не общероссийская функциональная валидация.

Для пересчёта RFSD из восстановленного микросреза используйте:

```bash
python economy/build_coded_features.py --restored /absolute/path/to/restored/extracted --out /absolute/path/to/new_coded_output --years 2021 2016
```

Для полной сборки панели/геолинка и аграрки параметры перечислены в `data/README.md`, `economy/READOUT.md`, `agriculture/README.md`. Независимые проверки и источники команд находятся в `review/`, `data/statistics/`, `statistics/VERDICT.md`. Пути в первоначальных протоколах сохраняют рабочую среду как provenance; явные CLI-параметры позволяют выбрать собственные каталоги.

Рисунки:

```bash
python build_figures.py --root . --graph model/documented_graph --axis data/point_axis.parquet
```

SVG/PDF/PNG изображают документные связи без искусственных полигонов покрытия. Линии не являются дорожными маршрутами. `figures/visual_QA.json` фиксирует просмотр; расчётная координата Приозёрного не используется.

## Реальные ограничения первого этапа

Три школьных документа и два ФАП не дают национальной выборки; опубликованный тест не является слепым holdout. Мощности учреждений, реальная посещаемость, полная сеть альтернатив, дорожное время и трудовые потоки не измерены. CAPTCHA и timeout национальных сервисных реестров зафиксированы в `services/access_audit.json`; ограничения не обходились. Полноценная многопрофильная делимитация остаётся следующей эмпирической задачей, а не объявленным итогом этого этапа.

Новые материалы сохраняются в ветке `research/sgrt-final-protocol-20261018`, draftPR4 без слияния. Самостоятельные исходные книги не перепубликуются.

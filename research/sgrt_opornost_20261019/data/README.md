# Новая ось исследования опорности

Запуск из `/workspace/scratch/202266b2aadb`:

```sh
python anchor_research_20261019/data/build_inputs.py --restored restored/extracted --out anchor_research_20261019/data
```

`point_axis.parquet` содержит все 142570 НП и 64 демографических/географических поля восстановленной панели. Каждая численность 2002/2010/2021 непосредственно сверена с stage71. Значения 2010 года, включая нули, сохранены. Старые центры, зоны и назначения в новый вход не входят. Это ось наблюдений, не перечень опорных пунктов.

`immutable_input_manifest.json` фиксирует SHA256, покрытие, существенные проверки и доступные функциональные микроданные. `package_member_audit.csv` проверяет SHA256 и размер каждого файла внутреннего PACKAGE_MANIFEST. Архив read-only. Исходники не изменяются.

Координаты — представительные точки 2021 года (часто Geonames), не измеренная историческая геометрия. Переписи относятся к 2002/2010/2021, а муниципальный контекст взят из версии v20251217 данных переписи2021; он не доказывает административное состояние2026 или2010. Наличие всех трёх численностей у каждого НП не означает полного покрытия всех поселений/населения РФ. Связка1989 частична: 19863 уникальных соответствия, остальное пропуски.

В bridge нет явного признака административного центра. `municipal_literal_name_candidates.csv` содержит только буквальные совпадения названий поселений с именами МО после снятия явных префиксов; ни население, ни расстояние, ни старое районирование не используются. Это список гипотез для независимой проверки, а не доказанный перечень центров. Адъективное сходство названий специально не используется.

RFSD2016/2021 — самостоятельные организации с координатами юридического адреса, отраслью и признаками качества/сопоставимости отчётности. Эти файлы позволяют построить point-level экономические признаки заново. Готовые старые зональные и «center witness» таблицы не считаются входами новой опорности. RFSD не является полным реестром больниц, школ или фактических мест работы; массовые публичные услуги требуют отдельного источника.

Автор этой базовой оси также автор восстановленной демографической панели. Поэтому независимость последующих статистических проверок может заявляться от авторов новых функциональных/GIS-алгоритмов, но не от происхождения панели.

# Правила функциональной сборки, 19.10.2026

Сборка сохраняет исходные поселения и направленные связи «место проживания → место функции». Полигонов, обязательного покрытия территории и назначения к ближайшему пункту нет. Школьная связь сама по себе не превращается в целостный СГРТ.

Две независимые оси: (1) вид свидетельства — физический объект, регистрация юридического лица, нормативное прикрепление, сообщённое поставщиком обслуживание, плановый выезд, организационная подчинённость, наблюдённый поток; (2) охват вывода — одна функция, несколько функций, несколько уровней/пунктов. Их нельзя складывать в единую шкалу доказанности.

Узел с внешней документированной связью получает статус `documented_external_function_node`. Если такие связи имеются по двум группам функций, статус `documented_multifunction_external_node` — только в наблюдаемом корпусе, с перечнем дат. Ни один статус не называется полным доказательством СГРТ. Локальное разнообразие организаций отдельно: сочетание внешней школьной функции с двумя юридически зарегистрированными группами — кандидат многопрофильности, а не доказанное внешнее обслуживание по всем группам.

Известная школа/ФАП/ПВЗ без внешних связей — местоположение функции. `institutional_subdivision` — организационная принадлежность, не отношение тяготения жителей. `scheduled_mobile_visit` — предложение в указанную дату, не состоявшаяся поездка. Источники разных лет не объединяются скрыто в исторический срез.

Граф фиксированных источниковых окружений: каждый источник×поставщик×группа функции сохраняет набор внешних происхождений. Население 2002/2010/2021 считается внутри этого неизменного набора, без вывода, что такое обслуживание существовало во все три года. Нулевые значения сохранены.

Совпадение окружений разных поставщиков показывает пересечение документированных функций. Непустое пересечение разных функций — свидетельство распределённого обслуживания в конкретном корпусе; один вложенный набор населённых пунктов не доказывает функциональную иерархию. Для иерархии нужна отдельная связь более высокого функционального уровня. Ни сосуществование школ, ни разный размер центра автоматически её не создают.

История сравнивается только при явно заявленной предметной/территориальной сопоставимости парных документов. Изменение нормативного поставщика не называется измеренным перемещением спроса. Разложение населения точно: ΔP = Σ(S0∩S1)(P1−P0) + Σ(S1\S0)P1 − Σ(S0\S1)P0. Дополнительно выделяется динамика фиксированного S0 и чистый эффект новой разметки при P1: ΔP = ΣS0(P1−P0)+[ΣS1P1−ΣS0P1]. Даты переписей и дат обслуживания различны и явно указаны.

При неполных реестрах отсутствие наблюдения означает неизвестность. Не применяется произвольный outside-порог по числу организаций. Независимые связи не используются для подгонки формулы; этот этап восстанавливает документный граф, а не обучает модель выбора.

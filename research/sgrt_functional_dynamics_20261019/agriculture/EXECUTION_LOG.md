# Исполнение аграрного модуля

2026-10-19. Прочитаны контракт задачи, документированный Учалинский результат, таблицы совпадения функций и вложенности, существующий аграрный код. Исходники не изменялись.

Первый пробный полный `to_pandas()` по8,8млн строк превысил память: процесс завершён с кодом137. Следующий проход выполнен батчами60000строк; чтение всех исходных записей подтверждено счётчиком и метаданными Parquet. Это устранённая техническая ошибка, не ограничение данных.

Прочитан полный перечень двух сельсоветов в воспроизведённом первичном законе№126-з. HTML непосредственно загружен HTTP200,1313396байт; SHA в `source_crosswalk.json`. Доступ к иному правовому хосту `https://base.garant.ru/408854083/` вернул403; использована доступная полная правовая репродукция с явно указанным статусом хоста, а не поисковый фрагмент. Поисковая выдача и муниципальная библиотечная страница использованы для обнаружения, но численные аграрные результаты взяты из замороженной официальной выгрузки, не из пересказов.

Полный модуль был запущен повторно после добавления проверки двух выпавших ИНН во всём2021исходнике. Последний проход также проверяет идентичность множеств функциональных членов непосредственно с реализованным модельным графом. Счётчики исходников, SHA256 и результат всех важных инвариантов — в `AUDIT.json`/`CHECKS.json`, фактический stdout — в `run.log`.

`verify_outputs.py` отдельно читает записанные таблицы, пересчитывает группировки по ИНН и проверяет полный список поселений по исходному нормативному тексту. Это авторская повторная проверка; независимая экспертная проверка должна называться отдельно и этим файлом не подменяется.

Ключевое принятое решение: не распределять целые сельсоветские гектары и поголовье по части деревень с предположением одинаковой аграрности. Вместо этого опубликованы точные границы множества членов, полное кодовое пересечение, временная несопоставимость и реальные точечные организационные суммы. Пропуски полной оси сохранены явно.

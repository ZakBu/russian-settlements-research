# Воспроизведение

База — неизменённый stage71 из этого репозитория. Проверяемый gzip SHA-256: `d40273e13a8ecf8f31bf367ddc414e21bd026eea325192629fb2f81f6dfa374c`. Версия кода зафиксирована до финального расчёта: коммит `19b103a743adcdf26c5e7d35eafd0bd2e1a620fe`, `protocols/final_lock.json` и SHA зависимостей. Python 3.12.14; пакеты закреплены в `protocols/requirements-research.txt`.

Из корня репозитория:

```bash
python -m pip install -r research/settlement_context_20261018/protocols/requirements-research.txt
python research/settlement_context_20261018/scripts/reproduce.py --output /absolute/new/scratch-directory
```

Укажите новый пустой каталог. Скрипт строит три пространственных набора, проверяет закреплённые SHA и выполняет фиксированные модели. Отказ при несовпадении SHA является защитой; не обходите его подменой протокола. Один исходный расчёт выполнен по этим компонентам; оболочка команды дополнительно проверена синтаксически, отдельный второй полный запуск оболочки не заявляется. Переносимая оболочка аудита и независимого обучения находится рядом; исторические агентские скрипты сохранены с исходными путями как доказательство фактического запуска.

Независимый пересчёт входа:

```bash
python research/settlement_context_20261018/scripts/audit_portable.py --repo . --output /absolute/new/audit-directory
```

Независимое обучение основной E1, без импорта основного исполнителя:

```bash
python research/settlement_context_20261018/scripts/independent_fit_portable.py --repo . --features /absolute/new/scratch-directory/geo/features.csv.gz --lock research/settlement_context_20261018/protocols/final_lock.json --output /absolute/new/independent-fit
```

Это отдельная реализация признаков и разбиения, использующая тот же sklearn; это не независимый алгоритм или новые данные.

Основной риск — все 121324 записи с положительным выбранным населением2010. Нули2010 остаются в мастер-таблице и окружениях. Исходное разбиение по hash-блокам содержит101593 development и19731 holdout записей риска. Федеральные территориальные массы не прибавляются к обычным НП; Москва/Санкт-Петербург представлены отдельными дистанционными якорями. Окрестности — полная доступная принятая ordinary-панель, а не все переписные жизненные циклы.

Финальные имена конфигураций, радиусы, seed и число повторных обучений не выбираются после раскрытия. Прогнозы сначала сохраняются на диск с хешем; затем читаются исходы отложенной части. Это не внешнее временное удостоверение прогноза. Данные ранее исследовались, общий аудит видел полные сводки, первоначальный описательный E3-парсер прочёл полную колонку до немедленного маскирования. Эти ограничения не позволяют назвать проверку исторически невиданной.

Первый дополнительный drift-gzip был усечён и отклонён до расчёта. Используется только `exclude_drift_recovery`, восстановленный атомарной записью и проверенный CRC/EOF. Результаты original2010 — чувствительность ковариат: риск и исход остаются на выбранной оси. Постаудитная маска дрейфа использует межгодовые координаты и не является исходным прогнозным признаком.

Большие широкие производные таблицы восстанавливаются кодом; в манифестах сохраняются SHA и размеры. Исходные книги, закрытые документы и повторные копии переписных массивов в исследовательскую ветку не добавляются. Состав проверки следует читать по receipts: проверочные подвыборки не являются оценкой национальной точности данных.

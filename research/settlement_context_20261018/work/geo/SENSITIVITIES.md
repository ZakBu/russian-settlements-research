# Геометрические проверки чувствительности

Исходный `features.csv.gz` завершён до проверкине зависимымR; SHA256 `b3e62de9163e7b07116a5737cfa1817e93aa4dc690ec38bea7b8043cff810ee4`. Точный код этого запуска сохранён как `build_features_v1.py`, SHA256 `d9693ecee4ab94703405d1022d3c3a8047127a5cce122b6c97980f0a52b83d4e`.

`build_features.py` v2 расширен только явнымиCLI-осями. `--population-axis original_fallback` использует конечное числовое `original_population_2010`, иначе выбранную численность. Все сопутствующие признаки соседства/иерархии полностью пересчитываются. Это ковариатная чувствительность: координатор фиксирует основной selected2010 cohort и selected2010→2021 target для парного сравнения моделей. Это не полный повтор исследования с original2010 как целевой исходной осью. Поле качества2010 остаётся provenance выбранногоисточника;qualityoriginal автоматически не переоценивается.

`--exclude-neighbor-uids PATH` исключает перечисленныеUID из совокупности соседей/центров, сохраняя все142570фокальных строк. Полная пересборка в `exclude_drift/` исключает48строк с межгодовым дрейфом координат>5км. Маска определяется метаданными координат2002/2010/2021 и является отдельной проверкой аудита, не основнымpredictor2010. Численности и исходные координаты не исправляются и не перераспределяются. Фокальные48строк можно отдельно исключить в runner. Предварительный `coordinate_sensitivity.py` рассчитываетточное вычитание flaggedmass/history,но полнаяпересборкатакжезатрагиваетHHI,NN,hierarchy.

Ни эти CLI, ни геоаналитик не читают исходыpopulation2021. Никакие варианты не выбираются по знаку/размеру эффекта.

## Дополнение: инцидент целостности

После завершения первоначального запуска `exclude_drift` повторная проверка обнаружила, что файл с результатами усечён: текущий SHA `e3741a2c08eee638c3caf9c9bb1656bd5c1695f3d9938ebacab5f04364465000` не совпадает с первоначальным manifest SHA `d6cb6258eb229d1a425f803dde5542c6c8a692285bd55c0808aa93c38cc8b540`; gzip не достигает end-marker. Причина замены/усечения не установлена. Старые файл и receipt сохранены как отклонённая попытка; использовать их нельзя. Восстановление выполняется в отдельном `exclude_drift_recovery`, через `build_features_atomic.py`: запись во временный файл, закрытие, полный gzip/CRC проход, вычисление хешей, атомарное переименование, затем manifest. Main и original2010 прошли полный gzip/CRC проход и сохранили исходные SHA. V2 default selected повторён отдельно и побайтно совпал с main.

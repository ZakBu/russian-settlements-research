# Независимый допуск к freeze

Проверено до запуска финальных моделей: статистический протокол и функции split/bootstrap прочитаны. SHA256→int→mod5 применён правильно; floor отрицательных projected coordinates корректен. EPSG6933 — равновеликая цилиндрическая проекция; её area-of-use по установленному PROJ ±86°, код консервативно допускает ±85°. Хешированные блоки являются алгоритмически воспроизводимыми, а не случайно выбранными независимыми территориями.

До freeze обязательны:
- Input SHA и code SHA; schema X, точные отобранные колонки/радиусы, значение missing/empty, федеральный crosswalk и статус недостающей массы.
- UID/block/mask manifests и SHA; N train/test/blocks для каждого fold, ближайшее геодезическое train-test расстояние не ниже60км с допуском1м. Не менять маски на основании исходов.
- Доказательство, что X отсутствуют исходы2021 и связанная с ними административная/качественная информация. Контекст2002–2010 допустим на test при объявленном transductive дизайне.
- Формальный список исключений и ряды нулей; момент открытия holdout; append-only run journal.
- Первичные3 контраста, фиксированный learner и sensitivity learner; заранее названные negative controls; явное условие, что невыполненная simulation calibration блокирует подтверждающие p-формулировки.

Парный bootstrap в статистической утилите правильно рассчитывает среднюю разность потерь по строкам с повторным выбором блоков. Интервал условен на обученных моделях. 200км projected blocks не гарантируют независимость; фактический геодезический размер ячейки меняется с широтой. Морфология200км, радиус100км и буфер60км допускают общую среду train/test; это не target leakage само по себе, но требует соответствующей области интерпретации.

Статус: пригодно к freeze после закрытия перечисленных gates; индивидуальные predictions не просмотрены.

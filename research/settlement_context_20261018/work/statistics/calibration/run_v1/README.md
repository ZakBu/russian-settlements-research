# Синтетическая диагностика покрытия условного bootstrap

Вычислено на фактической геометрии89holdout-блоков,19 731НП исходной совокупностиP2010>0. Реальные2021исходы и предсказания не читались; загружены толькоUID,координаты иP2010. Seed20261018;300независимых Gaussian-полей для каждого сценария;499bootstrap-повторов на поле. Фиксированные длины корреляции0(независимые блоки),100и300км.

Статистика: среднее синтетических block-constantразностей потерь с весамичислаНП. Точное безусловное ожидание=0; известная ensembleSE вычислена из заданной ковариационной матрицы. Длина поля измерена sphericalchorddistance; Gaussiankernel выбран для положительной определённости. Bootstrap как в анализе: равновероятно выбираются блоки с возвращением, их исходные числастрок сохраняются;95%percentileCI.

|Длина поля,км|Покрытие0|95%MCWilsonинтервал|ДоляCIцеликом>0|СредняяbootstrapSE/истиннаяensembleSE|
|---|---:|---:|---:|---:|
|0|93.3%|89.9–95.6%|4.0%|0.914|
|100|90.0%|86.1–92.9%|4.3%|0.893|
|300|75.3%|70.2–79.9%|11.7%|0.634|

При независимых блокахcoverage93.3%иMonteCarloинтервал включает95%; это ограниченная диагностическая совместимость, не валидация bootstrap для реальных прогнозов. При поле300кмcoverage75.3%(MC95%70.2–79.9%), аSEоценивается примерно63.4%истинной. Значит, при такой заданной дальнейзависимости200кмблоки не дают номинального покрытия; «положительнаяCI» может появляться при нулевомensembleожидании. Для100кмполучено90.0%(MC95%86.1–92.9%): также демонстрируется ограничение.

Это отрицательная проверка достаточности блочной независимости. Она НЕоценивает истинную дальность корреляции реальныхошибок, НЕдаёт откалиброванныхp, НЕпроверяетнулевую дополнительную информациюE1/E2 и НЕподтверждаеткаузальность. Здесьразности потерьсинтетическинеограниченныеGaussian,постояннывнутриблока;реальныеBrier/MAEимеютдругуюструктуру. УсловныеCIисследованияследуетназыватьописательными,не«доказательствомзначимости». Измененийfreeze,моделей,seedилиотбораиз-заэтогорезультатаневнесено.

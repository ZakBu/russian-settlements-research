# Экспериментальное восстановление интервалов российского бонитета

Из первичной карты «Бонитет почвенного покрова», Национальный атлас почв РФ,
с. 240–241, получен самостоятельный экспериментальный слой. Основной
`context/soil_settlement_features.parquet` не изменён. Его строго подтверждённый
`soil_russian_bonitet_score` остаётся NULL.

Первичный источник: https://soil-db.ru/soilatlas/razdel-6-funkcii-pochv/bonitet-pochvennogo-pokrova

Изображение: https://files.soil-db.ru/soilatlas/3600x2400/240-241-min.jpg

Источник имеет масштаб 1:30 000 000 и 13 классов: 0–10, 10–20, …, 110–120,
120–125. Это потенциальное плодородие почвенно-географических округов равнин
и горных провинций. Это не измерения земельных участков или отдельных НП.
Год фактических почвенных наблюдений и исходная CRS карты не установлены;
публикация атласа не превращается в датированное измерение почв 2010 или 2021 г.

## Реальный результат

- 173 527 строк на неизменённой оси НП.
- 20 559 НП имеют восстановленный устойчивый **интервал**, остальные — NULL
  с причиной. Средние/точные баллы из интервалов не вычислялись.
- 45 вручную прочитанных точечных знаков городов связаны с координатами
  принятой оси. Москва/Санкт-Петербург имеют отдельные внешние опоры.
- 33 опоры использованы для выбора семейства проекции посредством 5-fold CV;
  12 заранее выделенных по номеру опор оставлены для отдельной проверки.
- Отложенный RMSE: 3,92 пикселя, приблизительно 19,26 км;
  максимальная отложенная ошибка: 34,24 км. Это небольшая техническая выборка,
  а не доказанная верхняя граница ошибки по всей карте.
- Проверка техническая, не слепая внешняя приёмка: до окончательного
  разбиения опор пробные fit по всем точкам использовались для выявления
  ошибочно прочитанных городских знаков. Итоговое семейство проекции затем
  выбиралось только по train-CV. Этот порядок явно сохранён в receipt.
- После проверки коэффициенты уточнены по всем 45 опорам. Названия опор,
  координаты, пиксели и статус train/holdout сохранены.
- Для присвоения класса требуется устойчивость в окне радиусом 10 пикселей
  (примерно 50 км): ≥35% пикселей распознаны по реальной легенде, ≥95%
  распознанных пикселей имеют один класс, второй класс занимает <2% окна.
  Эти доли — правила согласованности изображения, **не** статистическая
  вероятность правильности класса.
- Вне выпуклой оболочки опор экстраполяция запрещена. Пограничные,
  смешанные, текстовые, водные и нераспознанные места не получают балла.

`experimental_bonitet_settlement_intervals.parquet` содержит нижнюю и верхнюю
границы класса, пиксельную позицию и статус качества. Поля названы
`soil_bonitet_atlas_experimental_*`; `scientifically_adopted=false`.

`experimental_bonitet_intervals_25km.tif` — два канала (нижняя и верхняя границы),
EPSG:3576, сетка 25 км. Размер ячейки — шаг представления, а не точность
измерения; ошибка привязки и крупный масштаб источника остаются.

`georeference_diagnostic.png/.pdf` показывают источник, точки контроля и
восстановленную координатную сетку. `atlas_classification.npz` сохраняет
распознанные классы исходного изображения и маску устойчивости.

## Ограничения использования

Слой пригоден для явно обозначенной проверки чувствительности на крупном
территориальном уровне. Он не принят как окончательное объясняющее поле,
не является почвенной съёмкой НП и сам по себе не закрывает требование Word
о надёжном почвенном бонитете. FAO soil-quality ratings не переименованы
в российский бонитет.

GIS-метаданные soil-db и загруженный `map-livewire-Bg3JD9As.js` изучены:
видны почвенная карта, профили и агростатистика; пригодного открытого слоя
бонитета там не выявлено. Это результат проверки конкретных доступных
ресурсов, а не утверждение об отсутствии таких данных вообще.

## Воспроизведение

Из корня репозитория:

```bash
OPENBLAS_NUM_THREADS=1 python research/sgrt_word_completion_20261021/soil_bonitet_recovery/recover_bonitet.py
python research/sgrt_word_completion_20261021/soil_bonitet_recovery/plot_georeference.py
python research/sgrt_word_completion_20261021/soil_bonitet_recovery/validate_recovery.py
```

Исходные пиксельные опоры — `control_points_digitized.csv`; ошибки отложенных
опор — `heldout_georeference_errors.csv`; семейства проекций, параметры,
контрольные SHA256 и покрытия — `recovery_receipt.json`.

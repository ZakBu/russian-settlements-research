# Источниковая нормализация единиц — prospective метод, фактические таблицы ещё не получены

Каждый исходный cap×partition обрабатывается отдельно. Cap — операционное ограничение прямого дорожного времени, не функциональный ранг. Прочитанные исходные строки/членства сохраняются отдельными scoped-файлами с SHA; объединение альтернативных разбиений в один национальный знаменатель запрещено. Принятое дерево и его ядро/членства не изменяются. Внутренняя вычислительная глубина слияний не получает статуса географического уровня.

Основной центральный объект — строго один фактический `core_id` из принятого ядром правила fixed-ownMi + прямой дорожной допустимости. Именно этот единственный ID исключается из сельского окружения. Все остальные исходные provider_seed_ids сохраняются и могут входить в сельское окружение при подтверждённой статистической сельской роли. Пул поставщиков услуг не является набором доказанных полицентрических ядер. Ветка all_supported_cores не используется в основном запуске и требует отдельного независимого определения сопоставимых ядер.

Население берётся из принятого population-only source view; допускается отдельный прямой overlay с явной картой reviewed-полей. Перед прямой заменой сверяются прежние численности и качества ВСЕЙ оси, не только новых строк. Оригинальные provenance-колонки population_2010 в full-axis overlay НЕ являются новой эффективной первичкой. Меняются только явно разрешённые reviewed поля; source UID и source-layer admission сохраняются отдельно от допуска итогового overlay. Текущие и прежние качества/числа/UID и same-number quality-only recovery сохраняются. Принятый источник169V3 — временный конечный допустимый срез;353 может стать новым срезом после отдельного допуска, без перезаписи169.

Три периода/три даты: 2002,2010,2021. Для каждой единицы вычисляются собственный атомарный ряд (для атомарных единиц), focal center, всё аддитивное членство и внешние известные сельские члены. Неизвестные роли не становятся несельскими: сельская полнота=False при любой неизвестной роли. Для положительного числа членов с полностью пропущенными значениями сумма=NA, а не0; структурно пустая сельская группа имеет известный счёт членов0 и техническую сумму0, но классификатор помечает объект not_applicable. Пустая whole-группа имеет суммуNA и полнотуFalse. Контекстный неизвестный неаддитивный focal блокирует полноту whole, хотя известный аддитивный subtotal показывается отдельно. Численность федерального субъекта в NP-население не добавляется.

Доли primary/secondary2010 имеют явный знаменатель: конечные неотрицательные известные величины собственных атомарных рядов либо аддитивных членов агрегата. При нулевом/отсутствующем знаменателе долиNA. Они не показывают долю от неизвестного полного населения. Число пропусков аддитивных членов и неизвестных неаддитивных focal-слотов отдельно. Primary означает утверждённый набор quality-тегов прежнего принятого метода; неизвестность истории границ не снимается.

Функциональный профиль — только положительные свидетельства из явно перечисленных столбцов/источников/дат. Scope focal, rural_members и all_members различаются. В неполном институциональном каталоге count0 не доказывает отсутствие объекта/функции; выходная положительная метка True/NA. Для такого каталога наблюдаемость без отдельного принятого observed-флага устанавливается только положительным исходным свидетельством. Для проверенного контекстного булева критерия False может быть наблюдённым отрицательным результатом; primary_profile всё равно хранит только положительную метку. Исходные nonmissing/positive/missing по каждому полю сохраняются, как и actual_source_observed_flag.

Контекстная coverage — доля известного населения2021, приходящаяся на членов с применимым наблюдаемым источником. Знаменатель, пропуски населения, положительная доля и число поддержанных членов выдаются отдельно. Число уникальных первичных source-unit ключей учитывается по муниципальному/региональному/иному действительному grain: повтор одного муниципального значения у многих NP не создаёт независимые источники. Региональное историческое Нечерноземье сохраняет год1974 и historicalregional scope, без заявления современной точной зоны/почвы.

Числовой контекст (муниципальная урожайность/посевные площади, климатические и почвенные прокси, муниципальные natural/migration rates) агрегируется как exposure известного населения2021, а не собственная продуктивность NP. Среднее использует только конечные применимые значения и известные неотрицательные веса; нули источника сохраняются как наблюдаемые значения, пропуски не заменяются нулём. Отрицательные natural/migration величины не отбрасываются. Coverage и distinct-source-unit counts обязательны. Правила high-grain/decline берутся из уже принятых входных флагов, не вычисляются новым порогом по NP-дубликатам.

Независимый аудит сравнит каждую агрегированную ячейку с исходным членством и принятым node-source, центральные/сельские/whole наборы — по точным ID-set hash, а все остальные поля дерева — с raw-входом. Допуск prospective классификатора не подменяет этот фактический source/cell admission. Новый output остаётся pending до него.

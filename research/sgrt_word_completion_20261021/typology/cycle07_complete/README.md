# Полная типология cycle07

Новая реализация под новое пользовательское требование. Никакие результаты cycle06 не перезаписаны. Наблюдения новой эмпирической иерархии ещё не классифицированы: требуется независимый перспективный допуск метода и самой иерархии.

- `PROTOCOL.md`: смысл классов, источник порога, полное разбиение, ограничения.
- `classify_complete.py`: параметризованный классификатор произвольного набора уровней.
- `check_edge_cases.py`, `synthetic_checks.json`: только искусственные пограничные примеры.
- `render_case_charts.py`: карточки фактических классов после допустимого запуска.
- `input_contract_TEMPLATE_NOT_RUNNABLE.json`: схема, намеренно с пустыми путями/хешами. Не выдаётся за связанный конфиг.

Входной нормализованный источник обязан содержать все принятые строки единиц, их роль и вид, три даты каждого применимого объекта, полноту, качества и точные центральные ID. Атомарным единицам нужен только собственный ряд; столбцы остальных объектов могут быть nullable, но заявленная схема должна присутствовать. Многоцентровая единица может описывать один явно выбранный focal core или совокупность всех поддержанных ядер. Выбор и исключение центральных ID из сельского окружения подтверждает отдельный независимый аудит. Центральный объект не выводится типологизатором из максимума населения.

`context_witnesses` — список явных положительных свидетельств: column, kind (`boolean` или `positive_count`), label, source, year, grain, absence_is_unknown=true. Пространственный/временной масштаб обязан оставаться в label и исходных колонках. Показатели, для которых положительное число не равно наличию функции (например, любое положительное количество осадков), не могут попадать сюда без отдельно принятого содержательного правила.

Проектируемый фактический запуск после допуска:

```
python typology/cycle07_complete/classify_complete.py --contract ACTUAL_BOUND_CONTRACT.json --output NEW_OUTPUT
python typology/cycle07_complete/render_case_charts.py --classification NEW_OUTPUT --output NEW_CHART_OUTPUT
```

Пути в примере условные; запуск из корня пространства исследования. Контракт содержит абсолютные пути или пути от текущей директории. Оба выходных каталога обязаны быть новыми. Классификатор проверяет хеш входа до и после, точное принятие версии протокола и кода, исходные допуски, а также центральный набор. Выход: полный классификатор, длинная доказательная таблица 3 объекта×3 периода (для атомарной единицы один объект), численности типов/уровней, выборка карточек и receipt. Ролевые знаменатели territorial/carry/context раздельны. Статус поддержки типа не является вероятностью или доказательством причинного механизма.

# Карты строгого прохода

`render_atlas.py` строит по реальным таблицам карты вPNG200dpi/SVG/PDF и сохраняет SHA256входов и выходов в`map_manifest.json`.

* `01_axis_road_coverage` — фактические исходные сущности переписи2021 и привязка к графуOSM19.10.2026. Статусы привязки2–5/5–10/>10км показаны отдельно; отсутствие координат указано в счетчиках.
* `02_functional_evidence` — рекреационные объекты, садовые участки, исторические моногорода и добывающий контекст. Эти объекты не названы поездками, миграцией, утратой производства или вахтовым переходом.
* `05_settlement_demographic_dynamics` — картографическая демографическая ось2002–2010 и2010–2021, без причинной интерпретации административных изменений.
* `06_ethnic_composition_context` — агрегированные ответы переписи2021 среди указавших национальность; подавленные значения остаются неизвестными.
* `03_road_hierarchy_<config>` — фактические рассчитанные назначения и центры по уровням модели; цвет повторяется и не задает полигон района.
* `04_nine_word_types_<config>` — отдельная панель для каждого Word-типа, с числами выполненных и неизвестных условий. Пересекающиеся правила не превращены в искусственную взаимоисключающую классификацию. Вывод по измеримым условиям не доказательство полного причинного механизма.

Последние две карты создаются только после появления `memberships.parquet`, `systems.parquet`, `word_type_hypotheses.parquet` в переданной конфигурации. Пример:

```bash
python research/sgrt_word_completion_20261021/maps/render_atlas.py --model-dir research/sgrt_word_completion_20261021/model/output_2021_restricted_baseline
```

ПроекцияАльберса, стандартные параллели50°/70°с.ш., центральный меридиан100°в.д. Береговая линияNaturalEarth110m используется только для ориентации; исходныйGeoJSON сURL/SHA сохранен в`sources/`. Административные границы и выпуклые оболочки не используются как доказанные границы тяготения. Сеть2026 не объявлена исторической сетью2021. На фигурах и в имени конфигурации разделяются baseline и inclusive.

Дополнительно `07_agro_climate_soil` показывает действительную суточнуюСАТ и летнееP/PET нормы1981–2010FAO GAEZ, а также нижнюю границу почвенного класса low-input maize (это не бонитет). `08_municipal_sown_share_2008` отражает единственный доступный парный год2008 с предупреждением о ретроспективном коде и непроверенной эквивалентности границ. `09_current_monotowns_2026` отделяет121 буквальную привязку текущего правового перечня от исторических318.

`10_center_rural_dynamics_<config>` — матрица динамики центра и сельского окружения по полным парам2010–2021. Она рисуется после появления модельных результатов; функциональные неизвестные не мешают показать фактически измеренную демографическую ось. Карта04 дополнительно выделяет оранжевым операционные гипотезы с неизвестными полными Word-условиями. Они не названы доказанными типами.

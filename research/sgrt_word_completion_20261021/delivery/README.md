# Материалы для научного руководителя

Пакет собирается из одного явно выбранного завершённого модельного прохода. Основной проход — `model/output_word_ci_2021_baseline`; его зафиксированный состав и SHA — [output_manifest.json](../model/output_word_ci_2021_baseline/output_manifest.json). [Основной 14-листовый атлас](../maps/atlas_output_word_ci_2021_baseline.pdf) доступен отдельно от сборного отчётного PDF.

**Это материалы для научного обсуждения; полная научная приёмка концепции Word пока не получена.** Актуальный допуск — [strict_gate_receipt.json](../reviews/strict_gate_receipt.json), поля `decision`, `scientific_final_allowed`, `completion_claim_allowed`.

Существование файла само по себе не доказывает свежесть. До использования сверяйте `package_inputs.json`, `model_directory` GIS-receipt и `run_receipt.json` выбранной модели. Ранние версии с теми же названиями могут быть пересобраны после ремонта рангов: численности берутся из конечных receipts, а не из названия или старого отчёта. Несжатый `.gpkg` не хранится в Git; распакуйте ZIP.

Основная масса/функции относятся к 2021; демографическая динамика — 2010–2021 в фиксированной сетке. Дорожная топология — октябрь 2026 со сценарными скоростями и отдельным коннектором. Девять типов Word представлены как проверяемые содержательные гипотезы; операциональный кандидат не тождествен доказанному полному типу. Полная ось включает единицы без координат; GIS не устраняет их из национального знаменателя.

Повторная сборка из корня репозитория:

```bash
python research/sgrt_word_completion_20261021/delivery/build_research_package.py --model research/sgrt_word_completion_20261021/model/output_word_ci_2021_baseline
python research/sgrt_word_completion_20261021/delivery/export_geopackage.py --model research/sgrt_word_completion_20261021/model/output_word_ci_2021_baseline
```

Команды выбирают завершённый основной проход из `package_inputs.json`; до окончания расчёта запускать сборку нельзя. Генератор проверяет закреплённые входы и отбирает соответствующие проходу карты. Строгая приёмка остаётся самостоятельным результатом: её отрицательный статус не исправляется выпуском документов. Соответствие концепции артефактам, команды модели и источниковые разрывы — в [основном README](../README.md).

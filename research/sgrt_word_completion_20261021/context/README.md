# Реальные демографические, жилищные и природно-аграрные контексты

Все три `*_settlement_features.parquet` сохраняют ровно 173527 уникальных `id` полной оси. Для 18558 записей без принятых координат пространственные значения отсутствуют. Это фактически полученные данные, а не каталог предполагаемых источников. Детальные URL, SHA256, размеры и первичные метаданные находятся в `source_manifest.json`, `*_acquisition.json`, `climate_receipt.json`, `soil_context_receipt.json`.

## Муниципальные ряды

`municipal_settlement_features.parquet` содержит контекст верхнего муниципального уровня, повторённый у относящихся к нему НП. Это **не собственные рождения, миграция, ввод жилья или посевы отдельного поселения**. Повторённые муниципальные численности нельзя суммировать по НП. Источник: Росстат БДМО, публикация/нормализация «Если быть точным», выпуск v20260928. Доступны собственные фактические годы, включая 2010–2021; дата скачивания не становится датой наблюдения.

Первичная ось содержит ОКТМО2021, а `oktmo_stable` источника использует гармонизированный код. Связь строится только по однозначной паре первичного кода2021 и stable-кода в наблюдениях2021. `municipal_source2021_to_stable_crosswalk.parquet` сохраняет этот мост. Равенство stable-кода **не доказывает неизменность границ**. Объединение нескольких разных исходных ОКТМО в одной паре stable/year/metric помечается `ambiguous_multiple_raw_codes`, и численное значение исключается даже при равных числах. Несогласованные численные значения также исключаются. Первичные выбранные строки сохранены отдельно, поэтому усечение не скрывает конфликтов.

- Рождения `Y48112003`, смерти `Y48112001`, естественный прирост `Y48112004`: человек. Первичный естественный прирост сохранён как `context_natural_increase_reported_YEAR`; исходный опубликованный вариант коэффициента — `context_natural_increase_reported_per1000_YEAR`.
- Аналитический `context_natural_increase_YEAR` дополняется разностью реально наблюдённых рождений и смертей, только когда они имеют одинаковые год, исходный ОКТМО, единицу «Человек» и действующий интервал кода. Производные имеют отдельные `context_natural_increase_derived_from_births_minus_deaths_YEAR`, `context_natural_increase_balance_status_YEAR`. Несогласие с опубликованным приростом остаётся в `context_natural_increase_source_balance_mismatch_YEAR`. Производный вариант не является независимо подтверждённым исправлением Росстата; для чувствительности следует сравнить с reported-only.
- Миграционный прирост `Y48112023`: человек; только «Миграция — всего» × пол «Всего» × возраст «Всего». Реальный архив начинается **2011**, поэтому2010 остаётся NULL. Подкатегории не суммируются.
- Жильё `Y48010001`: ввод жилых зданий, м² общей площади, только область показателя `mosh=Жилые здания`. Ввод населением и другие пересекающиеся области не добавлены к нему.
- Коэффициенты движения: 1000×число/среднее двух Jan1-численностей текущего и следующего года. Ввод жилья на душу: м²/тот же знаменатель. Источник населения `Y48112027`, только `mest=Все население`; городской и сельский итоги не смешиваются. Для знаменателя требуется одинаковый исходный ОКТМО обоих концов и числителя коэффициента. Отсутствующий конец или неоднозначная география дают NULL.
- Посевы `Y48007018`, все хозяйства, «Вся посевная площадь», га; урожайность `Y48007025`, все хозяйства, зерновые и зернобобовые всего, ц/га убранной площади.
- Сельхозпродукция `Y48007010`: тыс.руб. в текущих ценах, поэтому номинальный рост не означает реальный рост. `Y48007013`: индекс производства в сопоставимых ценах, % к предыдущему году. Его нельзя складывать как проценты или цеплять через отсутствующие годы.
- Фактический знаменатель площади сельхозугодий `Y48006006` существует только2006–2008; сохранён датированным. **Синхронная пара2008** позволяет отношение двух реально наблюдённых величин, сохранённое только как `context_sown_share_of_farmland_source_harmonized_usable_2008`: одинаковые год и исходный код, но источник ретроспективно присвоил большинству2008значений ОКТМО с периодом действия с2010. Это не доказательство совпадения границ2008/2021. Флаг `context_sown_farmland_historical_code_interval_valid_2008` сохраняет проверку. Строгая `context_sown_share_of_farmland_usable_2008`, требующая также действующего2008кода, остаётсяNULL. За2010/2021 доля NULL; площадь всех муниципальных земель не подставлена вместо сельхозугодий. Отношение вне[0,1] отмечается и исключается из usable-поля.

`agro_decline_evidence`: nullable, посевы2021/2010<0.8 при известных площадях, положительном2010 и source-declared «Без изменений» истории кода обоих лет. Это ограниченное свидетельство сокращения посевов, не автоматическое доказательство общего упадка. `agro_high_productivity_evidence`: nullable, муниципальная зерновая урожайность2021 не ниже национального Q75 наблюдаемых муниципальных значений; порог зафиксирован в receipt. Это зерновая урожайность, не общая факторная производительность и не бонитет.

## Природный контекст

В `climate_settlement_features.parquet`:

- `climate_gaez_sat_above10_cday_1981_2010`: **точная требуемая переменная SAT**, опубликованная FAO GAEZv4/CRUTS32, годовая сумма температур воздуха по дням Ta>10°C, °C·сутки, норма1981–2010, растр5′. Это климатическая модельная норма, не дневные станционные наблюдения2010/2021.
- `climate_gaez_summer_precipitation_over_pet_1981_2010`: P/PET апреля–сентября, безразмерное отношение; первичный процентный растр разделён100.
- WorldClim2.1: помесячные средние температуры°C и осадкимм, норма1970–2000,10′. Месячное приближение SAT сохранено с явным `monthly_approx` именем; для основной SAT следует брать FAO.
- GlobalAI/ET0 **v3.1**, норма1970–2000,30″: годовое P/ET0 и ET0мм/год. Значения AI масштабированы0.0001; использована исправленная версияv3.1, а не отозваннаяv3.0. Индикатор насыщения целогоAI сохранён отдельно.

`soil_settlement_features.parquet`: семь первичных FAO GAEZv4 почвенных оценок low-input maize: ограничивающая оценка, доступность питания, корнеобитаемость, кислородный режим, засоление/солонцеватость, известь/гипс, обрабатываемость. Основа HWSD; временной ряд отсутствует, источник обозначает год `n.a.`. Оригинальный classcode сохранён. Человеческие подписи и границы рейтинга0..1 получены **точным совпадениемRGB палитрыTIFF и изображений первичнойFAOлегенды**, а не догадкой о порядке кодов. NA/permafrost/not-evaluated/water не получают численного рейтинга. Это реальные пространственные свойства почв, **не российский балл бонитета** и не фактическая урожайность.

Российский бонитет: первичная карта Национального атласа почв, с.240–241, скачана в3600×2400, классы0–125, масштаб1:30000000. Карта опубликована как JPG без геопривязки. Дополнительно проверен первичный224.8MB архив `2013_map_per.zip`:16PDFлистов почвенной карты, атрибутов бонитета нет. Автоматическое присвоение поселениям баллов по негеопривязанной иллюстрации не валидировано. `soil_russian_bonitet_score` остаётся NULL; почвенные классы FAO не переименованы в бонитет.

## Воспроизведение

Из корня репозитория:

```bash
python research/sgrt_word_completion_20261021/context/acquire_context_sources.py
python research/sgrt_word_completion_20261021/context/acquire_migration_members.py
python research/sgrt_word_completion_20261021/context/build_municipal_context.py
python research/sgrt_word_completion_20261021/context/build_climate_context.py
python research/sgrt_word_completion_20261021/context/build_gaez_context.py
python research/sgrt_word_completion_20261021/context/build_soil_context.py
python research/sgrt_word_completion_20261021/context/validate_context.py
```

Миграция извлекается HTTPRange из ZIP центрального каталога: загружены только годовые parquet2011–2021 вместо1.47GB архива. SHA256 полного архива сознательноNULL; диапазонные SHA, членские CRC/SHA и ETag сохранены. Большой агрораздел читается с projection/filter, не загружается целиком со всеми измерениями. `validation.json` проверяет ось, NULLбезкоординат, исходные конфликты, согласованность знаменателей/производных, отсутствие2010миграции и200прямых выборок исходных климатических растров.

Здесь выполнены фактические проверки исходных строк, а не повторение утверждений построителя модели. Старые ось, компоненты массы, модель и поставка не изменены.

Общий итог147182123:155411обычных НП дают128022280, три федеральных территориальных итога19159843. Дочерние федеральные НП нельзя прибавлять к этим итогам.
- `latest2021_np_roster_complete_accounting.parquet` учитывает каждую из155747строк уровня«Населённый пункт» в отдельно полученной версии20260925. Контроль населения не доказывает полноту нулевого физического реестра или историческую эквивалентность территорий. Агрегатные контроли и исходные строки принадлежат одной переписи, разным таблицам/версиям одного распространителя; они не объявляются вторым независимым полевым наблюдением. ## Жилищный ввод и демографические компоненты (W05/W04/W11)

`audit_source_controls.py` непосредственно читает26427исходных строк жилищного ввода и32733строки январских оценок населения; скрипт не импортирует production builder/collapse. Все24159опубликованных модельных муниципальных отношений воспроизведены точно:

`жилищный ввод за год, м² / ((население на1января2021 + население на1января2022)/2)`.

Требуются одинаковые исходные коды у числителя и обоих концов знаменателя; конфликтующие значения/коды не складываются. Площадь, люди, период и год сохранены. Это муниципальный контекст, повторённый у НП; его нельзя суммировать по НП или объявлять собственным строительством НП.

В прежней версии отсутствовал защитный фильтр интервала существования исходного кода в метаданных источника.612отношений за2010–2021, в том числе99за2021, выходят за этот интервал. Это конфликт метаданных/исторической интерпретации, а не доказательство, что площадь неверна. Отдельный строгий сценарий сохраняет их как неизвестные; основной замороженный проход не переписывается.

| Компонент2021 | Муниципальных отношений удержано как неопределённые | Охват НП до → после | Затронуто НП / кандидатов центров |
|---|---:|---:|---:|
| Ввод жилья, м²/чел. |99|135843→133980|1863/23|
| Естественный прирост, на1000 |169|134666→132803|1863/23|
| Сальдо миграции, на1000 |169|135281→133418|1863/23|

Числа1863/23во всех трёх строках относятся к одним и тем же исходным НП; это не5589единиц. Демографические значения независимо прочитаны из исходныхCSVрождений/смертей/естественного прироста и миграционногоParquet2021; оба готовых отношения воспроизведены точно. Вариант«рождаемость−смертность» сохраняет происхождение и применяется только при совпадении нативных кодов/года/единиц. Производные строгие поля не заполняются нулями.

Поля для нового модельного прохода:

- `strict_housing2021_settlement_context.parquet`: `context_housing_completed_residential_m2_per_capita_strict2021`.
- `strict_demographic2021_settlement_context.parquet`: `context_natural_increase_per1000_strict2021`, `context_migration_increase_per1000_strict2021`.

250муниципалитетов в прочитанном переписном перечне содержат ровно один НП, сумма которого совпадает с муниципальным итогом;193из них имеют строгую жилищную величину2021. `single_np_municipality_housing_candidate_bridge.parquet` сохраняет эту более узкую гипотезу охвата, но не объявляет её доказанным совпадением юридических границ или местоположения построенных домов. Два неоднозначных имени«Городской округ» в Смоленской области удержаны отдельно.

## Воспроизведение

Из корня репозитория:

```bash
python research/sgrt_word_completion_20261021/data/source_controls_cycle05/audit_source_controls.py
python research/sgrt_word_completion_20261021/data/source_controls_cycle05/audit_latest_census_roster.py
python research/sgrt_word_completion_20261021/data/source_controls_cycle05/audit_demographic_native_year.py
```

Для первых двух шагов исходные файлы уже в Git; жилищный и популяционный исходныеParquet побайтно сохранены в `sources/`, сSHAархивов/членов иURL. Третий шаг читает три большие исходныеCSV и миграционныйParquet из ранее фактически полученного `/workspace/scratch/sgrt_context_completion`; компактные выбранные исходные ячейки2021 сохранены в этом каталоге. URL/SHAисходных архивов находятся в `../../context/source_manifest.json` и `../../context/migration_range_acquisition.json`. Наличие производных ячеек не выдаётся за встраивание всех полных исходных архивов в Git.

Receipts: `source_control_receipt.json`(24проверки), `latest_roster_receipt.json`(6), `demographic_context_receipt.json`(3). `source_freeze_manifest.json` фиксирует все файлы этого источникового прохода. Решение по требованиям принимает отдельный независимый проверяющий.

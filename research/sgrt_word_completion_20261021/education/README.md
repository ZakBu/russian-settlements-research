# Образование: национальный пространственный слой

Текущий полный проход OSM (срез 19.10.2026) дал 76 713 исходных объектов образования: 33 106 school, 35 475 kindergarten, 4182 college, 2713 university и 1237 специализированных школ, отделённых по названию. Сохраняются исходные теги, координаты, тип геометрии и все объекты вне принятой оси. После ограниченного устранения дубликатов школа-узел/школа-полигон остаётся 33 046 школьных site_id. Это инвентарь опубликованных объектов, а не полный ведомственный реестр действующих школ.

`settlement_features_full_axis.parquet` имеет 173 527 уникальных id; `settlement_features.parquet` сохраняет 142 570 id предыдущего master. Счётчики `*_baseline_count` обозначают объекты с явно названным в адресе НП, единственным совпадением этого имени в пределах 5 км. `*_candidate_additional_count` — отдельные геокандидаты в пределах 2.5 км, при достаточном отрыве от второго НП и отсутствии противоречия с адресом. Геокандидат не является доказанной адресной связью. Непринятые ближайшие НП остаются диагностикой. Привязка использует НП с населением2021, координатами и additive-флагом. Современная школа не присваивается только историческому исчезнувшему НП.

Явные связи школ имеются в 2466 НП; вместе с кандидатами — в 13 234. По прокси сельского типа (все типы кроме город/пгт/посёлок городского типа) — соответственно 1818 и 11 314 НП. Разрезы по населению и регионам: `coverage_by_population_size.csv`, `coverage_by_region_rural_proxy.csv`. Это не проценты полноты школ: знаменатель школ неизвестен.

Нулевой object count означает отсутствие принятого наблюдения в этом источнике; `*_observed_presence` при этом имеет NA, а не False. Полная мощность/даты открытия не выдуманы и остаются неизвестными. Из 33 106 школ только 90 имеют численный тег capacity. 737 школьных объектов имеют явный isced/grades тег; для 10 134 уровень лишь предполагается по словам «средняя», «основная», «начальная», «лицей», «гимназия». `school_level_evidence` различает эти основания; name signal нельзя выдавать за проверенную образовательную программу. ISCED1/2/3 и общее образование не смешаны с college/university.

Дополнительный каталог2022 содержит 22 301 сырую строку названия+сайта. Из-за нестрогих кавычек строки сохраняются без потерь; связаны2351 свидетельство в1854 НП при обязательном совпадении региона и явном locality name, неоднозначность сохраняется. Эти сведения дают dated institution witness, а не мощность или координаты кампуса. Пример реестра Тутвиднее (Башкортостан,1241 координатная организация) оставлен отдельно: координаты юридического адреса не являются координатами всех мест обучения. Портал явно не предоставляет полную выгрузку, поэтому массовое получение региональных страниц не выполнялось.

`source_manifest.json` содержит URL, дату, bytes, SHA256 и семантику фактически полученных основных источников. Полный журнал проб/ошибок и хешей ответов — `source_byte_manifest.json` и scratch JSON. Архив DataCrafter/Rosobrnadzor был найден, но доступные зеркала дали502/timeout и официальный endpoint503; полученным архивом это не считается. GitHub H3 worldwide aggregate исключён как не являющийся объектным реестром.

Воспроизведение после общего national extract транспортного агента:

```sh
python research/sgrt_word_completion_20261021/education/link_school_name_catalog.py
python research/sgrt_word_completion_20261021/education/build_school_features.py
python research/sgrt_word_completion_20261021/education/validate_school_features.py
```

`validation_receipt.json` проверяет уникальность, сохранение142570/173527id, взаимоисключение baseline/candidate, внешние ключи, сохранение исходных объектов и групповых счётчиков, пороги расстояния, отсутствие выдуманной мощности/ложных отрицательных presence. История2021 будет отдельным датированным слоем; изменение OSM покрытия не равно открытию/закрытию школы.

Conservation/uniqueness/baseline-candidate disjointness проверены.

`education_osm_identity_snapshot_comparison.parquet` сохраняет59 648общих OSMidentity,17 065только в2026 и9980только в2021 по всем группам. Объект мог быть добавлен в OSM спустя годы после постройки, удалён из-за картографического дубликата, сменить тег/identity/геометрию. Эти значения не доказывают открытия/закрытия. Два снимка позволяют пересчитать чувствительность функциональных районов к датированному опубликованному покрытию. Подтверждённой временной сетью действовавших физических школ они не названы.

# Cycle06 descriptive regression adapter

This new adapter preserves frozen cycle05 analysis and uses the accepted context_source_freeze_v4 municipal source view. No actual cycle06 regression metrics have been read or computed during adaptation.

CLI: `python run_regressions_cycle06.py --model-output PATH --output NEW_DIRECTORY --inputs BOUND_JSON --stage preregister`. Independent guardian acceptance matching code, input and preregistration SHAs is mandatory before `--stage full --preregistration-review RECEIPT`.

The template must be bound to the actual cycle06 model configuration, completed outputs, and direct rural-member-to-own-center network pairs. It does not point to old cycle05 outputs. Model main implementation and both cycle06 configuration and large-city helpers are checked against the completed model receipt and watched throughout analysis.

Two comparison families are registered separately for each of the 11 scientific scenarios:

- A: M1/M2 on identical complete-source rows, regional folds and bootstrap draws.
- B: M1/M2/M3 on identical complete-source rows with observed own-order configuration, regional folds and bootstrap draws.

No score difference between A and B estimates the benefit of added predictors. The comparison output compares only models within the same named family. Unknown configurations remain visible in coverage and sample gates. Level1 `structural_assignment_unit` maps to missing configuration. It is never assigned a monocentric zero. The configuration predictor maps actual own-order field-potential labels and uses the declared `own_order_shared_origin_fraction`; it does not reconstruct old highest-rank counts or an ambiguity proxy. Nested child-complex configuration is preserved separately and never fills missing own-order configuration. It is not included in the primary regressions.

The primary access predictor is 2010 resident-population-weighted directed time to each rural member's own hierarchy-level center on the dated2021 graph. Nearest-large-city accessibility is a separate contextual modifier. The suburban share is specifically the 30–60minute band. Missing values and routes remain unknown.

Whole-including-center population outcomes additionally require finite nonnegative own-center population in both2010 and2021. Source-membercohort completeness alone is insufficient. The external Moscow/SaintPetersburg context anchors have unknown own-city population and are excluded from these outcomes; federal-territory aggregates are never injected. Their actual rural member ledgers, rural-only outcomes and accessibility context remain. `whole_system_outcome_scope.csv` records the derived flags without changing modelsourceaggregates. The baselinepopulation control in ctxrural-only sensitivity refers to knownsource-members, not a wholecitytotal.

Context V4 preserves the38 rejected same-year grain links as missing and admits historical grain through either independently valid same-series identity or direct own-year code/interval/unchanged-history/unit/uniqueness proof. Historical boundary equivalence is unproven. The2008 strict ratio is unavailable under actual own-year constraints; the adapter does not restore its unrestricted raw proxy.

Before sample gates there are55 possible models per level: 45 across the nine main scenarios and10 across the separately named ten-region agricultural-census and historical-grain sensitivities. This is a design size, not a promise of estimable models. All fitted models remain descriptive rather than causal. The499 regional bootstrap replicates condition on fixed sources, routes and partitions.

Synthetic checks cover paired regional bootstrap repeatability, nested OLS, distinct denominator/family design, and a physical direct-own-center route example whose raw type says city while its accepted statistical role says rural. The last test verifies that structural L1 configuration stays missing.

# Word M1/M2/M3: сопоставимый описательный анализ

Исполнение: `python research/sgrt_word_completion_20261021/analysis/run_regressions.py --stage full`. До окончания полного дорожного расчёта допустим только `--stage coverage`; он сохраняет действительное покрытие источников, не результаты регрессий. Точные привязки полей и пороги — в `analysis_inputs.json`. SHA256 каждого прочитанного источника, кода и конфигурации проверяется до подготовки, после подготовки и после всех расчётов; изменение источника делает run недействительным.

Основной расчёт: `model/output_2021_restricted_baseline`, с ограниченным допуском кандидатов, согласованным root. Прежняя широкая сетка не подменяет этот основной расчёт.

**Качество демографии:** большинство сельских значений2010 имеют `secondary_confidentiality_protected_value_exact_scope_unverified`. Известное число не равнозначно независимо проверенному первичному итогу. Основные Y и веса условны относительно этих опубликованных/вторичных числовых значений; не называются точным ground truth. Значения и качество читаются согласованно из окончательных nodes после проверенных восстановлений2010, а не из прежней оси; имеющиеся original2010/recovered2010 provenance сохраняются отдельно. Для каждой системы сохраняется полная композиция источников по числу записей и сумме известных значений, отдельно для всей системы и внешних сельских членов.

Единица анализа — система `(level,center_id)` на фиксированной модельной сетке2021. Неназначенные и негеокодированные исходные записи остаются вне этих систем; регрессия не распространяет вывод автоматически на национальный остаток. Сельский статус берётся из фиксированной сетки2021 для всего ретроспективного периода, не восстанавливается как наблюдённая классификация2010. Каждый уровень оценивается отдельно, поэтому одна вложенная территория не объявляется независимым повтором в общей регрессии разных уровней. Основной Y: `100*(P2021/P2010−1)` при полном наблюдении обоих поселенческих составов, P2010>0 иP2021≥0. Фактические обнуления2021 сохраняются. Неполная известная сумма населения не становится полным населением системы.

- **M1**: log собственной массы центра2021, log населения системы2010 иlog(1+дорожная доступность сельского окружения к более сильному городскому узлу).
- **M2**: M1 + log(1+муниципальная зерновая урожайность2010), точная FAO сумма активных температур, летнийP/PET, FAO почвенный рейтинг.
- **M3**: M2 + модельная потенциальная полицентричность, доля конкурирующей принадлежности, сельская доля населения в пределах60минут сильного городского узла и взаимодействия массы×пригородной доли и урожайности×полицентричности.

Пригородная доступность не является измеренной маятниковой миграцией. Полицентрическая конфигурация — свойство модельных центров/конкуренции, не наблюдённый поток услуг. Почвенный рейтинг — FAO low-input maize/HWSD, **не российский бонитет**; midpoint интервала0..1 используется как явно объявленное приближение внутри класса.

Природные и аграрные характеристики агрегируются по сельским внешним членам системы с весами реально наблюдённого населения2010. Это средний контекст проживания, не средний балл сельскохозяйственной земли и не суммарная муниципальная продукция. Муниципальный показатель2010 привязан через текущий мост2021и source-stableкоды; независимая эквивалентность исторических границ2010/2021не доказана. Это ограничивает и основную урожайность, не только отдельную долю2008. Повторённые муниципальные значения усредняются; муниципальные итоги не складываются по НП. Требуются известные веса всех сельских членов, положительный суммарный вес и не менее80% охвата населения соответствующим признаком. Неизвестные маршруты/почвы/урожайность не становятся нулём.

Все M1–M3 внутри одного сценария и уровня используют **одинаковую полную выборку**, сформированную по совокупности регрессоров M3. Общая выборка фиксируется до оценкиM1. Сохраняется её состав, числа исключений и источник каждого признака. Минимум: max(80,10×число всех параметров) систем и10регионов. Не прошедшие пороги уровни получают явный статус, а не нарисованные коэффициенты. Постоянные признаки удаляются и перечисляются; отсутствующий эффект не изображается оценённым нулём.

Проверка переноса: пять фолдов GroupKFold по региону, одинаковых для всех трёх моделей. Центрирование/масштабирование выполняется заново внутри обучающего фолда. OOF R² сравнивается с обучающим средним для каждого фолда; также сохраняются RMSE/MAE. Ранг обучающей матрицы сохраняется для каждого фолда; при дефиците ранга fold-коэффициенты не интерпретируются, сравнениеCV помечается нестабильным. Регион системы — регион центра, поэтому трансграничный состав и пространственная близость по разные стороны границы могут сохранять зависимость.

В OLS каждая система имеет одинаковый вес; население2010 используется только для агрегации сельского контекста, а не для превращения крупных систем в повторные наблюдения. OLS-коэффициенты сообщаются на одноSD признака; 95%CI используют региональные cluster-robust CR1 ошибки и t-критическое сG−1 степенями свободы. Сохраняются ранг/обусловленность матрицы, leverage иCook's distance. Точные линейные зависимости удаляются в фиксированном порядке и перечисляются; взаимодействия интерпретируются условно, их коэффициент не является общим независимым эффектом. Такие интервалы условны относительно фиксированной сетки и не охватывают всю неопределённость маршрутов, массы, источников и исторического сопоставления.

Пространственная диагностика: Moran'sI остатков по симметризованным8ближайшим соседям на сфере, строчная стандартизация,499перестановок. Это точечная, а не полигональная смежность. Сохраняются расстояния соседей и карта остатков предсказаний на исключённых регионах; таблица средних/ошибок по регионам позволяет проверить остаточную географию.

Чувствительность оценивается отдельными сценариями, с собственной общей для M1–M3 выборкой:

1. `source_harmonized_agro2008_sensitivity`: добавляет только M2/M3 синхронную долю посевы/угодья2008, у которой источник ретроспективно гармонизировал муниципальные коды. Это не доказанная эквивалентность границ2008/2021. Строгая доля2010в источнике NULL и не подменяется этой величиной.
2. `rural_outcome_sensitivity`: Y — изменение только внешнего сельского населения при полной паре и положительном2010. Это уменьшает прямую арифметическую связь2021массы центра и суммарного2021населения, но не устанавливает причинность.
3. `positive_population_logratio_sensitivity`: `100*log(P2021/P2010)` только при положительных обоих итогах. Исключение обнулений здесь явно ограничивает сравнение.

4. `pure_primary_population_source_sensitivity`: только системы, у которых **каждый** член имеет разрешённое первичное качество2010 и опубликованный первичный2021. Whitelist указан в JSON; context-specific dash interpretation, secondary иunknown исключены. Произвольный допустимый процент вторичных значений не придуман. Даже нулевая/слишком малая выборка получает sample-gate, коэффициенты не создаются.

5. `experimental_bonitet_lower_bound_sensitivity` / `upper_bound_sensitivity`: отдельные сценарии с нижней иверхней границей экспериментально оцифрованного интервала первичного Атласа почв1:30М. Техническая геопривязка не является слепой независимой валидацией; это не измерение почвы НП и не принятый основной бонитет. Унижней/верхней границ проверены одинаковые исходные допустимые строки, весаP2010, охват и общая выборка. Границы распространяются согласованно на все записи одного исходного цветового интервала, без независимого случайного шума по НП; идентификаторы почвенных округов в оцифрованном продукте отсутствуют, поэтому полноценная ковариация ошибки округов неизвестна. Midpoint не подставляется вM2. Два крайних сценария не образуют полные доверительные границы с учётом всех неизвестных внутри интервалов; при недостатке общегоsample остаётся gate.

6. `reviewed_primary_supported_population_source_sensitivity`: отдельный вариант со100% первичной поддержкой, включающий принятые `reviewed_primary_control_derived_zero`. Эти нули доказаны проверенными контролями, но не выдаются за непосредственно прочитанное численное значение строки НП. Строгий pure-primary сценарий выше их исключает; оба используют одинаковые прежние требования кN/регионам и сохраняют детальную композицию качества.

**Интерпретация — ассоциации.** Масса2021, текущая дорожная сеть и сетка2021 используются для ретроспективной динамики2010–2021. Суммарная динамика содержит население центра2021, входящее также в массу: механическая связь/эндогенность неизбежна. Ни региональнаяCV, ни контроль начальной людности, ни доверительный интервал не делают этот анализ причинным или прогнозом из2010. Нельзя сравнивать R² разных сценариев как чистый прирост качества, поскольку их выборки различаются; внутри каждого сценария M1–M3 сопоставимы.

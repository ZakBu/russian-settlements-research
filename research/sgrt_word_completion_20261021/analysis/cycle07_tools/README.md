# Анализ изменений населения по фактическим пространственным единицам

Это описательная проверка концепции Word на опубликованных значениях населения 2010–2021 гг. Собственная масса центра задана источниками; она не подгоняется по населению получившегося района. Масса и урожайность 2021 г. не являются предшествующими факторами для причинного объяснения всего изменения 2010–2021 гг.

Каждый сценарий 30/45/60/90/120 минут оценивается отдельно. Это альтернативные разбиения, а не пять доказанных географических уровней и не независимые повторные выборки. Supported-end forest и выбранный промежуточный срез также нельзя смешивать.

`new_adapter.py` сохраняет старый source checkpoint с принятыми 353 первичными восстановлениями населения 2010 г. `new_adapter_source477.py` готовит отдельно новую семью с 477 восстановленными точками, новыми учрежденческими привязками, новым пулом всех документированных местных административных центров и новым выбором собственного ядра. Изменения между этими семьями нельзя приписывать только координатам.

Сельские контексты взвешиваются населением 2010 г. по статистически сельским внешним членам. Исключается только точный ID одного собственного ядра. Другие исходные поставщики остаются в сельской части, если они статистически сельские. Нужны все известные веса, не менее 80% наблюдаемого населения по признаку и отсутствие неизвестной роли у внешнего члена. Известный ноль сохраняется; неизвестный вес не становится нулём. При отсутствии жителей взвешенное среднее не определено.

Целое изменение населения допускается только при полной исходной совокупности обоих лет и известных собственных значениях ядра. Любой неизвестный московский или петербургский городской контекст внутри единицы блокирует полноту целого, включая неядерный контекст. Сумма известного населения обычных поселений сохраняется отдельно; население федерального субъекта не добавляется к ней. Сельский исход остаётся самостоятельным.

Собственное время доступа — фактическая направленная пара «член → ядро» на принятой сети 2021 г. Доступ к крупному городу является отдельным контекстом. Старый checkpoint имеет исходное поле до 360 минут. Новая семья использует единый предел 180 минут для всех истоков и тот же фиксированный список 171 источниково подтверждённого крупного городского якоря. Неизвестность за ограниченным полем маршрутов не означает отсутствия города.

В семействе A сравниваются M1/M2 на общей полной выборке M2. В семействе B сравниваются M1/M2/M3 на общей полной выборке M3. Между семействами выборки различаются: сравнение их оценок не идентифицирует эффект добавления M3. M3 описывает инвентарь исходных поставщиков и концентрацию их фиксированных масс; он не доказывает функциональную полицентричность и не измеряет концентрацию вместимости учреждений.

Проверка по отложенным регионам использует одинаковые строки и региональные разбиения внутри семьи. Стандартизация в каждом CV-fold оценивается только на обучающей части. CR1-интервалы условны на исходных значениях. 499 региональных повторных выборок используют общие draws для моделей одной семьи; они не распространяют неопределённость исторических границ, защищённых значений населения, исходного инвентаря, геометрических привязок и выбора самого разбиения. Moran — диагностика по точечному KNN, а не исправление всей пространственной зависимости.

До оценивания требуется независимый приём источников и агрегатов, точное связывание предварительной регистрации и текущего кода. После оценивания требуются отдельная проверка фактических чисел и визуальная проверка рисунков. Прежние результаты не копируются как новые. На момент создания этого описания фактические cycle07 регрессии ещё не запускались.

В premetric-уточнении PROTOCOL_v2 для baseline-контроля во всех сценариях, включая сельский исход, требуется полная совокупность наблюдаемых значений2010 всех объявленных аддитивных членов. Это известная полная сумма обычных исходных членов, а не вымышленное население неизвестного неаддитивного города. Неполная известная нижняя граница не поступает в этот регрессор.

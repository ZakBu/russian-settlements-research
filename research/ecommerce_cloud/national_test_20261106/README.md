# Интернет-заказы, муниципальные расходы и функции средних центров

Дистанционное приобретение стало массовым: опубликованная доля сельских жителей 15+, заказывавших товары или услуги через интернет, выросла с 37,5% в 2022 году до 58,0% в 2024-м. Микроданные 2024 года позволяют выделить вещевые группы и самовывоз, а муниципальный набор — изменение структуры безналичных расходов. Но эти показатели не раскрывают адрес получения, прежний центр или число отменённых поездок.

[Научный ответ](REPORT_RU.md) · [Проверка источников и расчётов](review/REVIEW_RU.md) · [PDF, рисунки, notebook и таблицы](https://github.com/ZakBu/russian-settlements-research/releases/tag/ecommerce-national-evidence-20261106-v1).

Новые результаты:

- Первичный ИКТ-2024: 53,89% сельских жителей 15+ сообщили о заказах хотя бы одной из восьми явно вещевых групп; 47,88% также отметили самовывоз. Последнее — пересечение по человеку, не по одному заказу, и не получение в своём НП. Знаменатель — 55 579 респондентов, вес около 30,1 млн человек.
- СберИндекс: у 2 016 МО с полными 24 месяцами медиана отношения модельных расходов на маркетплейсах ко всей корзине — 11,62% в 2023 году и 15,91% в 2024-м. Медиана изменений внутри МО — +4,10 п.п. Все территории имеют рост отношения; остаток номинально растёт у 1 965. Он включает другие интернет-магазины и услуги, поэтому не называется офлайном или местной розницей.
- КОУЖ-2024: новое разбиение постоянных и эпизодических пользователей товарного интернет-канала и сравнение основной географии приобретения. Оно не превращено в географию онлайн-заказов или поездок.
- Котовск: численность работников организаций без МСП выросла в 2024 году, но этот год уже нельзя считать невоздействованным — перевозчик сообщал о доставке на склад WB весной 2024-го. Новые отраслевые зарплаты не подменяют отраслевую занятость.
- Полностью прочитанное количественное исследование 2026 года даёт региональные связи интернет-торговли с безработицей и МСП; проверка дизайна не позволяет объявить их причинным ответом о средних центрах.

Сопоставимая опубликованная динамика любых заказов не является новой динамикой физических товаров: второй микромассив не получен. Кроме возраста, важна калибровка: официальная сноска выделяет данные до 2024 года как опубликованные без учёта переписи 2020 года. Все 20,5 п.п. нельзя приписать чистому изменению поведения.

## Воспроизведение доступных расчётов

Из корня чистого клона исследовательской ветки:

```bash
python -m pip install -r research/ecommerce_cloud/national_test_20261106/requirements.txt
python research/ecommerce_cloud/flows_20261026/fetch_kouzh_inputs.py
python research/ecommerce_cloud/national_test_20261106/fetch_sber_inputs.py
python research/ecommerce_cloud/national_test_20261106/build_deliverables.py --public-ict-aggregates
python research/ecommerce_cloud/national_test_20261106/package_results.py
```

Этот режим **пересчитывает КОУЖ, муниципальные расходы и отраслевые зарплаты из восстановленных файлов**. Для ИКТ он явно проверяет только опубликованные агрегаты, отношения числителей к знаменателям и внешние контрольные значения. Первичный SAV не восстанавливается автоматически через сервер, ограничивший доступ. Ни обхода ограничения, ни снятия проверки TLS нет.

Полный локальный пересчёт ИКТ выполнен двумя разными кодами по полученному файлу: 47 439 591 байт, SHA256 `587562f042ca1f61d3a37532bfa919bb2304b2997e6170bbf69632241496c1a7`. В [карточках](ict_survey/ict_source_pins.json) сохранены исходный адрес Росстата, архивная версия и её проверенный SHA1. При наличии этого неизменённого файла по указанному пути можно повторить полный режим:

```bash
python research/ecommerce_cloud/national_test_20261106/build_deliverables.py
```

По умолчанию он требует SAV и не заменяет его агрегатами молча. Скрипт `ict_survey/acquire_ict_sources.py` предназначен для нормального доступа к опубликованной версии после восстановления доступности, выполняет один запрос и проверяет хеш. В этом сеансе дальнейшие запросы к ограничившему доступ архиву прекращены.

Годовые книги Тамбовстата восстановлены по индексированным фрагментам официальных таблиц, а не по целиком полученным PDF. Их повторные извлечения и арифметика сохранены; чистое воспроизведение не объявляется повторным чтением полных книг. Два изображения и PDF строятся по проверенным числам. Опубликованный notebook сообщает режим каждой части расчёта.

Общая база населения и фиксированная средняя когорта не изменены. Новый муниципальный набор не присоединён к ней через неподтверждённые текущие центры или коды формы территории. Национальный причинный эффект на посредническую роль центров остаётся открытым вопросом.

# Зависимость окружения от среднего центра: результаты 6 ноября 2026 года

Местная выдача заменяет отдельные обращения к среднему центру, но другие сельские покупатели продолжают приезжать к городскому ПВЗ. У центра могут сохраняться или появляться функции оптовика, работодателя и логистического узла. Новое исследование различает эти операции и не выводит общее ослабление из одного распространения ПВЗ.

Основной результат — [научный ответ](REPORT_RU.md). Проверка источников и ограничений — [критический разбор](review/REVIEW_RU.md). Выпуск с PDF, исполненным notebook и малыми реестрами: [ecommerce-functional-routes-20261106-v1](https://github.com/ZakBu/russian-settlements-research/releases/tag/ecommerce-functional-routes-20261106-v1).

Новое: Спасская Полисть — прежнее Чудово; Орешки — прежняя Руза; Угольные Копи — прежний Анадырь, с работающей местной альтернативой, но без измерения поездок после открытия. Опочка даёт реальный сельский приезд к городскому пункту; Удомля — изменение одного бизнеса из розницы к опту и выдаче; Котовск — уточнённые внешние места проживания работников к июлю 2026 года. Сохраняются частичные сведения о местном довозе, отдельный случай переназначения в Дубках и операторские сообщения о перестройке грузовой сети.

В [сводном реестре](functional_evidence.csv) семь нынешних мест получения и шесть названных прежних центров, включая четыре места предыдущего прохода. Нынешний адрес пункта, прежнее назначение поездки и домашнее поселение различены. Даты отзывов не названы открытиями. Источники разного качества не превращены в одинаковые наблюдения: есть самоотчёты, рекламная история и сообщение об открытии без послеподключенческого счёта поездок.

Поиск охватил 24 новых подтверждённых центра западной части и 29 Урала, Сибири и Поволжья: соответственно 72 и 58 основных запросов. Первые просмотры, исключённые кандидаты и внешние наводки записаны отдельно. Полные журналы содержат 84 западных и 71 восточный запрос; у восьми начальных восточных запросов нет сохранённого ответа. Эти числа описывают работу с источниками, а не распространённость эффекта.

## Воспроизведение

В чистом клоне этой ветки, из корня репозитория:

```bash
python -m pip install -r research/ecommerce_cloud/observed_operations_20261104/requirements.txt
python research/ecommerce_cloud/fetch_bundle.py
python research/ecommerce_cloud/functional_routes_20261106/build_deliverables.py
python research/ecommerce_cloud/functional_routes_20261106/review/independent_checks.py --registers-only
python research/ecommerce_cloud/functional_routes_20261106/package_results.py
```

Первый загрузчик восстанавливает прежние закреплённые входы; он не перезаписывает отличающиеся местные данные. Нынешняя переписная ось — 144 151 запись, фиксированная средняя когорта — 1 273 центра. Контрольные суммы обоих входов проверяются до присоединения. Старые территориальные иллюстрации включены с явным происхождением из предыдущего отчёта.

Эти команды повторяют синтез, географическое присоединение, пересчёт опубликованных реестров, notebook и PDF. Первоначальный поиск и прочтение источников не являются автоматической воспроизводимой оценкой: поисковая выдача меняется, а полные страницы не распространяются. Скрипты первичного извлечения в подпапках требуют исходных локальных ответов, перечисленных в карточках источников. Полная независимая проверка сохранённых исходных файлов выполнена в рабочей среде; режим `--registers-only` явно пропускает их хеширование и сохраняет проверки всех опубликованных чисел и географических ключей.

Следующий содержательный пробел — сочетание целей поездки и фактический путь груза в одних и тех же случаях. Общероссийская частота, чистый баланс функций и причинный эффект по нынешнему корпусу не идентифицированы.

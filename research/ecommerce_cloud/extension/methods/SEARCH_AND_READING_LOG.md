## Файлы и статусы

`fetch_primary.py` сохраняет личные рабочие копии вне Git в `work/sources/research/ecommerce_settlement_20261024/methods_primary_20261025/`; это не переиздание научных публикаций. `primary_acquisition.json` фиксирует URL, время обращения, статус, размер и SHA256 реально скачанных тел либо ошибку. Официальные веб-страницы, прочитанные через поисковый инструмент, не приравниваются к сохранённому HTTP телу, если Python-запрос не прошёл. Источник может быть прочитан в web и не скачаться локально.

`source_registry_additions.json` содержит аддитивные записи для общего `references/sources.json` с сохранением перекрёстных идентификаторов прежнего обзора. Уровень чтения — выборочные разделы первичного полного текста, если прямо не сказано иное. Статус полного чтения каждой статьи целиком не заявляется.

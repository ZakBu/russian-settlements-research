# Как меняется посредничество среднего центра

В конкретных российских наблюдениях часть товарных поездок заменяется местным получением, но центр может сохраняться в маршруте товара и других поездках. Национальная частота изменения посредничества и причинный баланс утраченных и новых функций пока не установлены. [Подробный ответ](DEPENDENCY_REPORT_RU.md) связывает новые наблюдения поведения, документы операций и отдельный национальный расчёт окружений.

Новый национальный знаменатель — 71 211 жилых поселений окружения 1 273 средних центров, 19 411 640 жителей переписи 2021 года. Положительные записи WB/Ozon в собственном НП имеются у 9 614 НП с 12 472 999 жителями (64,26%). Это размещение разновременных записей 2026 года, не число покупателей и не доля отменённых поездок.

## Как повторить

Используйте корень этой исследовательской ветки. Не нужны старые пути macOS и временный PYTHONPATH. В чистой среде:

```bash
python3 -m venv .venv-ecommerce
.venv-ecommerce/bin/pip install -r research/ecommerce_cloud/extension/requirements-report.txt
.venv-ecommerce/bin/python research/ecommerce_cloud/fetch_bundle.py
.venv-ecommerce/bin/python research/ecommerce_cloud/check_bundle.py
.venv-ecommerce/bin/python research/ecommerce_cloud/run_checks.py
.venv-ecommerce/bin/python research/ecommerce_cloud/dependency_20261026/fetch_behaviour_sources.py
.venv-ecommerce/bin/python research/ecommerce_cloud/dependency_20261026/analyze_national_options.py
.venv-ecommerce/bin/python research/ecommerce_cloud/dependency_20261026/independent_options_check.py
.venv-ecommerce/bin/python research/ecommerce_cloud/dependency_20261026/build_deliverables.py
```

Последняя команда создаёт notebook через `nbformat`, исполняет обычным ядром `nbclient`, сохраняет реальные таблицы и два рисунка, статический HTML просмотра и PDF научного текста с критическим разбором. При редактировании только текста PDF можно пересобрать с `--pdf-only` после полной сборки. Используется выбранная среда Python; notebook не требует ручной установки отдельного именованного ядра. Результаты находятся в `work/ecommerce_dependency_20261026/export/`.

`behaviour_series.csv` — выписка опубликованных агрегатов, не пересчёт микроданных Росстата. Код загрузки проверяет SHA256 четырёх полных рабочих копий, но сторонние PDF не входят в Git и выпуск. URL, страницы, объём прочтения и хеши — в `behaviour_sources.json`, `observed_links_sources.json`, `logistics_sources_additions.json`; новые записи также добавлены в общий `references/sources.json`. Для оперативных веб-страниц не заявляется фиксация каждого тела SHA256.

Для национальной географии используются три входа закреплённого комплекта; точные пути/хеши сохраняются в `national_options_inputs.json`. Детальные 15 276 контекстных строк лежат в `work/ecommerce_dependency_20261026/national_options_contexts.csv`; малые национальные и региональные сводки — рядом с кодом. Разные административные сетки не складываются. Допуски 1/5/10 км проверяют идентичность адреса Ozon, а не поездку покупателя.

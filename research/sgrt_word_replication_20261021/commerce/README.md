# Торговля и получение товаров: национальный рабочий слой

Фактически выполненный проход 21 октября 2026 года по московскому времени.
Восстановлена вся ось **142 570 UID**, а не выборка крупных городов. В
`settlement_features.parquet` — 181 поле и ровно одна строка на UID. Исходный
master не изменялся; его контрольная сумма проверяется в `source_manifest.json`.

## Что сделано

1. Реально загружен опубликованный JSON Wildberries:
   <https://static-basket-01.wbbasket.ru/vol0/data/all-poo-fr-v11.json>.
   Сохранён неизменный gzip и SHA256 сжатых и исходных байтов. Из всех стран
   выделен опубликованный провайдером раздел `ru`: **91 043 записи**. Метка
   провайдера не равна независимой проверке государственной границы.
2. Все записи повторно сопоставлены с общей осью по буквальному имени в
   части адреса до улицы, явному типу НП и согласованной координате в 10 км.
   Среди одноимённых кандидатов требуется единственность; более длинное
   составное имя имеет приоритет над входящим в него коротким. Ближайшее
   поселение само по себе никогда не принимается. Карантинная точка
   Приозёрного исключена из поиска, её UID сохранён в широкой таблице.
3. Получено **74 763 baseline-записи в 16 172 НП**. Это все типы доставки,
   а не только публичные ПВЗ. Основной узкий профиль типов 8/34 присутствует
   в **7 991 НП**; более строгий вариант до 5 км — в **7 973 НП**.
   Коды типа сохранены без объявления всех кодов ПВЗ.
4. **56** соответствий с конфликтом типа сохранены отдельно как conditional;
   **825** неоднозначных и **7 425** прочих неразрешённых записей не
   распределены на ближайшие деревни. **7 973** явно федеральных адреса
   сохранены как территориальный контекст отдельно от обычной оси. Одна
   запись Баренцбурга не получает UID российской обычной оси. Мелкий
   адресный UID имеет приоритет над грубым упоминанием федерального города.
5. Из проверенного frozen master перенесены исходные счётчики WB,
   Places baseline/conditional/nearest, лексические сигналы Ozon и ряды
   зарегистрированных организаций розницы/общепита за **2011–2025**.

## Рекомендуемые поля для предварительной модели

| Поле | Смысл |
| --- | --- |
| `commerce_wb20261021_baseline_focus_count` | Принятые опубликованные WB типы 8/34 текущего снимка |
| `commerce_wb20261021_baseline_focus_within5km_count` | Пространственно более строгая чувствительность |
| `commerce_wb20261021_conditional_additional_focus_count` | Дополнительные условные связи; не baseline |
| `places_baseline_retail_store_count`, `places_baseline_market_count` | Исходные категории Places, включая возможные торгово-логистические пересечения |
| `commerce_goods_access_baseline_present` | Одна группа доступа к товарам: рынок OR розница OR WB-focus |
| `commerce_goods_access_log_mass` | Максимум логарифмов `log(1+count)` трёх предыдущих источников; источники не суммируются как независимые функции |
| `commerce_food_log_mass` | `log(1+places_baseline_food_service_count)`; отдельная группа общепита |
| `commerce_finance_baseline_present`, `commerce_postal_baseline_present` | Наличие принятого банковского/почтового свидетельства; не аудит всех действующих услуг |
| `econ_native_YYYY_retail47_legal_entities`, `econ_native_YYYY_food56_legal_entities` | Зарегистрированные юрлица соответствующего кода и года, не физические торговые площадки |
| `commerce_ozon_name_signal_not_verified_pvz_count` | Лексический сигнал имени; не проверенный реестр ПВЗ |

Доступ к товарам подтверждён принятыми источниковыми связками в **8 031 НП**,
физический общепит — в **671 НП**. Это положительный охват именно данных
правил, а не число всех обслуженных населённых пунктов России. Счётчик
отсутствующих записей не доказывает отсутствие услуги. `max` — прозрачный
консервативный показатель для модельной массы, а не оценка уникального числа
объектов после полной межисточниковой дедупликации.

Имена Ozon встречаются также у медицинских и иных учреждений: 50 baseline
лексических сигналов в 31 НП не превращены в ПВЗ. Запросы двух публичных
страниц Ozon дали redirect307 и тайм-аут15с; точные URL/время/ответ сохранены
в `sources/ozon_access_probe.json`. Это не доказательство отсутствия данных
Ozon вообще. Amazon не использован как замена российской сети.

## Что можно сказать о времени

В сохранённом снимке WB от 19 октября было 91 136 записей раздела `ru`, в
новом — 91 043: различие **−93** относится к содержимому каталога. Нет
сопоставленного полного прежнего объектного массива и сведений о физическом
открытии/закрытии, поэтому это не результат о закрытии 93 ПВЗ. Версии API
`v11` также не являются годами наблюдения.

`registered_commerce_calendar.csv` содержит реально посчитанные агрегаты всех
15 лет на той же оси. Например, число связавшихся с ней юрлиц розницы
составляет 178 368 в 2011 и 130 621 в 2025. История юридической отчётности,
изменение территориального кода и работа физической площадки — разные
явления. Этот ряд не используется для вывода о закрытии сельских магазинов.

Исторический документ PickPoint от февраля 2021 года остаётся отдельным
источником. В Git сохранён аудит 3 005 строк документа и 480 привязанных НП,
но полный объектный массив этого документа здесь не восстановлен. Эти
заявления прежнего аудита не выданы за новый пересчёт. PickPoint2021 и
WB2026 не объединяются в одну временную сеть.

Ни один каталог не измеряет объём спроса, поездки покупателей, обслуживаемое
окружение или границы СГРТ. Современная масса может использоваться только
для явно названной современной потенциальной конфигурации; её нельзя
перенести на 2002/2010 как наблюдённую историю услуг.

## Файлы и повтор

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 \
python research/sgrt_word_replication_20261021/commerce/build_commerce.py
```

Входы: восстановленный проверенный master, сохранённый
`sources/wb_20261021.json.gz`, прежний явный coordinate quarantine.
Требуются pandas, numpy, scipy и pyarrow.

- `wb20261021_objects.parquet`: все 91 043 строки, исходные типы/адреса,
  baseline/conditional, неоднозначность, диагностический ближайший UID и
  федеральный контекст. Последний не является принятой связью.
- `wb20261021_review_queue.csv.gz`: все строки без baseline.
- `settlement_features.parquet`: полная ось, исходные и производные поля.
- `feature_dictionary.csv`, `regional_coverage.csv`: определения/охват.
- `baseline_largest_distance_diagnostic.csv`: 100 самых далёких принятых
  именных связей для адресной проверки, а не выборка для калибровки модели.
- `source_manifest.json`: SHA256, размеры, source counts, 11 проверок.

Выполнены 11/11 инвариантов: точная ось и порядок, уникальность UID и object
id, баланс записей, отсутствие baseline/conditional пересечений, исключение
карантинной геометрии и известного зарубежного объекта, отсутствие
выдуманных потоков и фиктивной временной серии физических ПВЗ.

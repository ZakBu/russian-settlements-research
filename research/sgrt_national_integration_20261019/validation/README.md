# Независимая проверка массового соединения

`DESIGN.json` фиксирует проверку до появления общего master: неизменная ось, ключи, все значения присоединённых источников, баланс объектов, покрытие по регионам/размеру, очередь конфликтов и детерминированная выборка для последующей внешней проверки. Это не проверка трёх удобных примеров.

Финальный итог: **PASS_INTEGRATION_AND_DECLARED_CALCULATIONS**, см. `VALIDATION_SUMMARY.json` и краткий `VERDICT.md`. Канонический master `core/feature_master.parquet` содержит 142 570 × 914; проверены все 914 колонок. Первоначальный WAITING не выдаётся за выполненную проверку: он заменён фактическим итоговым прогоном. Промежуточный `core/results/feature_master.parquet` не подменяет финальный файл.

```bash
python national_integration_20261019/validation/build_bindings.py --master national_integration_20261019/core/feature_master.parquet
OPENBLAS_NUM_THREADS=1 python national_integration_20261019/validation/validate_master.py --master national_integration_20261019/core/feature_master.parquet
```

Доступны `--master`, `--axis`, `--bindings`, `--out`. Значения источников сравниваются на всех UID, а не только по национальным суммам. При неуникальном первичном ключе проверка останавливается; ошибочные/чужие UID не удаляются молча.

Владельцам слоёв: заполните `validation_bindings.json` по `validation_bindings.template.json`, указав действительные имена колонок, исходные пути, ключи, фильтры, единицы, даты и статус наблюдения. Шаблон не считается исполненным свидетельством. Для `coverage_status_bindings` состояния задаются явными фильтрами, например `{"name":"WB2026","states":{"baseline_link":[{"column":"actual_status_column","op":"eq","value":"accepted"}]}}`. Численная заполненность не заменяет это определение покрытия.

Все четыре финансовых поля, число пригодных отчётов, отсутствие данных, конечные нули и доли отчётности. Это не новая независимая проверка обучения условных aliases или географического legacy fallback.

Сверка master с feature-файлом агентства сама по себе не подтверждает правильность этого feature-файла; исходные и интеграционные уровни проверки не смешиваются.

Выборка: один UID из каждой существующей группы «регион × размер», затем до 75 записей из заранее определённой очереди рисков. Seed 20261019, выбор через SHA256. Метка `holdout_no_calibration` назначается до внешнего чтения и запрещает настройку модели по этим результатам без новой оценки. Пока у всех строк `external_review_status=not_yet_reviewed`: создание выборки не объявляется проверкой фактического тяготения.

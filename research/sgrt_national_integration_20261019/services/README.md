# Массовая привязка опубликованных мест доставки WB

Весь исходный корпус: **91 136 записей**, 26 значений `typePoint`, снимок 19.10.2026. Все записи сохранены; они не объявляются действующими публичными ПВЗ. Узкий сервисный профиль использует типы 8/34; расширенный вариант 8/34/28/53/54, технические 2/85 и прочие коды остаются раздельными.

Основная связка `wb_strict_uid`: буквальное название и согласованные координаты из прежнего проверенного crosswalk. 74 849 записей, 16 225 НП. Массовый nearest-кандидат расположен отдельно и не задаёт ни центр, ни район обслуживания.

В `wb_name_relaxed_features.parquet` дополнительно проверено расхождение типа НП (город/село и т.п.) при совпавшем имени, уникальности среди **всех** кандидатов в пределах координатного допуска и согласованных координатах. Приняты 56 **условных** дополнительных записей в 37 НП, включая 13 новых. Inclusive-слой включает основной: 74 905 записей, 16 238 НП; его нельзя складывать со strict.

## Исправления после массовой сборки

1. Пять точных мелких адресов первоначально терялись за более крупным заголовком Москва/Санкт-Петербург. Уточнённый именованный UID имеет приоритет; исходный заголовок и конфликт сохранены.
2. Координаты части записей находятся вне покрытия общей переписной оси. Их нельзя присоединять к далёкому пункту только потому, что он ближайший. Вся география сохраняется в объектной таблице; 1 666 записей выделены отдельно (1 661 в пустом для данной оси юго-западном конверте, 5 Байконур). Конверт проверен на отсутствие исходных UID. Это аудит покрытия оси, не политических границ.
3. Два федеральных городских агрегата сохраняют 7 972 объекта отдельно. Один объект Баренцбурга имеет явный внешний географический флаг. Новые правила не удаляют ни одной исходной записи.

После исправлений в координатном кандидатном слое 81 497 записей в 18 578 НП; 10 расстояний превышают 20 км. Это очередь проверки: для удалённых микрорайонов могут расходиться административное название и фактическая территория. Порог 20 км служит диагностике, а не границе тяготения.

## Файлы и воспроизведение

- `wb_objects_crosswalk.parquet`: все объекты, основные/условные/координатные идентификаторы, адреса и географические флаги.
- `wb_coordinate_candidates.parquet`: три ближайших географических кандидата для каждого объекта, 273 408 строк. Ни одна строка не измеряет поездку.
- `wb_settlement_features.parquet`: 142 570 строк, 71 поле, отдельные типы и основания связки.
- `wb_name_relaxed_features.parquet`: условное расширение с собственным аудитом.
- `AUDIT.json`, `NAME_RELAXATION_AUDIT.json`, `ITERATION_AUDIT.json`: балансы и контрольные суммы.

Из общего рабочего корня:

```bash
python national_integration_20261019/services/build_wb_national.py
python national_integration_20261019/services/audit_linkage_iterations.py
python national_integration_20261019/services/build_wb_name_relaxation.py
```

Источник: опубликованный JSON сервиса доставки Wildberries, неизменный снимок и provenance находятся в `functional_dynamics_20261019/marketplaces/`. Ноль связанного счётчика означает отсутствие принятой записи этого источника, а не доказанное отсутствие услуги. Снимок 2026 года не переносится на переписи и не образует временной ряд WB/Ozon. Отдельного полного провайдерского ряда Ozon в этой волне нет.

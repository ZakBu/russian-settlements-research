# Расширенные наблюдения населения и демографической структуры

Срез 13 октября 2026 года. Переносимое дополнение к принятому переписному реестру НП; исходные численности и совместное покрытие за 2002/2010/2021 годы не изменяются.

## Состав и смысл

- `data/history`: 9 045 буквальных вторичных наблюдений для 1 357 текущих физических НП по 167 фактическим годам, 1617–2025. Восстановлены из кэшированных Wikidata, а не объявлены новыми относительно недоступных старых внешних коллекций. Первичные ссылки не проверены, исторические границы неизвестны, исторические координаты не наблюдались. Текущая привязка по собственному коду/имени/типу/точке не доказывает сравнимость старой территории. Сохранены GUID, дата/точность, ранг, ссылки и путь/хэш сырого свидетельства.
- `data/primary`: 52 клетки первичного сборника «РСФСР. Городские поселения», 1991, для 13 проверенных городов: 1979/1989, наличное и постоянное население отдельно, единица — человек. Историческая территория не гармонизирована. Кроме того, 516 прежних годовых наблюдений 172 строк ежегодника Росстата 2024 за 2022–2024 восстановлены с привязкой к текущим UID; оценки на 1 января округлены до тысяч человек. Это восстановление существующей серии, не 516 новых наблюдений. Федеральные/агрегатные строки явно выделены и не выдаются за обычные НП.
- `data/structure/np_sex_2002_*`: первичные сведения о мужчинах и женщинах из Росстата, том 1, таблица 1-4, перепись 2002 года. 2 932 исходных городских НП, 5 864 половых значения. Сохранены исходные привязки и отдельные связи с 2021 годом; это ограниченная городская таблица, не все сельские НП России.
- `data/structure/np_structure_*_positive`: положительные переписные значения национального состава и связанных категорий 2021 года. Каноническая версия — 17.12.2025; версия 25.09.2026 сохранена отдельно, версии не складываются. По 794 071 положительному значению в каждой версии; категории могут перекрываться при нескольких ответах. 155 411 допустимых НП, три агрегатных объекта исключены из физических утверждений.
- `data/structure/native_np_*_all_attributes`: неизменные широкие исходные атрибуты нужны для точного различения опубликованного нуля, неизвестного и анонимизированного -9. Пустота в разреженной таблице положительных значений НЕ означает ноль. Сохранены 20 825 629 опубликованных нулей и 11 638 254 подавленных клеток каждой версии; -9 никогда не преобразуется в численность или ноль.

Возраст, пол, домохозяйства и структура семей на уровне всех НП отсутствуют в этих национальных составах 2021 года. Муниципальные возрастно-половые сведения из другого пакета остаются муниципальным контекстом; они не распределяются между НП. Федеральные территории — отдельная ось, не физические НП и не дополнительный слагаемый поверх уже учтенных дочерних наблюдений.

## Чтение и проверка

Требуются Python 3 и DuckDB (`python -m pip install duckdb`). Манифест содержит относительные пути, размеры, SHA-256, исходные пути/хэши и число строк. Все хэши следует проверить перед объединением. Таблицы можно читать напрямую через DuckDB `read_parquet`, без произведения НП на все строки.

Точное чтение исходной клетки, включая 0 и -9:

```bash
python code/lookup.py --wide-root data/structure --version frozen --source-record-id '2021:data_allsettlements_anon_156_v20251217.parquet:parquet:10' --field 'Армяне (русские армяне)'
```

`query_series.py` соединяет расширения с принятым переписным реестром по исходным UID-якорям. Требуется внешний текущий принятый Parquet (`--census`), закрепленный в квитанциях исходным SHA-256 `8be41d46b832310fc68bc48c715e71af87e5c525fc7e1c4d7264ce71931a623a`; файл намеренно не входит в этот ограниченный пакет. Его пересборка должна сохранять исходные UID. Имя НП не используется как глобальный идентификатор; перенумерация root не должна скрывать свидетельства:

```bash
python code/query_series.py --census /path/to/integrated_spatial_temporal_records.parquet --history data/history/population_history_long.parquet --primary data/primary/primary_city_population_1979_1989.parquet --primary data/primary/primary_city_annual_2022_2024.parquet --source-record-id 'ИСХОДНЫЙ_UID'
```

Исходные сведения о происхождении, проверках, полях и ограничениях находятся в `provenance`; просмотровые строки OCR остаются кандидатами, не принятой первичной исторической серией. Сырые изображения/PDF и смешанные защищенные материалы переписи 2010 года в этот пакет не включены.

## Использование источников

Wikidata: CC0 для структурированных утверждений. «Если быть точным»: Creative Commons BY без указанной версии, Росстат; обработка «Если быть точным»; сохраняйте ссылки и авторство. Для остальных официальных публикаций действуют условия конкретного источника; общей лицензии на весь пакет нет. Нельзя заменять переписные численности современными оценками, заполнять неизвестное нулем, складывать наличное и постоянное население либо несколько версий одной клетки.

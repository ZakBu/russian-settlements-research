# Дополнительный пакет «Если быть точным»: население и муниципальная демография

Срез 13 октября 2026 года. Это переносимое дополнение к исследованию населенных пунктов России: все 16 демографических показателей муниципальной статистики «Если быть точным», переписные атрибуты двух версий и проверенные связи с принятыми записями НП. Исходные переписные численности НП не заменяются.

## Что находится в пакете

- 66 таблиц PARQUET муниципальной статистики, исходная версия 28.09.2026. Периоды показателей различаются; совокупный фактический диапазон — 2006–2025. Рождения, смерти, естественный и миграционный прирост, прибывшие, выбывшие, возраст и пол, оценки населения на 1 января, дети 1–6 лет, средний размер домохозяйства и национальный состав. Точные периоды — в справочниках provenance.
- 192 756 041 исходная строка, включая дубликаты. 192 680 088 строк имеют допустимое числовое значение по проверке области значений, тоже включая дубликаты. 23 недопустимых значения сохранены в сыром слое; прочие отсутствующие значения не заменены нулями. Допустимость значения не доказывает уникальность наблюдения.
- Четыре широкие таблицы атрибутов НП/МО: замороженная версия 17.12.2025 и версия 25.09.2026; два полных исходных PARQUET сохранены отдельно для объектов, не связанных с принятой таблицей.
- Проверенные связи НП с источником, мост муниципального контекста, вторичные атрибуты, диагностика имен и связь версий. Отдельная ось содержит шесть принятых федеральных территориальных записей для Москвы и Санкт-Петербурга за три переписи. Эта ось не выдается за обычные НП и не суммируется повторно с дочерними строками.
- Источники, SHA-256, версии, условия использования, полученные описания и справочник БДМО — в provenance. Манифест связывает данные с исходными файлами/членами ZIP и фиксирует хэши всех файлов пакета.

## Как читать данные

Муниципальные показатели — контекст муниципалитета, а не собственные рождения, смерти, миграция, возраст или пол каждого НП. Не распределяйте муниципальные суммы между НП, не копируйте их как собственные значения и не суммируйте один муниципалитет повторно через несколько НП. Для старых переписей атрибуты 2021 года являются явно обозначенным справочным контекстом; историческая принадлежность к муниципалитету не утверждается. Даже точное совпадение кода не доказывает постоянство границ. Код с неоднозначным именем или связью требует просмотра флагов контекста.

Период «на 1 января» отличается от годового потока. Разрезы миграции, пола и возраста могут перекрываться; сначала выбирайте нужную классификацию, затем проверяйте уникальность. Сохранены исходные значения, дубликаты, уровень территории, год, период, комментарии и история кода. Арифметические проверки также выявляют расхождения: 218 несоответствий естественного прироста разности рождений и смертей сохранены для проверки; миграционные балансы проверялись только в охваченном подмножестве 2008–2015, а не во всех годах. Это не сертификат чистоты исходных данных. Полнота отличается по годам и территориям; первые миграционные годы и 2024 год особенно ограничены. Отсутствие строки не означает ноль.

Текущая принятая совместная территориальная численность исследования: 2002 — 144 637 473 / 145 166 731; 2010 — 142 172 049 / 142 856 536; 2021 — 144 329 319 / 144 699 673. Это показатели основного исследования, а не доля наличия муниципальной демографии в данном пакете.

## Воспроизводимый доступ

Требуются Python 3 и duckdb (`python -m pip install duckdb`). После распаковки:

```bash
python open_package.py --package-root . --verify
python open_package.py --package-root . --np-id 'ИДЕНТИФИКАТОР_ПРИНЯТОЙ_ЗАПИСИ' --year 2021 --indicator Y48112027 --limit 10
```

Для вторичных атрибутов используйте `--attributes`. `--output result.csv` сохраняет выборку. Reader открывает источники как представления DuckDB и не создает произведение всех НП на все муниципальные строки. `--verify` проверяет размеры и SHA-256 файлов по манифесту. Числовая проверка доступна как `value_status`/`usable_value`; исходное значение остается отдельно.

## Условия использования

Для наборов «Если быть точным» описания указывают Creative Commons BY (версия лицензии не названа): Росстат; обработка «Если быть точным». В пакете сохранены точные ссылки и описания. Это не общая лицензия на все внешние источники исследования. Пакет не включает смешанный сырой набор переписи 2010 года. Замороженные источники и принятые переписные значения не изменены.
